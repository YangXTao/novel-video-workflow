# additional_directive 写法指南（强度与特效诉求）

本文件是**工作流侧的传参指南**，不是创作规则。规则一律以安装版 v13.1.1 规则源为准。

## 1. 强度诉求在链路里的三层位置

| 层 | 载体 | 作用 |
|---|---|---|
| 规则源怎么执行 | 模板「特效落实」行 → 规则源 00/12 号子节 | 保证执行层**读了**特效硬闸（铁律19/33/38/5、12 号 2.9.1） |
| 跨章稳定的诉求 | `novel_video_production_config.json` 的 `video_prompt_generation.additional_directive` | 保证执行层**长期按同一强度**做 |
| 当次临时的诉求 | 模板「强度与特效诉求」行（用户当次口语要求逐字传入） | 保证**这一章**的临时加强不被丢掉 |

三者互补：缺第一层＝不知道要落实什么；缺第二/三层＝每项都做了一点，但都偏保守。

## 2. 为什么"抽象概括"不够（一次实测）

| | 第56章 | 第57章 |
|---|---|---|
| 子任务指令里的强度传参 | 有——逐条点名特效手法与元素库来源 | **无**——手写指令漏掉了模板的「项目级附加创作要求」行 |
| 自检 I 段实测 | 时间手法 5 次、⑨EWS 3/14、爆点量级 5 镜 | 时间手法 **0**、⑨EWS **0/4**、爆点量级 0 镜 |

两章题材不同，数字不能直接比大小；但"**某项全稿为 0**"是结构性缺失，可比。

配置里此前的写法是"打戏段统一采用**高强度表现**…呈现高速连续攻防、清晰身法位移、打击因果、环境互动和**大型特效**"——"高强度""大型特效"都是形容词，执行层无从下手，而且**丢掉了档位信息**。

## 3. 口语强度词实际指定了什么（所以它有效）

| 有效写法（口语） | 实际指定 | 规则源对应条款 |
|---|---|---|
| "特效拉满""开到最大" | 顶到最高档，不许退回平常档 | 铁律19「档位按剧情规模选…**禁止攻击特效退回"占1/3、人物占1/10"的旧最小平常档**」；铁律0.5-D 用户指定优先 |
| "碰撞特效""技能特效""大特效" | 三类特效都要出现 | 铁律5（每击必爆三档）· 12 号 2.9 · 12 号 2.9.1 |
| "多颜色的粒子特效""拖尾""武器挥动拖尾" | 具体现象类目 | 12 号 2.9.1 ⑫粒子系统系 · ⑨拖尾轨迹系（16 种；必写主体+材质+长度+消散） |
| "持续性时间长的特效""流动的" | 生命周期，不许一闪即消 | 铁律0.5 第4步「写清生命周期（怎么聚、沿什么轴线飞、命中、怎么散）」· 12 号 2.9.1 六要素（"消散方式"为必写项） |
| "中景近景远景超远景的空间感" | 景别跨档 + 纵深 | 铁律41/45 · 铁律19 五种大小对比表达 |
| "空间不能是死一样的空间" | 空间要参与反应 | 铁律11 环境破坏链式因果 · 铁律19 ⑧环境改变 |
| "背后要有常态化法阵" | 常驻场域法阵 | 铁律31（法阵立体生长）· 30 号 4.x |
| "闪现""追逐战""极速对砍" | 高速位移/瞬移段复合运镜链 | 铁律7「跟高速位移/瞬移/突围＝贴肩跟拍+Whip Pan追残影+失焦追焦」 |
| "全体高燃""剧情感""嘲讽""互砍" | 势曲线与对战叙事 | 13 号（叙事闸四问/势曲线/打法即人设/博弈停顿） |
| "复刻剑来/黑神话名场面，不出现称呼、同名替换" | 结构学习而非照抄外观 | 94 号「参考原型增强库」 |

⇒ 这类口语指令不"外行"，它是在用日常语言**指定规则源里的档位与手法**。不必照抄措辞，把同样信息写成可执行清单即可等价。

## 4. 建议文本（可直接复制进配置）

写进 `novel_video_production_config.json` 的
`video_prompt_generation.additional_directive`（字符串值，内部不含双引号）：

```text
按完整剧本逐场、逐镜、逐拍识别内容类型，不得用同一种规则覆盖全章。打戏与动作交锋段按规则源允许的最高强度档执行，用户指定以下诉求，优先于任何默认档：
一、强度档：攻击、碰撞、技能的规模与冲击力拉到规则源内最高档，禁止退回平常档；同一场内不得只用一种尺度，按剧情推进逐级放大，每个大特效后接一次尺度再证。
二、必含特效：碰撞特效、技能特效、大特效、多色粒子特效、拖尾（人物拖尾与武器挥动拖尾）每场打戏都要出现；法阵（含常态化场域法阵）、法相、个人领域仅在剧本或已有设定存在对应事实时触发，并完整展开，不得为强化效果凭空新增。
三、特效时间性：持续时间要长、要有流动感与完整生命周期，写清怎么聚、沿什么轴线走、命中、怎么散、留下什么残留，禁止一闪即消。
四、空间与镜位：场景按剧本事实铺开；景别在中景与近景与远景与超远景之间跨档；空间要有立体感与纵深感，禁止平面贴片式、禁止无反应的空场。破坏按链式因果逐级递进，禁止所有破坏同一时间炸开。
五、运镜：三维摄影机路径与二维画面冲击相结合的复合运镜；高速位移、闪现、追逐、极速对砍等段用对应的复合运镜链，不一套机位走到底。
六、情绪与剧情：全程高燃；对白短促、有剧情感（动机、嘲讽、互砍的张力），不重复同一句；剧情节点与原台词完整保留。可参考经典名场面的结构与节奏，但不得出现任何作品称呼或角色名，一律同名替换。
文戏与剧情对白段不套用以上强规则，完整呈现剧情节点与原台词，锁定说话人、声线、情绪、嘴部状态、听者反应、微表情、走位与空间连续性。混合镜头按时间轴逐拍分流：动作片段走高强度轨，对话片段走文戏轨。
```

保留原配置里"不得为强化效果凭空新增""文戏不套打戏强规则""混合镜头逐拍分流"三条约束——它们防的是与铁律48（剧本逐句映射）冲突。

## 5. 两条红线

1. **不得凭空新增剧本没有的法阵/法相/领域**。用户说"要有法阵"时，只有剧本或已有设定存在对应事实才触发（规则源 30/91 号）；否则等于改写剧本，违反铁律48。
2. **不得写工程参数**。强度诉求用画面语言表达（"拉满""极速"），不要写秒数、帧率、m/s、占比数字——铁律58 禁止工程参数进成稿；占比% 与三混合% 的例外见规则源 90/91 号卷首。

## 6. 怎么验证生效

出稿后跑工作流侧自检，看 **I 段**：时间手法（顿/升/甩/闪）、⑨EWS再证、巨物感三连、爆点量级、并行特效类数。诉求生效时这些数字应明显非零；某项全稿仍为 `·` 时，先查该行是否真的传下去了（模板三行都不许省略）。
