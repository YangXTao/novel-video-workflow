# video-prompts-v12.6 变更说明

本文说明 `video-prompts-v12.6` 分支相对 `main` 的核心变化。当前活动调用名为 `video-prompts-v12`，Skill 版本为 `12.6.0`。

## 视频提示词生成器

- 用小家 v12.6 完整规则取代旧 `video-prompts-v10`，新产物不再沿用 V10.1 格式、固定五个两秒节点、旧字数密度门槛或旧工业术语门禁。
- 将原 v12.6 单文件母版无损拆分为 `control.md` 和 25 个编号规则文件，运行时按文戏、打戏、追逐、法术及混合叙事按需读取，减少无关上下文消耗。
- 保留母版的全部规则、示例、素材和包装分隔标记，可依照 `rule-bundle.json` 中的顺序与哈希逐字节重组回原母版。
- 新增规则包完整性验证脚本，检查 26 个组成部分、文件顺序、分段哈希和原母版重组哈希。
- 停用旧 V10 校验器及资产正文重写脚本，避免旧正则删除 v12.6 正文内容或图号。
- 历史已生成成品默认继续沿用，除非用户明确要求重做。

## v12.6 新增四项核心铁律

1. **铁律48：剧本内容全保留**
   
   完整剧本转换时，台词、动作和物件必须逐场核对，不得静默删减。若固定时长无法容纳，必须显式请用户选择加镜、加长或拆分。

2. **铁律49：场景切换必须有物理因果**
   
   物理地点变化需用移动过程、跨时间线匹配剪辑，或回忆/想象/梦境的视听过渡建立因果，禁止无过程跳到新场景。

3. **铁律50：喜剧内心小人三模态**
   
   喜剧或萌系项目在小框、实体化、混合模式中三选一，全剧统一。实体化小人需使用 3D 三头身 Q 版、真实场景光影和角色本人音色，且剧中人物不可见。

4. **铁律51：秒数按项目锁定**
   
   用户在项目开始时指定的单镜秒数必须在该项目内统一继承，不得把其他项目的 10/15/30 秒设定套入当前项目。

## 配套 Skill 与生产规则

- `novel-to-screenplay` 增加 v12 触发语义桥接，让剧本中的打戏、法术、追逐和文戏信号能正常触发下游规则，同时加强剧本结构、声音、原文依据和场次匹配校验。
- 人物、场景和道具图片提示词 Skill 同步了新模板、全局风格、单一画面约束、复用判断和统一降噪后缀。
- `doubao-video-production` 增加对话生成与工作任务云电脑的路由、时长/套餐/额度判断、账号切换、失败恢复、原始视频卡片保留和无水印下载优先规则。
- 豆包提交引导语改为：`严格执行下方第<章号>章S<镜号>提示词，勿改写或摘要，直接生成视频；完成后返回原始视频卡片及结果链接。`
- 默认视频比例为 `16:9`；用户提前指定其他比例时才覆盖默认值。
- `novel-video-orchestrator` 增加时长与模型计划、依赖门禁、阶段状态和断点恢复字段。

## MCP 与脚本

- 同步豆包 Playwright MCP 和 ChatGPT 图片 Playwright MCP 的启动、显示、CDP 连接、状态检查与恢复脚本。
- 补充专用 Chrome 显示配置和持久化 profile 烟测脚本。
- 同步图片执行器、视频进度、参考图绑定、尾帧登记、下载恢复和命名脚本。
- 仓库不包含浏览器 profile、Cookie、账号凭据、任务账本、运行日志、章节素材或已生成媒体。
