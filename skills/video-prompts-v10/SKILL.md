# V10 视频提示词

## 执行顺序

1. 完整读取用户指定的基准剧本、本章 `asset_manifest.json`（如已建立）及本次实际提供的参考资产信息。
2. 完整读取 [references/execution-contract.md](references/execution-contract.md)，锁定当前生效格式、信息保真和验收条件。
3. 从头到尾完整读取当前唯一规则 [references/original-prompt.md](references/original-prompt.md)。该文件当前为V10.1工业句法版（附着八法、三层跨色、法阵活周期、大远景展招、瞬移甩镜），必须按原始顺序分段读取到文件结尾。
4. 先按基准剧本建立逐镜事实表，再依据资产清单写逐镜“参考资产需求”；事实表只供内部使用，不输出。
5. 有资产清单时运行 [scripts/validate_v10_output.ps1](scripts/validate_v10_output.ps1) 并传入 `-AssetManifest` 与 `-RequireSemanticAssetRequirements`；没有资产清单时按原始模式检查。校验器的内容密度门禁必须保持启用，禁止为通过四段式格式检查而合并、缩短或删除时间轴细节。存在错误时只重做失败镜头，验证通过后才能交付。

如果已通过的V10正文不需要重写、仅因 `asset_manifest.json` 的正式资产版本变化而使“参考资产需求”过期，运行 `scripts/sync_v10_asset_requirements.ps1` 另存新版本。该脚本只更新逐镜参考资产需求并把固定“严格参考图N”改成无编号语义锁，其他正文必须逐字不变。

禁止把用户提供的旧成品、其他模型成品或原始规则中的示例当作当前输出模板。它们只能用于对比，不得覆盖基准剧本和执行合同。

## 规则优先级

发生歧义时严格按以下顺序处理：

1. 用户本次明确要求。
2. 基准剧本中的剧情事实、原始对白、镜头编号和时长。
3. `execution-contract.md` 中的当前执行锁。
4. V10原文中标记为最新生效的规则。
5. V10原文中的历史版本说明、旧示例和废弃格式。

该文件是未经清理、拆分或重构的 V10.1 工业句法版原始规则正文：

- 原样执行其中的流程、约束和输出格式。
- 不得擅自删减、概括、改写、重构、优化、去重或调和其中的规则。
- 将其中的示例、模板占位内容与当前用户输入区分开，不得把示例当作当前剧本或当前镜头任务。

不得因为规则升级而自动重写已经完成的旧章节V10产物。规则文件只保留当前版本；旧章节继续使用已经生成好的正式V10成品，除非用户明确要求重新生成。

## 输入与产物

输入应包括小说转剧本环节产生的完整基准剧本，以及本次任务实际提供的已审核资产图或资产信息。人物、场景、道具的同一张已审核资产图同时作为设计母图和视频参考图，不另行要求第二套参考图。已有 `asset_manifest.json` 时，它是资产可用状态和真实路径的唯一依据：V10只写逐镜语义化“参考资产需求”，不得提前分配 `@imageN`。最终编号由视频制作 Skill 在实际上传前根据真实文件、最多10张限制和已审核尾帧动态分配。

没有实际提供参考图时，按V10规则完整描述外观；有已审核资产时执行“有图零外观”。`no_build`、`missing`、`generated_unreviewed`、`rejected` 或没有真实文件的资产不得写成可用参考图。

严格按照 V10 原始规则生成视频提示词。本 Skill 只生成提示词，不操作豆包网页，不等待、下载或命名视频文件。

## 失真防护

- 模板转换必须是无损重排：从文戏字段式改为打戏/法术四段式时，只能把空间锁定、上镜衔接、声音、特效、武器状态、环境反馈和穿模要求织入四段，不得删掉或概括。
- 四段式中的“精简”只指减少独立标题，不代表减少信息；时间轴仍是完整工业级正文。
- 打戏和法术大场面的五个2秒节点必须逐个完整展开，不能只保留动作摘要。
- 任一打戏或法术镜头若明显短于V10.1工业级密度，必须判定失败并重写，禁止提交网页生成；文戏继续按V10.1原有字段和校验执行。
- 打戏和法术大场面禁止背景音乐，只保留对白、环境音、动作音和必要静默；第④段负面提示词必须以“禁止背景音乐！！！”开头。
- 每一句可听对白都必须从基准剧本逐字复制其完整方括号声音标签，并紧贴该句对白出现；标签中的角色名、固定声线、音质、当前情绪、语速/重音和“开口”标记一项都不能省略。禁止只写“嘴部同步说/回答”、禁止自行缩成声线简称，也禁止把全局声音表当作逐句标签的替代品；基准剧本本身写“同一音色”时才允许原样保留。

## 工业句法硬闸

以下规则只增强打戏和法术大场面的可见执行，不改变基准剧本事实：

- 先锁动作因果，再写画面：起手、位移或离手、飞行或换位、命中或格挡、环境结果、衰减或收束必须连续，上一拍结束状态就是下一拍起始状态。
- 有能量武器时先判定附刃、离体、残留三态，禁止混写。附刃必须按原文“附着八法”表现武器分区、定向流动、手尖回流、发力爆亮、尖端拉长但根部不离刃、螺旋攀附、贴刃质感与远景不丢形；离体必须写出从刃上能量到独立攻击体的连续过渡及完整生命周期。
- 任何真实出现的法术、法阵、附刃光、爆炸、光柱或拳气必须具有三层跨色相结构；三层须肉眼可分，禁止用同一颜色的深浅渐变冒充三层。原文或既有资产已锁定的主色不得擅改，新增对比色只服务层次分离。
- 实际运转的法阵、剑阵和领域必须写出活周期：多层反向异速旋转、符文波浪点亮与循环明灭、涟漪外扩回收、层间光带穿梭；剧本明确沉寂、损坏或停止的阵法不得被强制活化。
- 剧本确有大绝招时必须留出大远景展招节点，使完整特效轮廓、连环爆点、原文允许的地形破坏及天地受光同时进入同一画框；不得为了增强规模新增剧本没有的毁城、伤亡或结果。
- 剧本确有瞬移时必须写成“起点高速残影→同向Whip Pan甩镜→落定帧已在新位置并完成起手”，禁止无过程硬切消失出现，也禁止用普通推镜假装人物换位。
- 正式输出只能出现自然画面语言，禁止泄露J0、B6、O1、N0、Q等内部族编号、槽位名、规则名或审计过程。
