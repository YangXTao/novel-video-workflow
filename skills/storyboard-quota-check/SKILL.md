# 分镜稿配额自检（v13.1.1 专用）

用脚本把"感觉合规"变成"数字合规"。**只认 v13.1.1 四段式成稿**：

```text
## S01｜戏剧功能词（15秒）
**①画质基准**          ≤250 字
**②角色·场景·核心设定**  ≤400 字
**③时间轴**            每拍 220-280 字，每拍独立成行，行首 00:00—00:02，
**④负面提示词**         ≤300 字
【全局正向词】          …
```

## 何时用

- 每次生成/修改分镜稿之后，出稿前必跑一次（对应 96 号 19.10 最终放行闸、70 号成立硬闸）。
- 用户质疑"是否严格按 v13.1.1 规则执行"时，用输出的数字回答，不要口头保证。
- 压缩、改写、拆分镜头之后重新验收。

## 怎么用

```text
<当前 Codex 可用的 Python> <本 Skill 的 scripts/quota_check.py> \
  <分镜稿路径> [<更多路径>] [--max15 N] [--dur N] \
  --rules <本次校验通过的 xiaojia-prompt-generator/references>
```

- 可一次传多份稿子做对比（例如新旧两版并排看差在哪）。
- `--max15 N`：">10s 镜数量上限"，默认 3。**每换一个项目都要按该项目契约给值**，否则长镜项目会被误报超限。
- `--dur N`：标题没写（N秒）时的兜底项目时长；缺声明会报硬项。
- `--rules DIR`：规则源 `references/` 目录。工作流调用必须显式传入本次已校验的规则源。独立调用未传时依次尝试同一工作流包、`~/.codex/skills/`、`~/.workbuddy/skills/`。
- `--no-verbatim`：关闭 F 段原文覆盖率。
- 退出码：0 全通过，1 有硬项违规，2 文件缺失。

## 判读标准（均出自 v13.1.1 规则源）

| 项 | 规则来源 | 标准 |
|---|---|---|
| 镜数与总时长 | 项目契约（96 号 19.2） | 镜数、总时长须等于用户点名值；每镜声明秒数须等于拍相加 |
| >10s 镜上限 | 用户覆盖项 | 用户点名"15 秒镜最多 N 个"时按 N 校验 |
| ①画质基准 | 铁律54 | ≤250 字；打戏必须含 **11 号 2.1** 画质词原文、文戏必须含 20 号 3.1 原文（铁律1 要求锁死原文、一字不改） |
| ②核心设定 | 铁律54 | ≤400 字；三混合配比%只在此锁一次 |
| ③时间轴 | 铁律4 / 铁律54 | 每拍 220-280 字（打戏）/ 180-240（文戏）；拍相加 = 该镜声明时长 |
| ④负面提示词 | 铁律54 | ≤300 字；v13.1.1 起为两层结构（核心≤10 条＋触发选加≤5 条，合并≤15 条） |
| 字数预算 | 铁律54（v13.1.1 公式制） | 单镜 = ①250＋②400＋③每拍上限×实际拍数＋④300＋⑤正向词100；**总上限＝公式求和值**（旧"全稿≤5000/10s≤1500"已废止）。参考满格：10 秒约 2450-2730、30 秒约 5250 |
| 承接复述 | 铁律46 / 99号12.14 | 非首镜首拍须有"上一镜尾帧复述"（同场景连续段可压成半句）→ `recap` ≥1，首镜应为 0。**v13.1.1 起该字段标签不进正文**，落字形态走 37 号 17.1 承接拍（自然句织入） |
| 图号锚定 | 铁律25 | 每镜都要锚 `@imageN`（各镜独立生成，模型无跨镜记忆）→ `img` 显著大于 0 |
| 尺度四件套 | 铁律19（00号 L223-229） | **凡攻击特效/大招/法术/EWS宏观镜，一句之内四样齐全**：①画框分数占比 ②宏观尺寸量级 ③参照物 ④人物在画框位置——**缺一即废句重写**。G 段用字面代理定位（只查①③两类），不是判定 |
| 运镜标签 | 铁律52（00号 L497）/ 57 + 00号 L99/L100/L138/L270、10号 2.x 复合运镜链表 | **按画质分轨**：打戏镜每个运镜必须绑视觉目标、正文写成 `[视觉目标]`（铁律0.5 L99/L100、铁律20 L270）；**文戏镜不贴标签**（20 号标杆示例明文，走"运镜融合句式"）。铁律52 明列核心 8 个：展规模/跟轨迹/聚焦命中/跟爆发/展结果/聚焦细节/压迫逼近/收束定场；规则源实际用到的运镜目标族 **44 个**；全源标签 **235 个**（v13.1.1；方括号 231 + 纯文本枚举核心目标 4 个）。**写不出目标 = 凑数运镜、删** |

> **这不是固定白名单。** 核心 8 个是固定的目标类型，但规则正文自己就派生到 42 个变体；70 号质检查的是"**有没有绑目标**"（L43/L54：有没有写不出目标的凑数运镜），不是"逐字命中 8 个词"。
>
> 因此脚本 E 段是**偏严的机器代理**：它要求用词在规则源里出现过，能抓"AI 自造词"，但会连带列出合法的非运镜结构标记。所以判读规则是：`跟*/展*/聚焦*` 开头的越界词**计入硬项**（自造目标 = 用词不合规），其余只在 E 段列出、由人判断。
>
> 定性也要分清：**"用词越界" ≠ "凑数运镜"**。越界词往往仍绑了目标，只是词是自造的；真凑数运镜是根本没有目标。
>
> **分轨是本段的另一半（v3.6 新增）**——标签是**打戏专属**要求，规则源实测分布：10 号 64 处视觉目标类方括号、20 号 **0** 处。
> - **打戏侧**（铁律0.5 L99/L100、铁律20 L270、铁律52）：正文每拍写成 `[视觉目标]`；打戏镜一个标签都没有 = **漏绑视觉目标 → 硬项**。
> - **文戏侧**（20 号标杆示例明文"…全部织进 10 秒时间轴，**不贴标签**"）：出现标签反而是噪声 → **软项提示**。
>
> 实测价值：第57章稿 14 镜（打戏 3 / 文戏 11）里，S11/S13/S14 三镜打戏**一个标签都没有**，脚本一次抓出——这类"该有而没有"的漏项比"用词越界"更隐蔽。

## F 段：锁死画质原文覆盖率（专治"没读就编"）

把规则源里的锁死画质原文切成"特征表述"，统计①段里字面命中了多少：

| 轨 | 原文出处 | 特征表述数 |
|---|---|---|
| 打戏 | **`11-打戏B-特效位移拖尾.md` 2.1 的整行画质词**（UE5.5 Path Tracing…）——v13.1.1 的**权威位置**（100 号 21.0.0 第 11 条：「一切『10 号 2.1』字样为历史误引，一律按 11 号 2.1 解析」）。该处是加粗标题下的普通行、**不是围栏块**，故用行匹配 | 23 |
| 文戏 | `20-文戏规则组.md` 3.1 中文版段（高精度3D半写实国漫BJD人偶风…） | 31 |

逐镜取命中率更高的那一轨作为"采用源"，再给章节平均覆盖率。**三类内容会先剔除，否则会把"按规则本不该出现的东西"算成未命中**：Time Ramp 内部参数档位（工程参数零泄漏）、🔴 之后的落稿指令（是写给作者的话，不是画面词）、`[占位符]` 内容。

**判读**：

- **覆盖率低（<60%）= 疑似①段不是从锁死原文派生**（可能没读就编、或自造画质描述）→ 人工核。
- **字面未命中 ≠ 违规**：规则自己要求「落稿压成 2-3 句连贯话、正文不分号罗列长清单」，所以「冷暖对冲」被写成「暖色赤金神火压在冷白高空云海之上」是**正确**的。未命中清单的价值在于**指出该人工核语义的位置**，不是判定违规。
- 参考基线：第57章稿（v13.1.1 规则源）打戏 3 镜 **100%**（23/23）、文戏 11 镜 **100%**（31/31）、章节 **100%**（410/410）；第56章稿在 v13.1.1 规则源下 **97%**（32/33，唯一未命中项 `Kodak胶片颗粒`——新版把该词合并为单一特征表述，①段里插了胶片型号即不命中）。
- 🔴 **F 段只查"漏"、不查"多"**：它统计的是「原文的特征表述有没有出现在①段」，所以①段**多写**了原文没有的内容（例如不该出现的胶片颗粒%或胶片型号）**不会**报未命中。那类问题属**铁律58（成稿零工程参数）**，需人工或按规则判，F 段管不到。

## G 段：尺度四件套（铁律19，脚本唯一能沾到的内容层硬规则）

铁律19 原文：*凡攻击特效/大招/法术/EWS宏观镜，一句之内四样齐全（①画框分数占比 ②宏观尺寸量级 ③参照物 ④人物在画框位置），**缺一即废句重写***。

G 段逐拍统计两类**字面证据**（只覆盖 ①③ 两项，②④ 未纳入代理）：

```
含画框分数/成数 : 33/60 (55%)     ← 识别 占七成 / 占画框过半 / 占右半幅 / 占比 / 千分之一 等变体
含参照物        : 1/60 (2%)
疑似特效拍      : 48（其中含画框分数 25 个 = 52%）
疑点拍（疑似特效/宏观镜但无画框分数）：S01 00:12… 逐条列出，交人工核
```

**判读：只用于定位，不得作为通过/否决依据。** 两个原因：①本项按「拍」统计而铁律19 判据是「句」，一拍含多句时会**低估**覆盖率；②「疑似特效拍」是用特效/动作关键词做的**偏宽**代理，连接性拍也会被算进来（如"镜头沿视线拉回"）。真正要判的是：**这一句是不是攻击特效/大招/法术/EWS 宏观镜**——这是内容判断，脚本做不到。

**用法**：拿 G 段的疑点拍清单逐条过，在 220–280 拍长配额内**替换补足**（不是加字——加字会把拍长顶出上限）。参考基线（第56章）：2026-09-15 稿 52/60 (87%)、参照物 11/60 (18%)；2026-09-16 重制稿 33/60 (55%)、参照物 1/60 (2%)——**同一章两版差异明显，说明这项密度确实会随执行波动，值得每稿都看。**

## 脚本管不到的部分（必须人工/规则审）

脚本只做**可数项**。以下只能靠逐条读规则原文判断，不要用脚本的"0 违规"冒充全合规：

- 运镜动机闸（铁律52/57）：每个运镜是否绑了视觉目标、凑数运镜是否已删、跨段运镜是否查重。
- 戏成立终审（70 号成立硬闸）：打戏势曲线是否可辨、逆转是否同拍三翻转、胜负是否闭环。
- 剧本映射（铁律48）：台词、动作、物件是否逐项映射到镜号。
- 画质基准是否为 11 号 2.1（打戏）/ 20 号 3.1（文戏）原文（脚本只数字数，不比对原文；F 段只证明"由原文派生"，且只查漏不查多）。
- 铁律19 尺度四件套的**句级**"四样齐全"判断，以及**九要素⑨（EWS再证）是否真接在大特效之后**（G/I 段只给字面检出与疑点清单，需人工逐句过）。
- 特效是否真按铁律19/33/38/5 与 12 号 2.9.1 落实（I 段只报"字面有没有"，判不了位置正确性，也判不了"这一镜算不算大特效镜"）。
- 正文是否泄漏内部口径（铁律号、模块名、依赖、规则卡、fps、米数）——脚本不查，需单独扫。

## H 段：②段必备要件与图号一致性

这一段的由来是一次真实事故：②段的「三混合配比%」与「场景五层」被整块删掉（详见文末"已知事故"）。

| 检查 | 规则出处 | 性质 |
|---|---|---|
| ②段含三混合配比%（三项，合计 100%） | 规则源 90/91 号卷首「🔴内部参考说明（铁律58）」：**三层复合体的 `[材质·色]`+三混合% 属 ⚠️级保留项，仅②段锁一次，不是工程参数、禁止误删** | **硬项**（③段含特效时） |
| ②段含场景五层（`地标=`/`地面=`/`光=`/`粒子=`） | 35 号 `16.1 场景五层描述法`：**每场戏开头②段按此五层写全，3–6 行压缩** | **硬项** |
| ③段引用的 `@imageN` 必须②段已定义 | 工作流交接合同 §3（图号本地连续、可追溯） | **硬项** |
| 图号-实体疑似错配 | 铁律25 图号绑定语义（无明文可机械判） | **信息项（启发式）** |

**④ 为什么只能启发式**：S14 事故里 `@image3` 是**定义过的**，只是被用在了错误的实体上（②段 `@image3＝沈青梧`，③段却写 `@image3舰主`）。脚本的做法是：全章收集实体专名（沈青梧/金面舰主/万象鼎/云宫剑/山河地契/十二光轮/咪咪/舰主），凡某图号**后面紧跟**一个不属于它的实体名即提示。**只提示，不判定**——必须人工确认②段映射是否就是该镜真实绑定，再决定改图号还是去掉图号。脚本与总控**都不得直接改写正文**，改动一律交回执行层。

## I 段：特效落实（12号 2.9.1 / 铁律19 / 铁律33 / 铁律5）

**为什么加这一段**：规则源对特效有一整套硬闸，而且**明文规定"用户没提特效时也要自动补"**（12 号 2.9.1「特效自动补全三分支路由」分支C：三混合配比打底 + 从十四大类择优补 1 个匹配补充特效）。但这一整套散落在多份规则里，委派指令与验收清单此前都没提——成稿最容易在这里"功能性带过"。实测第57章 v13.1.1 稿：4 个打戏镜里**时间手法（顿帧/升格/甩镜/爆闪）全为 0、⑨EWS暴拉 0/4**，两个候选巨物镜（含"万丈巨兽抬头"）都缺巨物感三连的②逼近下降与③暴拉超远景。

**逐镜检出的四组证据**：

| 组 | 检什么 | 规则出处 |
|---|---|---|
| 尺度四件套 | ③段是否含：画框分数/成数、宏观量级词、参照物、人物占比 | 铁律19（**缺一即废句重写**） |
| 时间手法 | 顿帧类 / 升格类 / 甩镜类 / 爆闪类 各是否出现 | 铁律11 · 12 号 2.15 |
| 巨物三连 | ①凝聚特写 ②逼近下降 ③暴拉超远景（**仅"打戏镜且标题含巨物词"时判**） | 铁律33（**缺一不可**） |
| 爆点与并行特效 | 轻爆/重爆/核爆画面词；同镜检出的特效现象类数（十四大类） | 铁律5 · 12 号 2.9.1 |

**判读：整段是「字面证据检出」，全部为信息项，不计入硬项/软项。** 三个原因：①"什么算大特效镜/巨物镜"须人工判断（脚本用"打戏镜 + 标题含巨物词"做候选，会把叙事里提到巨兽的镜也纳进来）；②铁律5「每击必爆」有适用边界（纯文戏与对话片不触发），爆点量级为 0 **不等于**违规；③时间手法与 EWS 的**位置正确性**（⑨是否真的接在大特效之后）脚本判不了。

**用法**：看"某项全稿普遍为 ·"。全稿普遍为 · 时，优先怀疑**该镜根本没读到对应规则子节**，连同镜号交回执行层核对——这是本段最大的价值：把"特效一般般"这种感受，变成可定位的具体镜号与缺失项。

**分轨**：攻击特效类硬闸只适用打戏镜（打戏/文戏按①段画质基准分轨，与 E 段同一判据）。

> 判据实现的坑：巨物镜判定用**镜标题**（`title` 字段），不能用 `tag`——`tag` 只保留到"｜"之前的镜号，标题文字会被丢掉，导致命中数恒为 0。与执行层对接的是 `video-prompts-v13/references/output-and-handoff-contract.md` §6「特效落实验收」。

## 实现注意事项

- 在 Codex 中使用当前工作区依赖提供的 Python 或可用的 `python`；不写死其他客户端的解释器路径。
- 稿子可能是 CRLF、段间可能空行 → 脚本已统一换行并容忍空行。若报"四段式缺失或不可读"，先确认段标是否严格为 `**①…**` 这种粗体独立行。
- 拍必须从**行首**开始才会被识别为新拍；若某稿把多拍挤在同一行，拍数会被少算。
- 用 Python 批量改稿时的坑：`re.sub` 用 `(?=...)` 前瞻替换会把换行吞掉、导致拍行合并 → 改完必须按时间码重新拆行并复跑本脚本；另有中文引号与 ASCII 引号混用触发 SyntaxError。
