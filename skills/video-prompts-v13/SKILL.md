# 视频提示词入口 · v13.1.1 规则源委派

## 0. 定位与唯一职责

本 Skill 是**入口与交接层**，不是生成器：

1. 解析并校验规则源（已安装的小家 v13.1.1 skill）；
2. 把工作流的生产输入**原样**交给规则源子任务；
3. 把规则源产出的**唯一**完整章节视频提示词 Markdown 原样接回。

🔴 本文件内不得出现任何分镜创作规则、句法样本、特效库或质检清单。规则一律从安装版 skill 现场读取；把规则复制进本仓库（或任何本地副本）都视为违规，会导致两套规则漂移而失去"严格按 v13.1.1 执行"的意义。

## 1. 规则源定位与校验

按 `references/installed-rule-source.md` 的三步顺序解析路径，读取源 SKILL.md 的 `metadata.version`，必须等于 `13.1.1`（或用户当次明确指定的更高版本）。校验未通过**不得降级**到其他版本的规则源，也不得凭记忆复述规则，直接停机报告。

只读纪律：对规则源只做读取（SKILL.md + 其 `references/` 下被 96 号契约点名的子节）。禁止修改、禁止移入本仓库、禁止改写其措辞、禁止把其内容并入任何中间摘要文件。

## 2. 执行流程（不得跳步）

1. 读取规则源 `SKILL.md` 全文（总控层：双模式、M0–M5、内容类型分流、冲突优先级、输出协议、路由总表）。
2. 按规则源 `references/96-规则执行契约与证据回执.md` 建立本次任务的项目契约、事实账本、缺口账本与**文件+子节依赖清单**。
3. 逐项读取依赖清单里的完整子节（只读标题不算读取完成），包括画质基准原文与内容类型专属规则组。
4. 在规则源的规则下规划分镜、每镜秒数与逐镜正文，按其输出协议落稿（打戏四段式＋正向词袋；文戏按其格式）。
5. 按规则源自身的三层验收与最终收口完成自检（成立硬闸、运镜动机闸、字数与时长闸、跨镜承接）。
6. 只输出唯一完整章节 Markdown 到工作流指定路径；内部状态、规则卡、证据回执、依赖清单一律不入正文。
7. **出稿后强制执行配额自检**（不得跳过）：按 `references/quota-selfcheck.md` 定位并运行校验脚本，硬项非空即返工、改完重跑；把 A–I 各段结果（含结构完整性、硬项/软项分档）随交付说明返回总控。自检结果不写入正文、不落盘为交付物。
8. **交付说明必带三项**（见 `references/quota-selfcheck.md` §4）：①规则源实际路径 + `metadata.version` + SKILL.md 的 SHA-256；②实际读取的 `references/` 文件与子节清单；③A–I 各段自检结果原样。第②项是自报证据，外部不可验证，但强制枚举可压掉"只读标题就落稿"，并供用户定点抽查。

## 3. 输出与下游合同

沿用原入口的下游合同（细则见 `references/output-and-handoff-contract.md`）：默认命名 `<章节名>_完整视频提示词.md`（用户要求时间戳或多版本对比时追加 `_<YYYYMMDD_HHMM>`）、按 S 编号顺序收录全部镜头、逐镜正文完整不得精简、逐镜本地图号从 `@image1` 连续、Seedance 参考图预算与连续性三分类照旧。制作层（`doubao-video-production`）直接按 S 编号从该 Markdown 提取每镜正文，不经过摘要或二次改写。

交付必须附本章配额自检结果（细则见 `references/quota-selfcheck.md`）：**硬项为空**才可交付；软项偏差保留时须在交付说明中逐条披露镜号与实测字数；F 段覆盖率作为信息项报出，未命中清单供人工核语义；脚本不可用时须显式声明「未跑自动自检」，不得声称已按规则自检。交付说明另须带「规则源路径+版本+SHA256」与「实际读取的文件与子节清单」。

## 4. 禁止事项（违反即返工）

- 禁止精简：不得压缩镜头数、时长、正文字数、规则要求的证据项。
- 禁止自创：不得引入规则源以外的写法、模板、字段或"优化版提示词"。
- 禁止替代：不得用总控摘要、资产摘要或图片提示词替代完整正式剧本输入。
- 禁止降档：整章生成默认完整档，篇幅长时继续写入同一 MD，不因篇幅降档。
- 禁止跳读：不得只读规则源 SKILL.md 就落稿，必须按 96 号依赖清单逐项读取。
- 禁止改写上游：不得改动剧本、资产清单、图号约定与用户锁定内容。
- 禁止越权：模型、时长、参考图预算等制作约束由工作流传入，本层不擅自放宽，也不在制作阶段改秒数或改正文。

## 5. 异常处理

| 情形 | 处置 |
|---|---|
| 规则源未安装 / 版本不符 | 停机，报出实际路径与版本，请用户安装或指定规则源路径；不回落其他版本 |
| 规则源 `references/` 缺件 | 停机并列出缺失文件；不得凭残件生成 |
| 用户当次明确要求其他版本规则 | 停机说明：本分支只接 v13.1.1 规则源。历史锁定稿沿用旧产物，不自动追溯重写 |
| 制作层要求改秒数或删参考图绑定 | 不改正文，交回本层重规划受影响镜头 |
| 配额自检脚本缺失或不可运行 | 停机报出解析到的实际路径与失败原因；不得自行新建/复制/改写脚本，不得伪造自检结论，交付说明须写明「未跑自动自检」 |
| 自检报出硬项违规 | 回生成阶段修改并重跑自检，不得交付；不得沿用修改前的通过结论 |
