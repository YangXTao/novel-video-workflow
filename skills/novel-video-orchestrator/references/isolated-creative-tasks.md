# 独立创作任务交接

适用于novel-to-screenplay、character-image-prompts、prop-image-prompts、scene-image-prompts、video-prompts-v13。工作流使用 Codex 独立上下文子 Agent；总控必须先调用 `spawn_agent` 且 `fork_turns="none"` 并取得 Agent ID，不创建新的用户会话。一个创作任务只承担一个现有 Skill，允许其内部按章节继续，不按每镜另造一套规则。执行类 Skill 仍负责浏览器、下载和剪辑，同一浏览器或桌面只允许一个控制者。

## 启动硬门禁

1. 总控在读取素材并开始创作前先启动子 Agent；交接首行写 `[isolated-creative-task:<所属Skill>]`，随后提供 Skill 入口绝对路径、完整输入、用户规格和唯一输出路径。该标记只用于证明当前已位于隔离创作任务，收到标记的子 Agent 直接执行，不再递归派生同类任务。
2. `spawn_agent` 未返回 Agent ID、子 Agent 启动失败或当前环境没有该能力时，本阶段保持未启动或阻断。总控不得自行生成成稿、不得创建占位成稿、不得把主会话直写结果登记为所属 Skill 的正式输出。
3. 总控必须等待该 Agent ID 对应任务完成后再接收产物。启动记录只证明调用路径，不能替代所属 Skill 的自检，也不增加第二个审计任务。

4. 总控只传递所属 Skill 真正需要的完整上游产物、用户规格和输出位置，不给剧情摘要、预写镜头或字数预算。小说转剧本接小说原文；三类图片提示词接完整正式剧本及本类已有设定；视频提示词只接完整正式剧本、上游已有资产清单和时长/模型要求，不扫描目录、不查看图片、不重复审核资产。
5. 子 Agent 读取所属 Skill 及其当前活动规则后直接创作。正常生产不生成逐文件读取范围、额外理解证明或独立审计文件；`video-prompts-v13` 自身要求的规则源标识、依赖清单和配额自检仍按其交付合同执行。
6. 子 Agent 独立创作并按所属 Skill 在内部自检。浏览器、账号额度轮换、下载恢复不进入创作任务；总控不另设创作层或内容审计层。
7. `video-prompts-v13` 的整章生成任务必须使用 workflow.md“视频提示词：完整输入直交”中的固定调用模板，明确完整正式剧本、生成模式、完整档及不因篇幅降档。只产出一个完整章节视频提示词 Markdown，默认命名遵循 SKILL.md，仅在用户明确要求时追加时间戳；不生成逐镜切片、计划、映射、验证、哈希或封存文件。真实图号由视频制作阶段按实际上传顺序和可用尾帧绑定。该任务必须在交付前运行工作流侧配额自检（video-prompts-v13/references/quota-selfcheck.md）并把 A–I 各段结果随交付返回；硬项非空不得交付。
8. 独立上下文是任务隔离，不是文件系统安全沙箱；哈希能发现变化，不能阻止所有任意写入。不得承诺阅读记录或隔离本身能保证文案质量。

## 正常生产与专项测试

正常生产由一个独立创作任务完成本Skill的整章创作和原规则自检；总控只确认目标文件存在，不默认再开审计任务、逐镜审稿、旧稿比较或工具回归测试。发现具体问题才返回原作者修订。

同一创作上下文内规则未变就不反复读取。视频提示词直接写入一个完整章节文件，不等待外部逐镜签收；正常生产不生成阅读审计、不重复运行规则包或工具开发自测。

未绑定图序、等待真实尾帧、待资产适配是自动后续步骤，不等于需要用户审计。已获整章生产授权时，总控安排图片制作Skill先按完整剧本预检并在现有授权内处理资产冲突；制作Skill逐镜确定实际图序、完成显式绑定与提交检查，合格后继续。未来镜头尾帧尚未生成只阻挡其依赖镜，不阻挡无该依赖的已就绪镜。只有超出授权、无法自动消解的创作选择或登录/付费等实际阻塞才请求用户；仅测试/仅文本任务不得擅自开启图片或视频生成。

工具接口：Snapshot -ManifestPath -InputPaths；Read -ManifestPath -Path -ReadLogPath -StartOffset -MaxLines -MaxChars；VerifyInputs -ManifestPath；VerifyReads -ManifestPath -ReadLogPath（素材选读可加RequiredRangesPath，JSON数组含path/startOffset/endOffset，未选中的文件仍要求全文）；Seal -ManifestPath -SealPath -OutputPaths；VerifyOutput -SealPath。偏移为从0开始的UTF-16字符位置，结束位置不包含；适用条目范围需按原Skill选定，范围合格不是路由判断正确的证明。使用前查看实际参数，不能依据旧章节命令猜测接口。
