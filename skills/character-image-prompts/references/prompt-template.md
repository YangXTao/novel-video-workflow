# 人物图片提示词当前唯一模板

本文件中的模板用于每个需要新建或更新的单个人形角色。执行时直接套用，不改变结构顺序，不删减字段，不另行改写成其他版式；所有【占位符】必须根据完整基准剧本、实际可见参考图和用户本次要求逐项替换，不得保留占位符，也不得把示例角色设定写死给其他角色。除非用户本次明确要求，否则不得在模板前后自行追加旧版的UE5、三渲二、3840×2160、quality参数、四分之三侧面或其他画风与版式句式。

灵宠、动物、妖兽和群众类型不强行套用人类五官模板，继续按照 `original-prompt.md` 的对应非人或群体资产规则生成。单个人形角色的负面提示词仍在正面提示词后独立输出，常规角色直接套用固定模板；明确的年龄、体型或正负词冲突必须执行文末“事实优先的局部适配”，该例外优先于固定句不得修改的一般要求。

## 默认奢华服装与特殊情况

无特殊情况下，服装尽可能奢华、精致：在符合当前时代、人物身份和衣服类型的前提下，优先设计高级真实面料、考究剪裁、多层穿搭、精细织纹或刺绣、讲究的滚边包边与缝制工艺、协调的配饰及背面结构；不能只写“奢华精致”四个字，必须落实到模板各层服装的具体材质、工艺、层次和可见细节。现代角色用该时代的高级服饰表达，不强套古装、金冠或仙侠纹样；动物不因此穿人类衣服。

特殊情况优先于上述默认：用户明确要求、实际参考图或已审核造型、原文明示的朴素/贫寒/囚禁服装、制服限制、伪装、丧服及破损战损等，不得擅自改装或抹去对应身份与剧情状态。只有原文未定、没有可用旧造型且不存在上述限制的新设计，才默认向奢华方向补全；不能把普通身份或“未写服装”自动当作必须简陋，也不能仅凭受伤、疲惫或在石室中就推断为囚服。现有可用图片仍按复用规则处理，不因本条自动重制。

不为奢华新增会改变剧情的武器、法宝、门派徽记、文字或超自然材质能力。头饰与配饰协调于服装，不覆盖角色已有固定数量、款式和禁忌。模板结构、正负词完整性、三视图版式及用户降噪段保持不变。

## 事实优先的局部适配（唯一例外，不改变版式或降低细节）

常规成年角色仍完整套用上面的模板。先核对年龄、体型与既有资产；儿童、老人或原文明示特殊体型不得套八/九头身、高腰长腿和成人骨相。仅把不相符的比例与面部/颈部句子替换为该角色年龄和体型相符的完整描述，保留头身协调、结构清楚、正侧背一致、正脸特写及材质光影细节。儿童不添加成人喉结和成人化身材；老人不因“美化版”抹去原文明示的年龄特征；壮硕或矮小人物不被改成长腿纤瘦体型。原文未明确的精确数值属于制作设定，不伪称原文。

负面词逐项核对正面与参考事实：明确有胡须、壮硕肌肉、紧身服装或特殊身高体型时，仅移除直接冲突的“胡须”“肌肉壮汉”“紧身服饰”“矮个子”等对应排除项；其他固定词保持原顺序和完整内容。正面明确要求的姓名与刻度必须保留，禁止的是额外文字及遮挡主体的刻度。不得借局部适配任意缩短负面词或改写整套模板。

信息表可简记“本次适配：原文有胡须，移除冲突排除词”等实际理由；该说明不进入生图Prompt。没有实际冲突则不增加说明。非人模板同样允许规定的名称与刻度，不得在其负面词反向禁止。
