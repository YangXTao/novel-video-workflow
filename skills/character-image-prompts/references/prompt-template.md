# 人物图片提示词当前唯一模板

本文件中的模板用于每个需要新建或更新的单个人形角色。执行时直接套用，不改变结构顺序，不删减字段，不另行改写成其他版式；所有【占位符】必须根据完整基准剧本、实际可见参考图和用户本次要求逐项替换，不得保留占位符，也不得把示例角色设定写死给其他角色。除非用户本次明确要求，否则不得在模板前后自行追加旧版的UE5、三渲二、3840×2160、quality参数、四分之三侧面或其他画风与版式句式。

灵宠、动物、妖兽和群众类型不强行套用人类五官模板，继续按照 `original-prompt.md` 的对应非人或群体资产规则生成。单个人形角色的负面提示词仍在正面提示词后独立输出，并直接套用本文件给出的固定负面提示词模板，只替换最后的角色特定禁忌。

## 输出格式

```text
【独立生图提示词｜复制此段单独生成该角色】

正面提示词：[完整填充上述模板后的连续文本]

负面提示词：[完整填充下方固定负面提示词模板]
```

正面提示词不得出现【】占位符、斜杠候选项或未确定范围。`【58-60】`、`【118-130】`等范围必须根据角色确定为一个具体数值；角色没有明确身高时，结合年龄、身份、体型和参考图选择一个稳定合理的身高，不得反问用户逐个补数值。
