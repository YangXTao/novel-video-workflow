# 角色图片提示词当前执行合同

本文件不替代、不精简、不改写 `original-prompt.md`。成品必须同时满足原始规则和本合同。

## 一、禁止自行精简

- 禁止以避免重复、节省篇幅、提高可读性或角色相似为理由，省略角色总表、复用清单、信息提取表、正面提示词或负面提示词中的必填内容。
- 每个需要新建或更新的角色提示词必须完整自包含；不得写“同上”“参考前一角色”“其余一致”或只输出关键词摘要。
- 原始规则要求的自然语言细节不能改成逗号关键词流，也不能把多个段落合并成一句概括。
- 描述长度由角色真实设定和8段模板决定，不设人为字数上限。

## 二、清点与数量闭环

- 必须先扫描完整剧本，再确定全部实际出场角色、排除纯提及角色、完成同名去重和造型版本判断。
- 总表中的“实际出场角色”“需要输出新提示词”“沿用既有资产”数量必须与逐行清单一致。
- 每个标记为“新建提示词”或“新增造型版本”的资产，必须且只能对应一个完整角色分块。
- 每个标记为“沿用既有资产”的角色只进入总表和复用清单，不得为了凑模板重新输出提示词。

## 三、正负提示词完整性锁

- 单个人形角色必须直接套用 `prompt-template.md` 的完整占位模板：左侧大幅正面面部特写，右侧依次为正面、标准侧面和背面三张完整全身图；左上角标注准确角色名，最右侧使用不遮挡人物的半透明身高比例刻度线。
- 除替换模板占位符和最后的角色特定禁忌外，不得改变模板顺序或自行添加旧版画风、像素、API参数、四分之三侧面等模板外句式；用户本次明确要求的追加内容除外。
- 每个新建或更新的人形角色必须分别输出一段完整自包含的“正面提示词”和一段独立的“负面提示词”。不得再显示第1—8段标题，也不得把负面要求塞回正面提示词。
- 正面提示词必须完整填充模板中的气质、年龄、身高、头身比、腰节、腿长、面部骨相与皮肤、发型发饰、三层服装、鞋履、配饰、禁忌物、正侧背结构、灯光和接触阴影；改成单段不等于允许精简。
- 灵宠、动物和妖兽必须使用对应的非人结构，不得因套模板困难而缩写或省略身体表面、头部、足爪、翼尾等信息。
- 必须把提取表中的相关事实写入正面提示词，不能只在表格里出现、最终提示词中消失。
- 正面提示词不得保留任何【】占位符、斜杠候选项或未确定数值范围，必须将所有变量落成当前角色的具体内容；负面提示词直接套用 `prompt-template.md` 的固定模板，不压缩、不重排，只把【添加角色特定禁忌】替换为当前角色的具体禁忌。
- 负面提示词数量不设固定上限，但每项必须与当前角色或常见三视图错误直接相关，不得照搬与角色无关的示例设定。

## 四、参考图与复用锁

- 只有当前实际可见或用户明确确认可沿用的图片，才能判为可用参考图。
- 已有图且本章外观不变时必须复用；仅修为、身份、任务或情绪改变，不得无依据建立新造型版本。
- 参考图不可读取时如实记录，禁止凭文件名编造图中外观。

## 五、交付前核对

交付前逐项核对：总表数量闭环、每个新资产都有完整信息表、完整正面提示词和独立负面提示词、所有占位符与候选范围均已替换、正负提示词标签明确、没有跨角色省略、没有遗漏剧本明确外观与参考图锚点。还要确认左侧为正面脸部特写，右侧为正面/标准侧面/背面三张完整全身图，四个视图属于同一角色，左上角姓名准确，最右侧身高刻度不遮挡人物，三张全身图脚底与头顶对齐。发现缺项必须补齐后再交付；不能用“篇幅较长”解释省略。

如果聊天消息不足以承载完整成品，应优先把完整内容写入用户指定文件并交付文件，不能改为摘要版。
