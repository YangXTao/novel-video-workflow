# 模块十四萌系喜剧 + 模块十五修仙写实双轨


## 模块十四：萌系/喜剧题材适配

### 14.1 低龄/能力受限角色身体限制系统

> **适用范围声明**：本系统仅适用于萌系/喜剧题材中**剧本明确设定**为低龄/能力受限的角色。严肃打戏中的正常战力角色不适用体力槽（他们按模块二打戏节奏执行，不会打着打着睡着）。能力受限角色参与战斗时，战斗写法按模块十五15.3执行（特效降级+不稳定+可能力竭），喜剧翻车按14.3执行。

当剧本中有幼童/受伤/灵力不足等能力受限角色时，适用以下规则：

**体力槽设定**：
- 能力受限角色有隐性体力槽，每场戏体力有限，不能全程高强度输出。
- 体力下降表现：动作变慢→打哈欠→揉眼睛→站着睡着→当场睡着，必须有渐进过程。
- 施法/战斗后可能直接力竭睡着，形成喜剧节奏（靠谱→突然断电→卖萌）。
- 体力恢复：睡觉/进食/使用恢复道具（由剧本设定具体道具），恢复后可再次爆发。

**身体比例与动作**：
- 低龄角色必须按实际年龄的身体比例设计（头身比、小短手小短腿、走路不稳、够不到高处）。
- 动作必须符合身体能力：跑起来摇摇晃晃、坐下时脚悬空、拿东西用双手抱、爬沙发要手脚并用。
- 禁止低龄角色做出成年人的流畅动作（如帅气转身、单手撑桌、长腿交叠），除非剧情明确是"老祖神识在幼童体内"的反差喜剧——此时可以有0.5秒的老成动作然后立刻被身体限制绊倒。

**常驻道具**：
- 由剧本设定角色的标志性常驻道具（如奶嘴/奶瓶/玩偶/零食等），道具必须跨镜追踪（7.7节）。
- 常驻道具在大部分镜头中出现（手持/放在旁边/嘴里含着），形成角色视觉符号。
- 道具可承载剧情功能（如奶瓶里装特殊灵液、玩偶是法器等），但外观保持日常物品的样子。

### 14.2 喜剧反应：内心小人（仅喜剧/萌系·替代Q版变形）

🔴适用范围：本节规则仅适用于喜剧/萌系题材。非喜剧题材的心声/旁白按铁律14传统写法（闭嘴微表情+旁白/自述音色），不用小人。模态必须在项目契约首次触发时锁定，后续按96号执行契约继承，不得临场重新选择。

改动：喜剧/萌系题材的角色心声/吐槽/内外反差**统一用"内心小人"表现**（规则见3.3.1），不再使用Q版变形表情（头部变大/眼睛弹出/头顶灯泡问号/石化龟裂/下巴掉地等）。

**🔴内心小人三模态（按96号项目契约与用户指定锁定，全剧统一不混用）**：

| 模态 | 呈现方式 | 适用 |
|---|---|---|
| **A 小框模式** | 画面角落浮出独立小框，mini三头身Q版角色在框内表演 | 轻快吐槽向、画面信息量大时（小框不抢正片） |
| **B 实体化模式** | Q版小人**实体化站在正片画面里**——站在真人肩膀上/脑袋旁/场景实物上（桌面/酒杯沿/兵器架/剑坛石头/门楼牌匾等） | 强调"内心戏实体介入现实"的反差喜剧、需要小人与场景实物互动时 |
| **C 混合模式** | 同剧内小框与实体化按场景切换（如激烈对话用小框不挡脸、独处吐槽用实体化站实物） | 节奏变化多的喜剧 |

**实体化模式（B）硬性规格**（用户明确确认的规格，比小框更强调"实体存在感"）：
- 小人=**3D三头身Q版**，穿**同款服装**、发型一致、五官Q版简化，掌心大小。
- 站位：站在**真人肩膀上/脑袋旁边/场景实物上**（酒杯沿/桌面/剑坛石头/门楼牌匾/铜镜边框等），与正片场景实物发生物理接触。
- **实体光影**：小人投射**小影子**、被场景光照亮、踩出小脚印（喜剧效果），让观众觉得小人"真的存在于这个空间里"。
- 小人用**该角色自己的音色**开口说话（嘴巴动），说的是内心真实想法。
- **剧中角色看不见小人**，只有观众看得见（打破第四面墙的喜剧特权）。
- 小人出现0.3秒过渡（从画面外跳进/从道具后爬出），消失0.3秒（跳走/缩小淡出）。
- 小人消失后，正片角色**表情切换一次**（如从放空→叹气、从淡定→嘴角抽搐、从黑脸→认命），完成"内心→外在"的情绪回弹。
- 穿模检查：小人脚底与所站实物（肩膀/石头/牌匾）防穿、小影子投射在所站实物表面。

**内心小人四段式（三模态通用）**：
1. **正常铺垫**（1-2秒）：正片角色正常表演，表情在正常范围内。
2. **小人登场**（0.3秒过渡）：小框弹出 或 小人跳进画面站在实物上。
3. **小人表演**（1-3秒）：mini角色做搞笑动作+开口说内心真实想法（角色自己的音色，嘴巴动）。
4. **回弹正片**（0.3秒过渡）：小人消失，正片角色表情切换一次（高冷→嫌弃/淡定→抽搐/暴怒→假笑），继续剧情。

**使用规则**：
- 只用于喜剧反应：震惊/吐槽/翻车/卖萌/得意/害怕/社死/心虚。
- 正剧/打戏/情感戏/严肃台词禁止小人。
- 同一场戏小人不宜过密，频次按当前场景节奏控制；**同一镜头最多1个小人，不叠加**。
- 小人声色=该角色自己的音色（幼童角色配mini幼娃=萌；成年角色配mini版吐槽=反差喜剧）。
- 小人风格全剧统一（统一三头身Q版+同款服装；模态A/B/C选定后全剧不混用），禁止混用多种风格。
- 打戏交锋段禁止小人打断节奏，只能在一击结束后的间隙插入。
- 小人动作要具体（叉腰/抱头/擦汗/指人/画圈圈/捂脸蹲下/抱银子蹦高等），禁只站着说话。

### 14.3 不靠谱能力/召唤翻车系统

当剧本设定角色可以召唤帮手/使用法术但因"太久没用/能力退化"而不靠谱时：

**翻车喜剧节奏五段式**：
1. **自信蓄力**（1-2秒）：角色胸有成竹，帅气施法姿势/口号/结印，特效开始亮起（观众期待）。
2. **期待峰值**（0.5-1秒）：特效达到最大/召唤物即将出现，镜头给角色自信特写。
3. **翻车**（1-2秒）：法术失败/缩水/遗忘/中途熄灭/召唤物状态不对（筋斗云被封号、天眼近视、哮天犬有女朋友叫不来、三昧真火变打火机等）。
4. **冷场**（0.5-1秒）：完全静默，角色懵逼表情（可用夸张Beat），风吹过/乌鸦飞过/ tumbleweed。
5. **吐槽/补救**（1-2秒）：角色自己吐槽或被旁观者吐槽，然后用不靠谱的方式补救。

**召唤物设定规则**：
- 召唤物可以是传说/神话/历史人物，但必须有"现代社畜化"的反差设定（穿现代衣服、用手机、有上班族烦恼、技能遗忘等）。
- 召唤物的不靠谱必须有逻辑（太久没用→忘了/被封号/有私事/设备老化），不能纯随机翻车。
- 召唤物偶尔靠谱一次形成反差（平时不靠谱，关键时刻突然帅一秒，然后立刻又不靠谱）。

### 14.4 混搭语言梗

- 角色可混用外语单词/短句制造反差喜剧（如中文句子里蹦英语单词、古风角色说现代网络用语）。
- 混搭语言必须符合角色设定（老祖闭关万年→偶尔蹦出古代词汇与现代词汇的错位；留学生角色→中英混杂）。
- 台词标注时保留原文，声色不变。
- 混搭频率适度，不能每句都混，笑点会稀释。

### 14.5 单镜人物上限

- 喜剧/日常场景每镜关键人物≤3人（不是固定3人，能少则少）。
- 配角/朋友偶尔只来一两个，避免画面杂乱、观众脸盲。
- 群演/背景人物不计入关键人物，但不能抢戏。
- 多人对话场景用正反打拆分，每镜只聚焦1-2人，其他人在画外或背景虚化。

## 模块十五：修仙+写实混合双轨

> **适用范围声明**：本模块是1.3节双轨制中"混合场景（都市玄幻爆发）"的详细展开，**不替代双轨制**。纯仙侠/玄幻剧全程用修仙版（铁律11/19全尺寸特效+铁律9/26周身气场）；纯都市/现代剧全程用写实版（0.5-1米冷光残影）；只有"日常写实+修仙爆发频繁切换"的混合题材才使用本模块的双态切换。打戏通用规则（模块二/铁律2-16/招式库/运镜五种融合句式/打击感五要素）在能力爆发态中**全部适用**，本模块只规定态切换和能力受限特例，不改变打戏本身的写法。

### 15.1 双态切换总览

当剧本是"现代/日常世界+修仙/超自然元素"混合题材时（都市修仙/修仙者下山/萌娃老祖等），画面在两种状态间切换：

| 维度 | 日常写实态 | 能力爆发态 |
|------|-----------|-----------|
| 特效 | 无超自然特效，纯物理 | 法阵/灵力/法术特效（`references/93-三层复合元素库附录A.md`三层元素） |
| 气场 | 无 | 能力爆发片段按96触发规则在适用功能节拍绑定一个流动态写进动作句（铁律9/26，参数内部化） |
| 画质 | 胶片颗粒+生活质感+自然光 | 同画质+特效光+能量粒子 |
| 运镜 | 手持/斯坦尼康/固定，纪实感 | ACT/FPV/升降，冲击感 |
| 声音 | 环境音+Foley | 环境音+法术音效+低频boom |
| 角色状态 | 正常穿着/无发光 | 灵力雾气/眼睛发光/符文浮现 |

### 15.2 切换信号与过渡

**写实→能力爆发态（触发信号，出现任意一个即切换）**：
1. 角色周身灵力雾气升腾/真气外露
2. 眼睛变色/瞳孔发光/眉心印记亮起
3. 武器/饰品发光，表面浮现符文
4. 周围物体悬浮/地面碎石震起/空气扭曲
5. 法阵在脚下/空中展开
6. 角色台词暗示（"认真了""不再留手""解封"）

**过渡方式（1-2帧，必须有因果）**：
- 灵力雾气从角色身体向外扩散，雾气所过之处画面色彩微调（饱和度微升/对比度增强）
- 法阵从一个光点扩展成完整阵法，光从阵纹中涌出照亮环境
- 眼睛发光特写→拉中景，角色已被气场包围

**能力爆发态→写实态（回落信号）**：
1. 灵力雾气消散/真气收回体内
2. 眼睛恢复正常/符文熄灭
3. 法阵碎裂成光点消散
4. 角色力竭/睡着/主动收功
5. 战斗结束

**过渡方式**：
- 灵力雾气回流身体，最后一丝光从指尖收回
- 法阵碎裂成光粒向上飘散，光粒消散后画面恢复日常色调
- 角色打哈欠→灵力像泄气一样从身上漏走→恢复正常

### 15.3 能力受限角色的爆发态特例

> **铁律11特例声明**：以下特效降级规则**仅适用于剧本明确设定为能力受限的角色**（幼童身体/重伤/封印中/灵力耗尽/修为被废等），且仅在该角色亲自施法时生效。正常修仙角色的打戏仍按铁律11/19全尺寸（上移一档：常规起手70-100米/重击100-160米/终结160-310米/灭世310米以上）+铁律9/26周身气场（半径5-8米）执行，不得滥用降级。召唤物/帮手（如被召唤的神仙）若自身战力正常，其特效按正常修仙版尺寸，不因召唤者受限而降级。

当施法者是幼童/受伤/灵力不足的角色时，能力爆发态特效**降级+不稳定**：

| 项目 | 正常修仙版 | 能力受限版 |
|------|-----------|-----------|
| 法阵尺寸 | 数米至数十米 | 巴掌大到脸盆大，可能只有半个 |
| 法术尺寸 | 攻击起手即70-100米（上移，重击100-160/终结160-310） | 缩小到1-5米，甚至只有一束光 |
| 稳定性 | 稳定持续 | 闪烁/忽明忽暗/中途熄灭/颜色不对 |
| 气场 | 半径5-8米雾气 | 半径0.5-1米微弱雾气，时有时无 |
| 命中效果 | 三层能量爆炸 | 效果缩水（炸个坑/吹阵风/点亮灯泡） |
| 持续时间 | 整场战斗 | 数秒至十几秒，然后力竭 |

**写法要求**：
- 特效仍按`references/93-三层复合元素库附录A.md`三层元素写，但尺寸用"巴掌大""一束""脸盆大小"等相对描述。
- 必须写出不稳定感：闪烁、滋滋声、中途熄灭、颜色偏差、施法者吃力表情（憋红脸/手抖/咬嘴唇）。
- 翻车时按14.3不靠谱能力翻车五段式处理。
- 偶尔靠谱一次：在情感/危机顶点，受限角色短暂爆发出完整规格的法术（1-2秒），然后立刻力竭，形成燃点。

### 15.4 旁观者反应镜

能力爆发时必须穿插普通人/不知修仙者的反应镜头，形成"神仙打架+凡人懵逼"的反差喜剧：

**反应镜类型**：
- **震惊型**：瞳孔骤缩→下巴微张→后退半步→揉眼睛（以为自己看错了）
- **吐槽型**：面无表情→扶额→翻白眼→内心OS吐槽（闭嘴微表情+旁白）
- 难以置信型：眨眼→再眨眼→掐自己→接受现实（或拒绝接受）
- **恐惧型**：脸色发白→后退→躲到障碍物后面→只露出半张脸偷看
- **崇拜型**：眼睛变星星→嘴巴张开→双手握拳→变成小迷弟/小迷妹

**规则**：
- 反应镜走日常写实态画质（无特效），与爆发态的华丽特效形成反差。
- 反应镜在法术爆发后0.5-1秒插入，时长≤1秒，然后切回ACT/FPV/POV沉浸运镜（铁律9），**禁止在连击段/交锋段中间插入反应镜打断节奏**，只能在一击结束后的间隙插入。
- 反应镜用35-85mm中近景/特写，极浅景深奶油散景，聚焦表情。
- 反应镜可以用夸张Beat（14.2）增强喜剧效果。
- 旁观者从"不信→震惊→怀疑→接受→崇拜"的态度转变要有渐进弧线，不能一集就全信了。

### 15.5 混合场景的节奏

- 日常写实态占60%-70%（生活/对话/喜剧/卖萌），能力爆发态占30%-40%（法术/打鬼/召唤）。
- 每次能力爆发态持续不超过20-30秒（受限角色更短），然后回到写实态喘息。
- 爆发态之间至少间隔1-2分钟（连续多个项目契约镜头）的日常戏，避免审美疲劳。
- 季终/高潮可以连续爆发态，但必须有旁观者反应镜和角色力竭回落做呼吸点。
