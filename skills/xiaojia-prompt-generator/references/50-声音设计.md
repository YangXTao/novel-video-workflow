# 模块八·声音设计


## 模块八：声音设计

### 8.1 五层架构

环境音Ambience(持续底噪)：风声/雨声/市集/虫鸣/火焰，同场景连续

动作音Foley(与动作同步误差≤0.1s)：脚步/衣物/呼吸/拔剑/武器碰撞/拳头击中肉体

特效音SFX(起势→爆发→余波三段式)：雷电/剑气/符文嗡鸣/能量爆裂/空间撕裂

音乐Music(情绪驱动，节奏与切镜频率同步)：快切=快节奏，慢镜=慢节奏

静默Silence(0.2-1.0s后必接强烈爆发)：重击蓄力帧/武器交缠僵持/致命一击前/关键台词前/真相揭露瞬间，一场≤2次

### 8.2 打戏声音要点

🔴 静默→爆发：重击/终结前0.15-0.3s所有声音骤停→命中瞬间所有层同时爆发峰值。这是打击感核心。

音画同步：命中帧=音效峰值(金属碰撞/骨肉闷响/法术爆裂)，与震屏同步

法术三段式：起势(低频嗡鸣渐强)→爆发(骤然爆裂/雷鸣/呼啸)→余波(电弧噼啪/能量消散/回响)

物理连锁音效：按连锁顺序同步(碰撞→碎石→尘土→衣袍)

### 8.3 声音转场

J-Cut声音先行(下场景声音提前0.5-1s进入，画面仍在上场景) L-Cut声音延续(上场景声音延续0.5-1s到下场景画面)

### 8.4 标注格式（内嵌时序每段）

(环境音)[描述]→(动作音)[时间点+描述]→(特效音)[起势→爆发→余波]→(音乐)[类型+节奏+对位]→(静默)[触发点+时长+爆发内容]

### 8.5 全局声色锚定系统

#### 8.5.1 角色音色表（项目开局必建）

项目开局时，必须为全剧每个有台词的角色建立音色锚定，格式如下：

| 角色 | 音色描述 | 年龄感 | 特质关键词 |
|------|---------|--------|-----------|
| （角色名） | （如：清亮少年男音/奶糯女童音/低沉磁性男音） | （如：20岁/3岁/40岁） | （如：玩世不恭/软糯/威严） |

- 音色描述由剧本角色设定决定，skill不预设任何具体角色和音色。
- 全剧统一，禁止中途换音色。每镜台词标注必须从表中调用，禁止临场编音色描述。

#### 8.5.2 旁白音色规则

- 旁白音色**由剧情基调决定**（俏皮/沉稳/温柔/冷峻/沙哑/悬疑等），项目开局设定一次，全剧统一。
- 旁白不绑定任何具体角色，可以是独立的第三人称叙述者。
- 🔴角色内心OS/心声有两种模式，项目开局统一选定：
 - **模式A·独立旁白**：所有内心OS由统一旁白音色念出，角色闭嘴微表情。
 - **模式B·角色自述**：角色内心OS由该角色**自身音色**念出（自述式旁白），角色同样闭嘴只有微表情。
 - 两种模式可全剧统一用一种，也可按角色区分（如主角用模式B、配角用模式A），但规则必须开局声明，禁止中途切换。

#### 8.5.3 音画同步铁律

| 声音类型 | 嘴部状态 | 声色来源 | 标注格式 |
|---------|---------|---------|---------|
| 角色开口说话 | 嘴巴动，口型与台词同步 | 角色自身音色表 | [角色名｜声色｜开口] |
| 角色内心OS | 嘴巴紧闭，只有微表情 | 旁白音色或角色自身音色（按模式） | [角色名OS｜声色｜闭嘴微表情] |
| 第三人称旁白 | 画面正常/角色闭嘴 | 旁白音色 | [旁白｜声色｜画面正常] |
| 角色呼喊/尖叫 | 嘴巴大张 | 角色自身音色 | [角色名｜声色｜开口] |

- 禁止角色说话时嘴巴不动，禁止内心OS时嘴巴动。
- 台词物理语速4-5字/秒，单镜台词≤10-12字，长台词跨镜拆分。
- 每镜必须标注所有台词和旁白的声色，禁止只写台词不标声色。

#### 8.5.4 与8.4标注格式的关系

8.4的标注格式`(环境音)→(动作音)→(特效音)→(音乐)→(静默)`是**音效层**标注；8.5的声色标注是**台词/旁白层**标注。两者共存于同一镜中，不冲突：音效层描述环境/动作/特效声音，台词层标注谁在说话、什么音色、嘴巴动不动。最终输出中两者都要写。

#### 8.5.5 每镜声音标注示例

```
00:01-00:03，50mm近景。角色A眉头一挑嘴角微扬，开口说话（嘴巴动），[角色A｜清亮少年男音｜开口]："这不可能。"
00:03-00:05，85mm特写。角色B瞳孔骤缩嘴唇抿紧，内心OS（闭嘴），[角色B OS｜俏皮女声｜闭嘴微表情]：（这人怎么发现的？）
00:05-00:07，35mm中景。镜头缓缓拉远，[旁白｜俏皮女声｜画面正常]：她不知道，这一切才刚刚开始。
```

### 8.6 BGM情绪映射表（文戏/混合叙事必用）

| 情绪 | BGM类型 | 进入/退出 |
|------|---------|----------|
| 紧张/悬疑 | 低频drone+弦乐拨弦+心跳脉冲 | 悄悄混入，爆发点骤停 |
| 悲伤/离别 | 钢琴单音+大提琴/二胡 | 情绪顶点进入，渐弱 |
| 温暖/告白 | 木吉他/钢琴+弦乐铺底 | 靠近段进入，余韵渐弱 |
| 愤怒/冲突 | 低频鼓+铜管/打击乐 | 升级段进入，爆发全频段 |
| 庄严/史诗 | 管弦全奏+合唱+定音鼓 | 蓄力低吟，释放全奏 |
| 平静/日常 | 极简钢琴/氛围pad | 几乎听不见 |
| 恐怖/怪谈 | 不和谐弦乐+金属摩擦+低频嗡鸣 | 大部分静默，Jump Scare前骤停 |
| 喜剧/萌系 | 轻快拨弦/木琴/口哨 | 随笑点卡点 |
BGM铁律：打戏交锋段BGM让位打击音效只在蓄力/余波铺底；BGM必须与静默点配合；禁止全程铺满；古风用民族乐器（古琴/箫/二胡/大鼓/笛子）。

### 8.7 文戏声音要点

①对白优先：台词出现时BGM降一个力度层级②动作音讲故事：只配有叙事意义的动作音（茶杯放下=决定，手指敲桌=不耐烦，剑穗摩擦=手按剑柄）③静默即台词：情绪顶点/真相揭露前0.3-1秒全静默④声画同步点：转身衣袂声/推门门轴声/握拳骨节响/递信纸张摩擦⑤声音转场：J-Cut声音先入/L-Cut余韵延续⑥环境音叙事：紧张时虫鸣消失风声变大，温暖时鸟鸣流水。

### 8.8 声音空间感

①混响匹配空间：大殿/山洞长混响回声，小房间短混响干声，旷野风声+远端回响，雨夜闷响②距离感：远处声音闷+小+高频衰减，近处亮+大+细节丰富；角色走来脚步从小到大从闷到亮③方位感：画外声音从对应方向传来，与视线匹配联动④声音焦点：说话者清晰背景压低，Rack Focus转移视觉时声音焦点跟着转移。

【v12.4新增·环境音随景变压+回声空间绑定】①环境音电平随景别变化：特写时环境音压低到几乎不可闻（突出呼吸/衣物摩擦），中景正常，全景恢复，大远景EWS时环境音为主体、人声变闷变远。②回声绑定空间材质：石室/山洞=长混响硬回声，木屋=短混响软吸收，旷野=风噪+远端稀薄回响，雨夜=整体闷响+雨滴高频。③动作音效链分层时序：复合动作必须写清时序（蹬地碎石摩擦→挥刀破空→命中闷响+骨裂→躯体坠地重物声），禁止只写一个'砰'。④打击音效同步精度：必须在命中帧±0.05秒内出现，禁止提前或延后。
