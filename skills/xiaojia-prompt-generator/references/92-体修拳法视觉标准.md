## 一、运镜模式（7种·纯画面语言，不含时间安排）

### 模式1：EWS史诗建立镜

- **焦段**：14-24mm超广角，全景深从近到远全清晰
- **机位**：战场外极远，与人腰/地面同高或高空俯拍
- **运动**：固定或极缓慢推镜（0.5m/s以内）
- **构图**：角色占画面高度3-8%，渺小如蚁；前景废墟/断壁/废弃载具，中景角色，远景天际线+光源
- **画面描述范式**：`末日废墟城市全景，断桥横跨画面，废弃公交车+汽车，夕阳火烧云，两人分别站在高地遥相对峙`
- **用途**：空间建立、大招规模展示

### 模式2：ECU蓄力特写

- **焦段**：85-135mm长焦，极浅景深背景完全虚化奶油散景
- **机位**：距拳面/手部30-50cm，拳面填满画面60-80%
- **运动**：缓慢推镜（1m/s）
- **构图**：拳面/手部为绝对主体，背景虚焦对手站立（占15-20%），碎石/能量粒子在拳周悬浮
- **画面描述范式**：`拳面极端特写，银白轮廓线高亮，水墨漩涡在拳面极速旋转，浓墨螺旋中心纯白高亮，墨滴飞溅，背景虚焦对手`
- **用途**：蓄力凝聚、大招拳面

### 模式3：侧后中近景跟拍（核心命中帧）

- **焦段**：35-50mm，浅景深背景柔和虚化
- **机位**：出拳方侧后方1-2米，与人胸同高，拳锋→受击方面部/胸口一条斜线贯穿画面
- **运动**：手持轻微自然晃动，随拳锋方向微推（攻击方向=镜头推进方向），命中瞬间机位被冲击波推后0.5-2米+震屏
- **构图**：出拳方在画面左侧（占40%），拳锋延伸至画面右侧受击者（占30%），拖尾从拳臂后方拉出
- **画面描述范式**：`拳锋压着对方面门往后飞，皮肤扯出半透明筋膜，面部肌肉拉丝，血滴弧形飞溅，白色水墨拖尾从拳臂后方拉出，径向模糊四周速度线`
- **用途**：直拳命中核心帧

### 模式4：低角度ORBIT环绕（旋转攻击）

- **焦段**：24mm广角，低于腰部/贴地
- **机位**：围绕旋转动作圆心外侧1-2米，低角度仰拍
- **运动**：ORBIT环绕跟随旋转方向做弧形运动（180°以内），动态模糊拉满
- **构图**：旋转角色在画面中心，腿/拳扫过轨迹形成弧形能量拖尾，受击方在画面边缘后仰/闪避
- **画面描述范式**：`腾空旋转360°右腿水平扫出，白色水墨弧形拖尾，低角度仰拍强化腾空高度，动态模糊拉满，对方后仰闪避`
- **用途**：旋风腿/旋转攻击

### 模式5：中景手持PAN连击

- **焦段**：35-50mm，浅景深背景柔和虚化
- **机位**：战场正前方3-5米，与人胸同高
- **运动**：手持跟拍，每拳一次PAN左右切换（15-30°快速横摇），每拳微震
- **构图**：两人在画面中各占40%，双拳交错，攻击轴线水平
- **画面描述范式**：`双拳交错快速连击，每拳PAN切换，衣摆随动作摆动，拳锋轮廓线交替高亮，地面尘土被脚步带起`
- **用途**：近身缠斗连击

### 模式6：能量波逼近镜头

- **焦段**：35-50mm，浅景深背景柔和虚化
- **机位**：攻击方前方3-5米，攻击方向正对镜头
- **运动**：固定或微后拉，能量从画面一侧向镜头推进并逐渐填满画面
- **构图**：攻击方在画面一侧（占30%），能量波从拳锋向镜头方向扩散（占60-70%）
- **画面描述范式**：`双拳前推，暗红半透明岩浆能量波向前扩散，画面被暗红能量填满，边缘赤红火苗舌状外吐`
- **用途**：反击/法术攻击

### 模式7：WS背影收束镜

- **焦段**：24-35mm，中等景深前后景分层清晰
- **机位**：胜者背后5-8米，与人腰同高
- **运动**：极缓慢后拉（0.3m/s）或固定
- **构图**：胜者背对镜头在画面中心（占15-20%高度），面向破坏场景，身后/前方巨大烟尘蘑菇云（占60%画面），光源从烟尘边缘透出
- **画面描述范式**：`背对镜头站立，风衣衣摆被爆风扯动，地面龟裂，身后巨大灰黑烟尘蘑菇云+余烬飘散，夕阳从烟尘边缘透出暖橙光`
- **用途**：终结余波、胜者孤独感

## 二、打击感四档（命中瞬间画面怎么表现）

### 轻击级（直拳命中面门/试探拳）

| 层级 | 画面表现 |
|------|---------|
| **身体** | 受击部位凹陷3mm+面部肌肉拉丝扯出纹路+头部猛然后仰+血滴/汗珠弧形飞溅 |
| **环境** | 拳风压带起周围尘土碎石2-3米，衣摆头发被风压吹直 |
| **镜头** | 命中瞬间画面轻微过曝提亮对比度拉满持续0.03s+机位微推后0.5米+震屏3% |
| **动态模糊** | 拳臂拖影+轻度径向模糊，速度线不明显 |

### 重击级（直拳命中胸口/核心攻击）

| 层级 | 画面表现 |
|------|---------|
| **身体** | 胸口凹陷+背弓成C型+口中赤红光液飞溅+受击点能量爆裂向外扩散+全身能量粒子飞溅 |
| **环境** | 气浪吹飞碎石尘土5-8米+地面微裂+周围杂物被风压吹飞 |
| **镜头** | 一道白光从碰撞点炸开覆盖50-70%画面+径向形变30%+四周速度线拉满+Bloom峰值+机位被推后2-3米+震屏5%（持续0.06s） |
| **动态模糊** | 径向模糊拉满+四周速度线+拳臂拖尾 |

### 轰飞级（重击后目标飞退）

| 层级 | 画面表现 |
|------|---------|
| **身体** | 身体水平飞出，身后能量拖尾，四肢随惯性摆动 |
| **环境** | 砸地产生坑洞+烟尘柱升腾+碎石飞散，撞墙则墙壁破洞+砖石飞溅 |
| **镜头** | 低角度跟拍飞退（动态模糊70%）→烟尘遮镜转场 |
| **动态模糊** | 水平方向运动模糊拉满+拖尾光带 |

### 终结级（大招/必杀）

| 阶段 | 画面表现 |
|------|---------|
| **蓄力** | ECU拳面特写，水墨漩涡极速旋转（浓墨螺旋中心纯白），法相在身后显现，画面去色转纯黑白水墨风格 |
| **轰出** | 中景低角度，全身弓步发力，拳锋前推，拖尾拉满，法相同步出拳 |
| **爆炸** | 拳气命中产生白橙混合光团→橙红火焰蘑菇云→灰黑烟尘蘑菇云（三层演进），径向模糊+鱼眼畸变 |
| **收束** | WS背影，胜者背对烟尘，衣摆飘动，地面龟裂，余烬飘散，光源透尘 |
| **镜头** | 纯黑0.03s→爆白0.07s+鱼眼畸变15%+三层冲击线+Bloom300%+机位被猛推后猛拉（持续0.1s） |

## 三、色彩与光影标准

### 日常交锋段

- **主光**：暖橙夕阳逆光，高对比硬光，暗部留细节
- **色调**：高精度超写实3D国漫电影风，暖橙+灰褐废墟+角色服装黑白对比
- **氛围**：体积光丁达尔，烟尘弥漫，远处火光点缀

### 大招法相段

- **去色转纯黑白水墨风格**，高对比，浓墨飞白
- 角色和法相都是水墨质感（浓墨勾勒轮廓+飞白笔触填充）
- 法相双目纯白发光
- **铁律**：法相段必须去色转黑白水墨，这是体修大招标志性视觉语言，禁止彩色

### 终结爆炸段

- 白橙混合光→橙红火焰→灰黑烟尘的三层色彩演进
- 爆炸瞬间色彩回归，之后余波段低饱和灰橙

### 余波收束段

- 灰黑烟尘+暖橙光源透尘+低饱和
- 孤独感，余烬飘散

## 四、7:3超宽画幅规范

> 【v13.1 边界】7:3 是本源参考视频的画幅，其构图原则（人物分居左右1/3、上2/3留给天空/法相/烟尘、横向展开）为通用构图经验；实际画幅一律以项目契约为准，契约为16:9横屏或9:16竖屏时继承构图原则、不强制7:3比例。

- **比例**：7:3（比2.35:1电影宽银幕更宽）
- **构图优势**：横向空间感极强，适合两人对峙+远景+能量拖尾水平延伸
- **人物位置**：交锋段两人分居画面左右1/3处，中间留攻击轴线空间；EWS段人物在画面下1/3，上2/3留给天空/法相/烟尘
- **禁止**：人物居中填满画面（浪费宽画幅），垂直方向重要元素（必须横向展开）

## 五、画面描述范式（这个视频怎么用文字描述打戏画面）

### 核心描述原则

1. **拳锋→受击点一条线**：描述直拳时，从出拳方拳锋写到受击方命中部位，贯穿画面
2. **拖尾从拳臂后方拉出**：水墨/能量拖尾永远在攻击方向的反方向（身后），不朝前
3. **命中瞬间三层同步**：身体形变+环境气浪+镜头反应，一句话内写完
4. **径向模糊+速度线**：重击/高速段必须写"径向模糊拉满+四周速度线"
5. **衣摆头发被风压吹直**：拳风压的视觉暗示，每次重击都要有
6. **战损累积**：面部血迹、衣服破口、尘土，逐镜增加不重置

### 常用描述句式

- **直拳命中**：`拳锋压着[部位]往后飞，皮肤扯出半透明筋膜，[面部/胸口]肌肉拉丝，[血滴/能量粒子]弧形飞溅，[水墨/能量]拖尾从拳臂后方拉出，径向模糊四周速度线`
- **重击爆发**：`命中瞬间一道白光从碰撞点炸开覆盖[50-70]%画面，径向形变[30]%，四周速度线拉满，Bloom峰值，[受击方]背弓成C型，[赤红光液]飞溅，气浪吹飞碎石尘土[5-8]米`
- **轰飞**：`身体水平飞出，身后[暗红/水墨]能量拖尾，低角度跟拍，动态模糊[70]%，砸地烟尘柱升腾`
- **大招蓄力**：`拳面极端特写，[水墨]漩涡极速旋转，浓墨螺旋中心纯白高亮，墨滴飞溅，身后[法相]显现，画面去色转纯黑白水墨风格`
- **余波收束**：`背对镜头站立，风衣衣摆被爆风扯动，地面龟裂，身后巨大灰黑烟尘蘑菇云+余烬飘散，夕阳从烟尘边缘透出暖橙光`

### 能量描述范式

- **水墨体修劲气**：`白灰水墨飞白拖尾，主体浓墨→中段飞白拉丝→尾端淡墨晕染，笔触边缘毛糙呈毛笔扫过质感`
- **暗红岩浆能量**：`暗红岩浆在拳面流淌，血管状纹路，边缘赤红火苗舌状外吐，半透明不遮拳`
- **对撞**：`白灰水墨与暗红能量对撞点产生白橙混合光爆炸，径向模糊拉满`

## 六、写实版适配调整

保留以上**运镜模式1-7 + 打击感四档 + 色彩光影 + 画幅 + 描述范式**，仅调整特效规格：
- 水墨拖尾→缩短到1-3米，低饱和半透明，不遮身体
- 暗红能量→降低饱和度30%，附着态不形成巨型光团
- 法相→**禁止使用**（写实版终结级用物理连锁+更大能量漩涡+冲击波表现）
- 爆炸→白橙光团缩小为物理冲击+尘土爆炸，无火焰蘑菇云
- 轰飞距离→8-15米
- 环境破坏→1.5-8米龟裂
- 音爆环→纯物理透明空气层+极淡白色凝结云，无棱镜色散
- 色彩→全程暖橙夕阳，不去色转黑白（法相段不存在）

**写实版适配v12.4机制对齐（与修仙版对等执行）**：
- **场景锚定（铁律42）**：写实版每拍同样必须落在②段已建立的具体地标上，地标取写实道具（铁管/木箱/汽车/油桶/铁丝网/水泥立柱），禁止抽象空间打斗；EWS建立镜（模式1）即写实版的地标建立拍，后续拍必须从已建立地标中取。
- **地标消耗（铁律43）**：写实版地标消耗走物理破坏——汽车撞瘪、铁管弯折、木箱碎裂、油桶滚落起火，当场声明消耗状态且后续镜头继承，禁止"撞完车完好如初"；消耗反馈同样走35号"受击点→形变→碎屑→二次影响"四步。
- **体力环境双曲线（铁律44）**：写实版跨镜头同样追踪体力线（40文件5.3）+环境损耗线（地标消耗进度+场景破坏程度），写实侧环境线以物理损耗为刻度（地面龟裂扩大/可用道具逐拍减少），每场收尾P2核对各自闭环。
- **情绪镜头联动（铁律45）**：写实手持跟拍体系上叠加情绪级细分——碾压方低角度仰拍强化压迫、被碾压方高角度俯拍强化弱势，与写实版"手持跟拍为主"不冲突（手持是题材级默认，情绪联动是叠加修正）。

运镜和打击感画面表现是内容骨架，双版本通用；特效尺寸和法相是规格差异，按双轨制切换；场景锚定/地标消耗/体力环境双曲线/情绪镜头联动是v12.4机制，双版本对等执行、仅地标材质与破坏尺度按轨切换。
