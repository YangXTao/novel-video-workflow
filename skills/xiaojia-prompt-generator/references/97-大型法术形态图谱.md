## 97-大型法术形态图谱

============================================================

# 模块二十·大型法术形态图谱与构成选择（v12.9现行形态卡）

> 定位：本模块把大型法术研究资料转成可调用的设计结构，不复制任何作品的具体镜头、角色、招式、画风或未经逐帧核实的制作事实。它只回答“本场法术属于什么形态、哪几层必须出现、接触后结果如何、哪些内容要进入正文和状态账本”。
>
> 关系：`96`负责本次任务的触发和依赖调度，`95`负责技能的唯一状态接口和跨镜交接，`30`负责法术专属输出与比例尺；本模块负责形态选择和构成分工。三者不能各自建立互相独立的技能状态表。
>
> 触发：只有出现大型范围法术、法阵、领域、巨型法相、能量神兽、群集洪流、天地异象、空间改写，或用户要求完整展示法术构成时启用。小法术、局部情绪特效和普通打击不自动套用本模块。

## 20.1 九类形态选择

先根据剧本事实和技能语义卡选一个主形态；可以有辅形态，但必须说明它服务主形态的哪一部分，不得把互斥形态混成一个无名特效。

| 主形态 | 观众首先读到的东西 | 必须锁定的结构关系 | 常见镜头任务 |
|---|---|---|---|
| 法相/巨掌 | 巨型体态与施法者动作对应 | 施法者动作→巨型结构响应→接触结果 | 证明神性、压迫或守护 |
| 能量神兽/兽形拟态 | 连续脊线和少量辨识部位 | 能量主轴→头/翼/尾等辨识点→转向与消散 | 证明追击、冲锋、穿梭 |
| 立体仪轨/法阵 | 多平面环组、节点和中心轴 | 释放源→节点就位→连接通道→核心→发动 | 证明召唤、封印、蓄力秩序 |
| 剑阵/万兵群集 | 阵眼、节点、通道和攻击走廊 | 节点组织→分层流束→收缩/齐射→回收或残留 | 证明围困、封路、齐射 |
| 天地异象/领域 | 天幕、边界和全场规则改变 | 边界建立→远景锚点→局部结构→规则生效→回收 | 证明范围、修为和世界状态改变 |
| 凝核/花形释放 | 压缩内核和分层外壳 | 多源汇聚→核心稳定→外壳打开→冲击扩散 | 证明能量融合和释放前后尺度跃迁 |
| 雷霆天罚 | 天空源头、导引节点和落点 | 天空源头→中继媒介→主雷→接触点→残留灼痕 | 证明天威、贯穿和纵向因果 |
| 群集洪流 | 宏观浪形、中层流束和局部个体 | 集结→分束→接触挤压→绕流/回返→再组织 | 证明群体有方向、有意志、可持续 |
| 空间改写 | 坐标参照、翻折轴和场景分区 | 锚点→轴线→分区变化→裂口/折叠→维持或复位 | 证明领域转换、禁锢或异界 |

### 20.1.1 形态排他判据

- 角色自身巨化/实体法身：继承角色服装、面部锚点、武器和控制关系，走 `4.0.4`。
- 能量拟形：只继承能量轮廓、材质、控制链和消散，不自动获得真实生物的呼吸、鳞片和重量。
- 独立召唤物/巨兽：作为独立单位记录实体材质、重量、惯性、距离、控制关系，走 `4.0.3`及 `95.2.1`。
- 领域异象/环境改写：记录作用边界、空间规则、受影响对象、退出/破域条件和恢复方式，不把领域写成一只巨兽。
- “法相”“金身”“化身”等词无法判定时，采用不改变剧本事实的最小解释，并把待确认点留在内部；不得同时套用互斥类别。

## 20.2 八层构成：每层只承担一个问题

大型法术不是把所有光效叠满，而是按当前镜头任务选择必要层。完整展示或用户明确要求时，按下表逐层检查；普通局部镜头可以合并层，但不能打乱因果。

| 层 | 要回答的问题 | 可落地内容 | 输出/状态位置 |
|---|---|---|---|
| 1 人物锚点 | 谁在施法、什么动作触发 | 姿态、手势、兵器朝向、控制关系 | 角色动作句、技能卡 |
| 2 主体轮廓 | 远处看是什么、范围多大 | 巨掌、兽形、花形、浪头、天幕 | 时间轴主形句 |
| 3 结构骨架 | 它如何立起来、怎样连接 | 环组、节点、剑群、脊线、边界 | 结构建立句、技能阶段 |
| 4 能量核心 | 能量从何来、汇向哪里 | 压缩核、主通道、经络、阵眼 | 聚合/释放句 |
| 5 物质表皮 | 表面是什么材质 | 火、水、金属、墨、冰、岩土及受光方式 | 画质/特效自然句 |
| 6 次级粒子 | 哪里外泄、剥离或消散 | 光屑、火星、花瓣、碎片、雾、残影 | 动态与消散句 |
| 7 环境反馈 | 周围物体怎样被改变 | 受光、风场、波纹、建筑变形、地标损耗 | 场景账本、动作反馈句 |
| 8 镜头与声音 | 观众何时看懂、何时感到重量 | 景别、遮挡、焦点、镜头受力、声场和静默 | 时间轴、声音账本 |

执行边界：

1. 不要求每个镜头同时展示八层；当前镜头只落需要证明的层，其余标记为内部不适用。
2. 大型法术完整演示至少覆盖“人物锚点→主体/结构建立→释放/运动→接触或空间改写→结果→余波”这条因果链；是否用远景、低角或EWS由 `30` 的具体类别和项目契约决定。
3. 主体轮廓、结构骨架和环境反馈优先于装饰粒子；粒子不能遮住释放者、目标和接触点。
4. 技术实现载体不是输出规则。体积、网格、粒子、流体、轨迹等只能作为内部制作思路，除非用户明确要求，不写成视频模型必须识别的软件管线。

## 20.3 大型法术生命周期与节奏旋钮

技能阶段沿用 `95.4`，本模块只补大型法术的构成顺序：

```text
释放源定位
→ 结构建立（节点/轮廓/边界）
→ 核心汇聚或稳定
→ 释放/运动/扩展
→ 接触、对撞或空间改写
→ 结果传播
→ 余波残留与消散/回收
```

大型法术的规模由三个独立旋钮共同证明：

- 结构数量：决定复杂度，必须有组织关系，不能只增加光点。
- 覆盖范围：决定宏观尺度，必须有地貌、建筑、角色或地平线参照。
- 运动速度与停顿：决定力量感，核心收紧可以慢，释放和接触可以突然加速，但必须有动作触发。

旋钮不能互相代替：镜头震动不能代替天气尺度，亮度增加不能代替结构建立，抽象的“毁天灭地”不能代替参照物和环境结果。

## 20.4 接触与破阵结果

遇到法术对撞、护盾、破阵、反制或环境接触，先选一种主结果，再写传播顺序：

| 结果 | 接触瞬间 | 后续必须留下 |
|---|---|---|
| 正面僵持 | 前缘压扁、接缝收窄、两侧泄流 | 地面压力、持续波动、双方控制关系未改变 |
| 偏转/引流 | 路径弯折但形态和颜色连续 | 新落点或反击路线，来源仍可追踪 |
| 穿透护盾 | 命中点凹陷或龟裂，再形成孔洞 | 穿出部分继续前进，盾面缺口保留 |
| 切开法阵 | 节点或连线断裂，相邻层失去连接 | 分区熄灭、断口外泄、未断区域仍有余波 |
| 相互消耗 | 接触面内收或分解，两股攻击同步减弱 | 余光、薄雾或空洞，主攻击不凭空复活 |
| 反弹/回返 | 受力方向改变，载体或施法者承担代价 | 新轨迹、反作用环境、原控制关系是否保持 |

统一环境顺序：**先有接触位置，再有接触传播的形变/碎屑/波纹，最后才有慢速尘雾或余烟。** 不同材质必须产生不同结果：岩石开裂，水面排开，云层卷动，木构件沿受力点断裂，金属留下弯折或热痕。
