# 模块二C·2.6–2.15 动作六要素/运镜/校验/连招/特效十四大类/卡点/写实痛点/音爆环/冲击帧


### 2.6 动作六要素

发起者起手式：角色+服装+锚点+战损+站位+起手+发力链(≥四级)+方向+蓄力时间

动作轨迹：形状+起点途经点终点(含高度)+速度变化+峰值速度(内部估算，输出转破音/极速画面、不写m/s)+武器姿态+移动方式+位移

落点命中：部位+角度+命中刹那+极短顿帧（碎片凝滞+环境声抽空+下一帧爆速）+冲击帧（轻击级过曝/重击级纯白闪帧+速度线/终结级黑白冲击帧+3道黑边+画面鼓成球面，禁止百分比和Bloom）+ACT运镜锁定（命中瞬间镜头凝滞，用画面语言不用秒数）+接触效果

受击反应：防御+反应时间0.15-0.3s+位移+物理反馈+表情+受击连锁

镜头运镜(内嵌，用五种融合句式)：焦段+构图+机位运动+前景交互+焦点+与动作同步关系，攻击段镜头极速甩动，禁止gentle

环境特效：地面(龟裂/碎石飞溅/尘柱升腾)+空气(气浪/音爆环[层数+凝结云+棱镜色散]/热浪/冲击帧[等级+闪帧+速度线，禁止百分比Bloom])+光影(剑光/轮廓光，揉进句子)+粒子(拖尾/火星/涟漪)+材质差异化+ACT运镜(跟随方向+镜头怎么动+命中凝滞+目标保持，用画面语言)

### 2.6.1 运镜方法论与镜头语言（核心输出规范以2.0四段式为准，以下为内部参考补充）

#### 核心理念

运镜不是"镜头1/镜头2"的零散切换，而是**有因果、有惯性、有情绪**的连续视觉叙事。每条运镜必须回答：机位在哪→怎么动→为什么这么动→和动作/特效什么关系→转到下一个镜头的逻辑是什么。此外按6.2.6再回答一问：这一拍是纯三维运镜，还是三维层叠加二维画面层的复合？凡复合必须写明两层"同步还是先后"。

#### 一、焦段跳切节奏（制造张力的核心）

- 🔴 **极端跳切**：18mm超广角 ↔ 50mm中近景 ↔ 75-85mm特写，视野从极宽到极窄极端变化，禁止缓慢变焦
- 🔴 **焦段与情绪绑定**：大场面/建立空间=18mm超广角；交锋/动作=24-35mm；情绪/受力=50mm；细节/武器=75-85mm长焦
- 🔴 **每镜必须标注**：焦段(mm)+机位角度(俯/仰/平)+景别(EWS/WS/MS/MCU/CU/ECU)+运镜方式
- 跳切公式：超广角建立空间→中景交代动作→特写捕捉细节→切回超广角展示规模，循环往复

#### 二、运镜与动作强绑定（运镜内嵌动作）

- 🔴 运镜必须用五种融合句式融进动作句子里（分号同步/镜头先行/镜头被动/运镜路径/括号嵌入），禁止动作写完再集中写运镜，禁止单独列"运镜：XXX"
- 攻击阶段运镜必须swift/whip/极速，禁止gentle/cinematic slow
- 蓄力/对峙阶段运镜缓慢/静止/微推
- 命中瞬间机位锁定+震屏+后挫，与冲击帧/顿帧/音爆环同步触发
- 收招阶段运镜惯性回弹/缓慢拉远

#### 三、机位被动力驱动（后坐力运镜·最有电影感）

| 触发场景 | 机位反应 | 效果 |
|---------|---------|------|
| 重击命中 | 机位被打飞、连滚着后退拍 | 力量感传递 |
| 大招爆发 | 机位被冲击波掀飞、翻滚着拍（整圈用SPIN） | 规模感 |
| 角色极速位移 | 机位迟滞0.3秒，只能拍到光痕/音爆环 | 速度感 |
| 碰撞对轰 | 机位被推开，镜头失焦半帧 | 冲击感 |
| 定格/顿帧 | 机位完全锁死，连震屏都停 | 窒息感 |

写法示例：`机位被冲击波掀得连滚后退`、`机位迟滞0.3秒，只能拍到两道虹暗光痕炸着音爆环往上窜`

#### 四、空间穿越式运镜（沉浸感来源）

- **贴地超音速推进**：镜头几乎擦过地面，前景碎石/沙尘被气流瞬间冲散，硬光在地面拉出锐利长影
- **斜向贯穿穿行**：镜头从角色身侧斜向下高速穿行，穿过对冲弹幕/爆炸层，最终掠至地面
- **沿载体跟拍**：贴光柱外缘高速上冲、沿剑身弧线绕行、贴剑锋第一视角
- **FPV贴背跟拍**：镜头在角色身后贴身跟随，视野边缘露出少量肩部/武器
- **螺旋环绕扩大**：以爆炸群/角色为圆心，高速螺旋环绕并逐步扩大半径
- 🔴 穿越式运镜必须写清：起点位置→穿行路径→终点位置→前景什么东西从镜头哪侧飞过（用画面语言描述速度感，禁止写推进速度m/s）

#### 五、因果转场体系（禁止无逻辑硬切）

| 转场类型 | 写法 | 适用场景 |
|---------|------|---------|
| **能量填屏** | 雷电/黑雾/水浪/冰雾填满画面→下一镜从能量中显现 | 大招爆发/场景切换 |
| **视觉匹配** | 眼中雷光填屏→炸回超广角；剑光擦镜→切武器特写 | 情绪/尺度转换 |
| **擦镜转场** | 剑气/紫焰/红绸/角色身体擦过镜头→利用遮挡切镜 | 动作连续/节奏快切 |
| **冲击波推镜** | 爆炸冲击波推向镜头→镜头被推到新位置 | 碰撞/爆发后 |
| **遮挡转场** | 前景黑岩/残柱/身体遮挡→移开后新场景 | 空间转换 |
- 🔴 每次转场必须写清因果逻辑，禁止"切到""画面切换"等无逻辑表述

#### 六、ACT游戏操控逻辑（双角色对战专用）

- **双目标智能锁敌**：镜头始终将双方保留在画面有效战斗区域内，永不脱锁
- **操作惯性与回弹**：镜头带摇杆控制感，跟拍后有惯性回弹，不是机械跟随
- **全局地图体感**：高空上帝视角时，镜头随炸点小幅全域震动，保持ACT全局地图操控感
- **单人追拍+对手保留**：聚焦一方动作时，另一方始终在画面边缘/背景可见
- 🔴 禁止镜头只追一方导致另一方完全出画（除非剧本明确要求单人镜头）

#### 七、荷兰角使用规范

- **角色分配**：强攻方用负荷兰角(-12°至-18°)，灵动/反击方用正荷兰角(+10°至+15°)
- **回正时机**：终极命中/睁眼掌控/大招释放瞬间，荷兰角迅速回正，象征秩序/掌控
- **使用频率**：高速交锋/失衡/爆发段可用，文戏/稳定段不用，一场打戏约30%-50%镜头使用
- 🔴 禁止连续超过3个镜头使用荷兰角，禁止全程倾斜

#### 八、摄影机规则限制（按场景）

| 场景 | 摄影机规则 |
|------|-----------|
| 群体攻击/万剑 | 只从外部拍完整群体，禁止进入内部/追踪单体 |
| 第一视角POV | 视野边缘露出少量肩部/武器，避免过度眩晕 |
| 定格/顿帧 | 机位完全锁死，震屏暂停，强化窒息感 |
| 结局/收尾 | 绝对无同框特写，只拍胜方背身剪影+环境破坏全景 |
| 大远景EWS | 人物占画面≤8%，用渺小感强化宏大 |
| 特写CU/ECU | 角色面部/武器占画面≥50%，背景虚化 |

#### 九、运镜链完整描述（独立运镜链已删除，运镜全部融进时间轴句子，详见2.0）

每场戏/每段在分镜前必须规划完整运镜链，写清：
```
开场机位→第一次运镜(方式+速度+终点)→转场(因果)→第二次运镜→...→收尾机位
```
示例：`剑锋第一视角穿焰→赤焰擦镜→超高空垂直俯拍公里神剑→随剑高速下压→低位斜侧命中顿帧→数公里外低机位插地→360°赤焰海啸→贴地高速后撤升镜→低位弧绕巨剑→二次下沉→高速升空后拉弧移→大地打开→极高位俯拍炼狱→高位环绕后拉拍万妖坠狱→极高空顶视天地闭合→男主落地→后拉升镜→赤焰凝字`

#### 十、运镜写法铁律

1. 🔴 每镜必须写清：焦段+构图比例+人物占比（同一句）+运镜融进动作句+前景交互，禁止只写"镜头跟随"，禁止f值和摄影机距X米
2. 🔴 运镜必须用五种融合句式融进动作句，禁止动作和运镜分成独立字段，禁止"运镜：XXX"后缀
3. 🔴 攻击阶段运镜必须极速/swift/whip，禁止缓慢
4. 🔴 每次转场必须有因果逻辑（能量填屏/视觉匹配/擦镜/冲击波），禁止无逻辑硬切
5. 🔴 **双人不必始终同框**（参考银尊青霜范本）：双人同框仅用于4种情况——①超广角建立空间（开场/场景转换）②能量对撞（剑气/法术在空中对撞）③极短近身（近身交锋不超过0.3秒）④最终轰飞（终结技命中+飞退）。其余时候用单人追拍/反打/过肩/武器脚步腰胯受力特写，通过画外剑气、背景爆炸、对手攻击在画外产生的风压和碎片来表现对手存在。禁止两人全程站在画面里对打。
6. 🔴 重击/爆发必须有机位被动力反应（后挫/掀飞/迟滞/失焦），禁止机位纹丝不动
7. 🔴 双角色对战镜头必须双目标锁敌（ACT近身对战用；与第5条不冲突：单人追拍时对手可在画外、靠画外风压/碎块暗示），禁止一方完全出画
8. 🔴 结局镜头绝对无双方同框特写，只拍背身剪影+环境全景

### 2.7 十一层逻辑校验

- ①空间(三维坐标+距离更新+Z轴+镜头方位+参照物+三层纵深) ②运动(预备发力跟随回收四阶段+加速度+动量传递+方向连续+重心+幅度力量正相关) ③物理(力传导+碰撞分级+材质差异+能量守恒+重力惯性+反作用力) ④人体力学(六段发力链+关节范围+受击连锁+重心平衡+握持力学+45°卸力80%) ⑤时间(反应时间0.1-0.3s+动作时间幅度正相关+硬直后摇+因果不倒置+升格≤30%+节奏变化) ⑥因果(命中有原因+伤害匹配+状态累积+环境延续+武器双向+翻盘有铺垫) ⑦能量(来源明确+消耗威力正相关+蓄力释放冷却+属性克制+范围精度反比+视觉一致+物理交互) ⑧身体状态(衣物破损累积+血迹动态+体力衰减0-30s满/30-60s轻疲/60-120s中疲/120s+重疲+伤势影响动作+姿势不可逆+表情匹配) ⑨视觉感知(视线引导+多重对比+三层纵深+留白1-2次/场+色彩情绪+动作可读性) ⑩武器道具(属性决定用法+位置追踪+磨损消耗+场景道具延续+可利用+法器规则) ⑪叙事逻辑(每场有目的+动作映射性格+传递信息+转折铺垫+结局影响+情绪节奏对位)

### 2.8 连招编排

轻-轻-重：0.3s+0.3s+0.5s重击+顿帧+震屏，“哒哒——咚！”

轻-重-轻：佯攻0.3s→重击0.5s+顿帧→追击0.3s，“哒——咚！哒”

轻-轻-轻-重：三连0.3s×3→0.6s重击+0.3s顿帧+五级震屏，“哒哒哒——咚！！”

重-轻-重：开局0.5s→补位0.3s→终结0.6s+升格，“咚！哒——咚！！”

攻防转换：防守方破绽(武器震开0.5s空当/脚步踉跄/呼吸紊乱)→进攻方抓住(眼神锐利/重心切换/武器变向/蹬地)→镜头(CU破绽→WHIP眼神→PUSH攻击)

假动作：起手方向≠实际方向→欺骗帧0.2-0.3s→变向加速动态模糊爆发→镜头(进攻方角度→防守方POV错愕→命中CU)

武器交缠：接触0.2s火花顿帧→僵持0.5-1.5s力量对抗肌肉紧绷脚下龟裂可升格→破局0.3s震退转换追击→镜头(CU火花→低角度MS ORBIT→PULL FS)

### 2.9 核心特效定义铁律（参考剑仙水刃/万剑）

AI输出每条打戏提示词时，必须在②段（角色·场景·核心设定）内统一定义、不另立板块：

- ①角色能量形态：写清"是什么+不是什么"，如"红绸仙力=暗红丝绸状千丝万缕流体+金色符纹，不是火焰、不是液体、不是光柱"。禁止只写"红色能量"。
- ②武器特效形态：写清具体材质+结构，如"水系剑气=半透明液态水浪+边缘冰晶碎块+水墨飞白边，高速溅飞水珠，不是纯色蓝光波"。
- ③群体结构：多体攻击写清三维结构，如"五路立体千剑群流=前部宽阔锋线+中部穿插补位+后部追入回填，如高速迁徙鱼群，不是平面剑板/剑墙"。
- ④音爆环（Sonic Boom Ring）：高速突破音障或重击爆发时的可视化冲击波环，必须定义环体层数+厚度+扩散速度+凝结云+棱镜色散，禁止只写"冲击波"。详见2.14音爆环特效规范。
- ⑤冲击帧（Impact Frame）：碰撞/命中/对冲/爆发瞬间的画面处理，必须定义等级（轻击级/重击级/终结级）+闪帧+速度线+镜头反应，用画面语言禁止Bloom百分比和径向形变百分比。冲击帧与顿帧+震屏+音爆环同步触发。详见2.15冲击帧特效规范。
- ⑥ACT运镜（Action Combat Tracking）：单挑中距离交锋段的战斗跟随运镜，必须用画面语言定义档位（轻击=镜头微推微震/重击=镜头甩动跟随被撞震动/终结=镜头猛推后猛拉被冲击波推后飞）+跟随方向+命中凝滞+惯性回弹+目标保持，禁止米数/秒数/百分比。详见6.2.5。
- ⑦颜色锁定：能量颜色与角色属性绑定全剧一致，禁止同角色火球忽红忽蓝。
- ⑧定义位置：必须放在【全局设定】之后、动作轴之前，不得在动作轴中临时改变。

### 2.9.1 通用特效十四大类种类库·六要素成句法·自动补全路由（横切"物理现象层"，与附录A三层材质库正交，打戏/法术/文戏共用）

> 定位与调用关系：附录A管"这个特效是什么属性、什么三层材质、什么三色"（按武器/属性纵切）；本节管"它在物理上呈现成哪一类现象、由什么产生、怎么动、怎么消散，以及剧本没说清时自动补什么"（按物理现象横切）。两者正交叠加、不互相替代：先按附录A/4.1定属性材质与三色，再从下面十四大类选现象形态，最后按六要素熔进该动作分句。本节不是独立板块、不另列清单输出，全部当场演进时间轴自然句（铁律1/9/26），工程参数仍走2.14/铁律19、合规替换仍走模块十二。

#### 2.13 写实类五痛点根治模块（写实版专属；参数为内部参考，输出一律翻译成画面语言，见铁律19）

#### 【核心理念】修仙版靠特效规模撑冲击力，写实版靠物理精度+速度量化+双向反馈撑打击感。两条路线彻底分开，禁止AI把写实打戏拍成慢动作武侠。本模块为写实版强制覆盖，优先级高于通用打戏参数。

#### 痛点一：没有打击感 → 命中四件同步（顿帧+冲击帧+震屏+音爆环，归属2.0打击感体系）

#### 【根因】AI生成写实打戏时，武器/拳头穿过身体像切黄油，没有"撞上去"的重量感。

#### 【全局重击参数·写实版强制·🔴内部参考禁止原样输出·输出翻译成画面语言（铁律19）】

🔴震屏/冲击帧/音爆环等视觉参数输出时必须翻译成画面语言（镜头微震/短促震动/猛然后挫；过曝闪帧/纯白闪帧/双闪球面；气浪瞬间炸开/猛炸扩散数丈），禁止输出百分比/度数/m/s/米数。顿帧/快门/帧率等时间参数保留。
顿帧：轻击0.03s / 中击0.06s / 重击0.1s / 终结0.15s
（顿帧=命中瞬间画面极短定格，表现动能传递，≠慢动作）
冲击帧（含身体形变）：轻击级过曝+拳面/脚掌凹陷3-5mm皮肤波纹 / 重击级纯白闪帧+径向形变+肌肉震颤15Hz / 终结级纯黑→纯白双闪+鱼眼+骨骼传导形变
骨骼传导：命中点→相邻关节→对侧肢体，延迟0.02s逐级传导
震屏分级：肌肉冲击1%位移 / 关节冲击3%+2°旋 / 骨骼冲击8%+5°旋
快门速度：重击1/4000s（凝固瞬间），常规1/2000s
动态模糊：攻击轨迹720°开角，命中瞬间模糊骤降为0（凝固感）
音爆环：高速攻击(>200m/s)1层340m/s半径3-8m / 重击命中/兵刃对撞2层450m/s半径10-15m，纯透明+极淡凝结云+无色散

#### 【写法规范】每击命中必须写「接触→顿帧定格→冲击帧闪白形变→传导→回弹」五步，禁止只写"击中"。

#### 示例：0.12s拳面撞中目标颧骨（CU特写拳面皮肤深深凹陷+颧骨皮肤波纹荡开，顿帧0.06s+冲击帧轻击级过曝）→0.18s动能沿下颌传到对侧颈椎，头部猛地甩向一侧→0.22s拳面回弹，目标鼻血飞溅

#### 痛点二：慢动作太多 → 「升格配额」硬锁 + 速度词密度校验

#### 【根因】AI默认把"有力量感"理解成"慢动作"，写实打戏被拍成MV。

#### 【升格配额·写实版铁律】

每场打戏升格总时长≤1.5秒（写实版进一步压缩）
升格仅用于：①终结技命中瞬间 ②关键格挡的兵刃接触点
升格帧率：120fps（禁止240fps，240fps仅修仙版终结技可用）
升格时长：单次0.15-0.3s，禁止超过0.5s
非升格时段：回到24/30fps基础帧率正常或加速播放（禁固定60fps·铁律8），攻击段播放速率1.2x

#### 【速度词密度校验】（每条提示词自检）：

#### - 10秒动作轴中，速度修饰词（极速/瞬间/猛地/爆发/迅雷/骤然/弹射/暴起）≥8个

- 禁止出现：缓缓/慢慢/徐徐/悠然/从容/不紧不慢（写实打戏零容忍）
- 正向词强制含：Fast Paced, High Speed Motion, Quick Cuts, Rapid Action, Dynamic Movement, Hard Impact, Brutal Force
- 反向词强制含：No slow motion abuse, No sluggish movement, No delayed action, No weak impact, No martial arts dance, No theatrical posing

#### 痛点三：打击速度慢 → 「物理速度锚点」量化写入

#### 【根因】提示词只写"快速挥拳"，AI没有速度参照，生成时按平均速度处理。

#### 【写实类武器/肢体速度锚点表·🔴内部参考禁止原样输出·输出翻译成画面语言（铁律19：瞬间炸开/爆速/快到只剩一道闪光），禁止输出m/s】

拳刺/直拳：峰值12-15 m/s（职业拳击手水平），加速段0.15s
摆拳/勾拳：峰值8-10 m/s，弧线轨迹
横踢/鞭腿：峰值15-20 m/s（胫骨末端线速度）
正蹬/侧踹：峰值8-12 m/s，推力型
短刀/匕首挥砍：峰值18-25 m/s（刀尖线速度）
长剑/太刀挥砍：峰值20-30 m/s（刀尖线速度），拔刀瞬间35 m/s+
长棍/长枪刺出：峰值15-20 m/s
反应时间：人类视觉反应0.2s，肌肉反应0.1s，写实打戏攻防间隔≥0.15s

#### 【写法规范】关键攻击必须标注峰值速度+加速时长，AI据此生成运动模糊强度。

#### 示例：右拳从腰间直线轰出，加速段0.15s、拳速快到破音【目标：左腮】，拳风带起鬓发

#### 痛点四：挥动不真实 → 「六段发力链」+「武器惯性」强制

#### 【根因】AI生成的挥砍是"手臂画弧线"，没有蹬地→转腰→送肩的发力链，武器像没有重量。

#### 【六段发力链·写实版每招必写】

蹬地（后脚承重70%→蹬地发力，地面凹陷/鞋底摩擦）
→转腰（腰部旋转45-90°，衣摆随离心力甩出）
→送肩（肩部前送，背部肌肉绷紧）
→挥臂（手臂沿轨迹加速，肘关节角度变化）
→腕锁（命中瞬间手腕锁定，禁止软塌）
→回收（借反作用力回弹，准备下一击）

【武器惯性参数】
单手剑（1-1.5kg）：挥砍后惯性回弹0.3s，手臂需对抗离心力
双手剑（2-3kg）：挥砍后惯性回弹0.5s，脚步需跟随调整重心
太刀（1-2kg）：拔刀后刀身继续前冲0.1s，纳刀需对抗惯性
长棍（2-4kg）：横扫后棍尾反甩，需双手交错握法调整
匕首（0.3-0.5kg）：几乎无惯性，可连续快速变向

#### 【写法规范】起手式必须包含发力链起点（蹬地/重心转移），收招必须包含惯性回弹，禁止"凭空挥出"。

#### 反例：A挥剑劈向B（无发力链，AI会生成手臂软挥）

#### 正例：A右脚蹬地鞋底在泥地犁出深痕→转腰沉胯→左肩前送→双手握剑沿垂直轨迹下劈、剑势快到破空，命中后剑身因惯性继续下沉一截，A左脚前踏半步卸力

#### 痛点五：没有反馈 → 「双向反馈系统」攻击方+受击方+环境三重

#### 【根因】现有模板只写受击者反应，攻击方和环境没有反馈，显得"打空气"。

#### 【三重反馈·每击必含】

①受击方反馈（2.4受击连锁强化版）：
 胸口→胸腔凹陷2cm→肩后缩→头后仰15°→腰反弓→重心后移→后退1-2步
 腹部→腹肌收缩→身体前屈60°→头低下→膝弯曲→单膝跪
 头部→颈部偏转45°→头部甩动→视线模糊0.2s→脚步踉跄
 腿部→膝盖弯曲→重心下降→身体侧倾→手扶地

②攻击方反馈（新增·写实版核心）：
 拳击：拳面皮肤红肿→指关节发白→手臂回弹2-5cm→肩部微震→重心微调
 脚击：胫骨/脚掌接触面红印→腿部回弹→支撑脚滑动5cm→身体微晃
 武器：兵刃碰撞→虎口震麻→武器震颤0.2s（高频微颤）→双手握法微调→脚步调整
 重击后：攻击方有0.1-0.2s硬直（动能释放后的恢复间隙），禁止无限连

③环境反馈（新增·根据场景）：
 室内：家具位移/碎裂，墙面凹陷，灰尘震落，灯具摇晃
 室外：地面龟裂/脚印，草木折断，碎石飞溅，水面涟漪
 金属环境：火星飞溅，金属凹陷，共振嗡鸣0.3s
 雨/雪场景：雨滴被拳风/剑气排开形成真空带0.1s

#### 痛点六：高速攻击无空气反馈 → 「写实版音爆环」物理空气压缩可视化

#### 【根因】写实打戏中高速挥拳/拔刀/兵刃对撞时，AI只画动作本身，没有空气被压缩/撕裂的视觉反馈，导致高速攻击看起来"没速度"。音爆环不是修仙特效，是纯物理空气压缩现象——物体突破音速或极速启停时，前方空气被压缩形成可见的密度差环。

#### 【写实版音爆环·触发条件】（满足任一即触发）

- 肢体/武器尖端速度突破音障时，在最前端产生音爆环（影视化写实时高速攻击即可触发弱音爆环，用画面语言描述禁止m/s）
- 重击/终结技命中瞬间，动能释放导致接触点空气急剧压缩
- 兵刃对撞且相对速度>150m/s时，在碰撞点产生双层音爆环
- 极速位移启动/停止瞬间（位移≥20米且加速度>80m/s²）
- 子弹/箭矢等高速投射物初速突破音速时（枪械射击场景）

#### 【写实版音爆环·视觉参数】（与修仙版严格区分，纯物理无能量色彩）

①环体形态：完美圆形透明压缩空气层，环体厚度3-10cm（比修仙版薄），边缘锐利，环体内部空气密度是外部2-3倍呈微弱透镜状，光线穿过有轻微扭曲但无彩虹色散
②凝结云：环体边缘附着极淡白色/灰白色Prandtl-Glauert凝结云，厚度5-15cm，呈絮状，随环体扩散0.2s内完全消散（比修仙版消散快）
③无棱镜色散：写实版音爆环禁止彩虹色散，只有空气密度差导致的轻微光线扭曲和边缘白色凝结云
④层级结构：标准级单层，重击/对撞双层（主环+尾随环，尾随环比主环晚0.05s，厚度为主环1/2）
⑤衰减规律：环体扩散0.2s后凝结云消散，0.3s后环体不可见（比修仙版持续短）

#### 【写实版音爆环·物理参数·量化】

- 扩散速度：340m/s（1马赫，标准级）/ 450m/s（1.3马赫，重击级）
- 持续时间：0.2s（标准级）/ 0.3s（重击级）
- 最大半径：3-8米（标准级）/ 10-15米（重击级/兵刃对撞）

#### 【写实版音爆环·声音设计·按接触类型区分】

音爆环的声音=音爆本体（空气压缩撕裂）+ 接触材质音，两者必须叠加。写实版音效更真实、更短、更干脆，无超低频震撼（写实版没有法术能量）：

**①金属对金属（剑剑/刀剑/枪剑/刀盾）**
- 音爆本体：低频boom（35-55Hz）+ 高频金属撕裂（5-8kHz），持续0.08-0.12s
- 接触材质音：尖锐金属"铿——"，带高频泛音，金属共振0.2s
- 复合："铿——轰！"，金属声在前0.02s，音爆滞后0.01s叠加

**②金属对肉体（剑劈身/刀斩肢/匕首刺）**
- 音爆本体：低频boom（40-60Hz）+ 中频撕裂（2-4kHz），持续0.1-0.15s
- 接触材质音：肉体闷响"噗"+骨骼"咔"+鲜血"嘶"
- 复合："噗——轰！咔！"，穿透类加"噗嗤"，斩击类加"唰"

**③肉体对肉体（拳拳/脚踢/肘击）**
- 音爆本体：低频厚重boom（30-50Hz）+ 肌肉撞击（100-250Hz），持续0.12-0.2s
- 接触材质音：肌肉"咚"+皮肤"啪"+内脏"嗡"
- 复合："咚——轰！"，厚重低沉，重击加骨骼"咔啦"+呼气"哈"

**④肉体对金属（拳砸剑/脚踢枪/掌拍刀）**
- 音爆本体：低频boom（35-55Hz）+ 金属震颤（1-3kHz），持续0.1-0.15s
- 接触材质音：拳肉"咚"+金属"嗡——"+指骨"咔"
- 复合："咚——嗡！轰！"，弹开类加"叮"脆响

**⑤武器对地面/环境（剑劈地/棍砸墙/脚跺地）**
- 音爆本体：低频boom（30-50Hz）+ 地面传导（60-180Hz），持续0.15-0.25s
- 接触材质音：岩石"咔嚓"+碎石"哗啦啦"+尘土"噗"
- 复合："轰——咔嚓！哗啦啦！"

**⑥拔刀/收刀**
- 音爆本体：中频撕裂（3-5kHz）+ 低频boom（40-60Hz），持续0.06-0.1s
- 接触材质音：出鞘"唰——"+摩擦"铮"+刀镡"咔哒"
- 复合："唰——铮！轰！"

**⑦枪械/投射物**
- 音爆本体：高频撕裂（5-9kHz）+ 低频boom（45-65Hz），持续0.05-0.08s
- 接触材质音：枪口"砰"+子弹"嗖"+弹壳"叮铃"
- 复合："砰——嗖！"，命中加"噗"/"叮"

**通用规则：**
- 与静默→爆发配合：重击前0.1s全静音→命中瞬间音效峰值
- 音画同步：音爆环视觉第1帧=音效峰值，误差≤0.02s
- 禁止：音爆环无声/所有接触用同一个boom/声音与材质不匹配/音画不同步

### 2.14 音爆环特效规范（高速突破音障可视化·双轨制）

#### 【双轨制区分】

音爆环分修仙版和写实版两套参数，AI根据双轨制判定自动调用：
- **修仙版**：有能量色彩+棱镜彩虹色散+多层环+大半径（5-50米）+长持续（0.3-0.8s），配合剑气/法术/终极技使用。详见下文参数。
- **写实版**：纯物理透明空气压缩+极淡白色凝结云+无棱镜色散+单层/双层+小半径（3-15米）+短持续（0.2-0.3s），配合高速拳脚/兵刃/枪械使用。详见2.13痛点六「写实版音爆环」。
- **混合场景**：从写实过渡到修仙时，前半招用写实版音爆环（透明无色散），命中瞬间叠加修仙版音爆环（能量色彩+色散）。

#### 【核心理念】

🔴【内部参考禁止原样输出】以下音爆环规格表（m/s/米/cm）仅供AI理解等级差异，输出时必须翻译成画面语言（铁律19翻译表：瞬间炸开/猛炸扩散数丈/气浪环形炸开扩散数十丈），禁止输出m/s/米数。

音爆环（Sonic Boom Ring）是物体/剑气/肢体突破音障（>340m/s）或重击爆发瞬间产生的可视化冲击波环。不是模糊的"气浪"或"冲击波"，而是有精确物理参数的环形压缩空气层——环体是高密度空气透镜，边缘有Prandtl-Glauert凝结云，光线穿过时产生棱镜彩虹色散（修仙版）。音爆环必须与攻击速度、等级严格匹配，禁止所有攻击都套同一个环。

#### 【触发条件】（满足任一即触发，禁止无理由出现·修仙版+写实版共用）

- 剑气/刀气/枪气尖端速度突破340m/s（1马赫）时，在最前端产生音爆环（修仙版为主，写实版高速兵刃>200m/s触发弱环）
- 极速位移启动/停止瞬间（修仙版位移≥50米且加速度>100m/s²；写实版位移≥20米且加速度>80m/s²）
- 重击/终结技命中瞬间，动能释放超过阈值（双轨共用，参数按版本区分）
- 所有高速接触均触发音爆环（修仙版核心规则，不限于拳对拳）：
 - 金属对金属：剑剑对撞/刀剑交击/枪剑格挡/刀盾碰撞，相对速度>200m/s
 - 金属对肉体：剑劈中身体/枪刺中躯干/刀斩中肢体，武器速度>250m/s
 - 肉体对肉体：拳拳对轰/脚踢躯干/肘击头部，肢体速度>200m/s
 - 肉体对金属：拳砸剑面/脚踢枪杆/掌拍刀背，肢体速度>250m/s
 - 法术对法术：剑气对剑气/火球撞冰墙/雷柱碰风刃，能量初速>340m/s
 - 法术对金属/肉体：剑气劈中武器/火球砸中盾牌/雷柱击中身体
 - 武器对地面/环境：剑劈地面/枪砸岩石/刀斩石柱，武器速度>300m/s
- 兵刃对撞且相对速度>200m/s（修仙版）/ >150m/s（写实版）时，在碰撞点产生双层音爆环
- 法术爆发（火球/雷柱/冰锥）初速度突破音速时（仅修仙版）
- 子弹/箭矢等高速投射物初速突破音速时（仅写实版，枪械射击场景）

#### 【视觉参数·五要素】（以下为修仙版参数，写实版详见2.13痛点六）

①环体形态：完美圆形/半球形透明压缩空气层，环体厚度5-20cm，边缘锐利如刀锋，环体内部空气密度是外部3-5倍呈透镜状
②凝结云：环体边缘附着白色/灰白色Prandtl-Glauert凝结云，厚度10-30cm，呈絮状/棉絮状，随环体扩散逐渐消散
③棱镜色散：光线穿过高密度环体时产生彩虹色色散（红→橙→黄→绿→蓝→靛→紫），色散宽度5-15cm，在环体迎光面最明显
④层级结构：主环+尾随环，主环最亮最厚，尾随环比主环晚0.05-0.1s出现，厚度为主环的1/2，间距0.5-1米
⑤衰减规律：环体扩散过程中厚度递减、透明度递增，0.3s后凝结云完全消散，0.5s后环体不可见

#### 【物理参数·量化】（以下为修仙版参数，写实版详见2.13痛点六）

- 扩散速度：340m/s（1马赫，标准级）/ 510m/s（1.5马赫，绝技级）/ 680m/s（2马赫，终极级）
- 持续时间：0.3s（标准级）/ 0.5s（绝技级）/ 0.8s（终极级）
- 最大半径：5-10米（标准级）/ 15-30米（绝技级）/ 30-50米（终极级）
- 环体厚度：主环10cm / 尾随环5cm（标准级）；主环15cm / 尾随环8cm（绝技级）；主环20cm / 尾随环10cm（终极级）
- 层数：1层（标准级）/ 2层（绝技级）/ 3层（终极级，主环+2个尾随环）
- 凝结云覆盖：环体边缘100%覆盖（标准级）/ 环体+前方锥形区域（绝技级）/ 整个半球形覆盖（终极级）

#### 【声音设计·音爆声音类型库】（按接触类型区分，禁止所有音爆都用同一个boom）

音爆环的声音=音爆本体（空气压缩撕裂）+ 接触材质音（金属/肉体/法术/环境），两者必须叠加，不能只有boom。AI根据动作轴中的接触类型自动匹配对应音效：

**①金属对金属（剑剑/刀剑/枪剑/刀盾）**
- 音爆本体：低频boom（25-45Hz）+ 高频金属撕裂声（4-8kHz），持续0.1-0.15s
- 接触材质音：尖锐金属铿锵"铿——"，带高频泛音和金属共振嗡鸣0.3s
- 复合效果："铿——轰！"，金属声在前0.02s，音爆boom滞后0.01s叠加
- 多层环：每层间隔0.05s，产生"铿-轰！铿-轰！"连放
- 示例：刀剑交击瞬间，金属尖锐撕裂声+低频boom叠加，周围空气被压缩产生"嗡"的共振尾音

**②金属对肉体（剑劈身/枪刺躯/刀斩肢）**
- 音爆本体：低频boom（30-50Hz）+ 中频撕裂声（2-4kHz），持续0.1-0.2s
- 接触材质音：肉体闷响"噗" + 骨骼碎裂"咔" + 鲜血喷洒"嘶"
- 复合效果："噗——轰！咔！"，肉体闷响在前，音爆boom叠加，骨骼碎裂滞后0.03s
- 穿透类（枪刺/剑刺）：增加"噗嗤"穿透声+空气涌入伤口的"嘶"声
- 斩击类（刀斩/剑劈）：增加"唰"的切割声+血液弧形喷洒声

**③肉体对肉体（拳拳/脚踢/肘击）**
- 音爆本体：低频厚重boom（20-40Hz）+ 肌肉撞击闷响（80-200Hz），持续0.15-0.25s
- 接触材质音：肌肉撞击"咚" + 皮肤拍打"啪" + 内脏震动"嗡"
- 复合效果："咚——轰！"，厚重低沉，比金属对撞更闷更沉
- 重击/终结技：增加骨骼碎裂"咔啦" + 气流从口中喷出"哈"
- 示例：双拳对轰，低频厚重boom+肌肉闷响叠加，周围空气被压缩产生环形气浪声

**④肉体对金属（拳砸剑/脚踢枪/掌拍刀）**
- 音爆本体：低频boom（25-50Hz）+ 金属震颤（1-3kHz），持续0.1-0.2s
- 接触材质音：拳肉闷响"咚" + 金属震颤"嗡——" + 指骨碎裂"咔"
- 复合效果："咚——嗡！轰！"，肉体闷响在前，金属震颤持续0.3s，音爆boom叠加
- 硬接类（拳砸剑面）：金属高频震颤+拳面皮肤撕裂声
- 弹开类（掌拍刀背）：金属"叮"的脆响+音爆boom+武器被弹飞的"嗡"尾音

**⑤法术对法术（剑气对剑气/火球撞冰墙/雷柱碰风刃）**
- 音爆本体：超低频boom（15-35Hz）+ 空间撕裂声（5-10kHz），持续0.2-0.3s
- 接触材质音：能量爆裂"噼啪" + 属性音效（雷=电弧"滋啦"/火=燃烧"呼"/冰=冰晶"咔嚓"/风=呼啸"嗖"）
- 复合效果："轰——！噼啪！"，超低频boom震撼胸腔，能量爆裂声高频刺耳
- 同属性对撞：能量共振"嗡——"持续0.5s，产生频率叠加效果
- 异属性对撞：属性克制音效（火克冰=蒸汽"嘶"+冰晶碎裂；雷克水=电弧"滋啦"+水汽爆裂）
- 示例：两道剑气对撞，超低频boom+空间撕裂+能量粒子爆裂"噼啪"，周围空气被电离产生臭氧味的"嘶"声

**⑥法术对金属/肉体（剑气劈武器/火球砸盾牌/雷柱击中身体）**
- 音爆本体：低频boom（20-45Hz）+ 能量穿透声（3-6kHz），持续0.15-0.25s
- 接触材质音：金属=灼烧"滋啦"+金属熔化"嘀嗒"；肉体=灼烧"焦"+穿透"噗嗤"+焦炭"咔"
- 复合效果："轰——滋啦！"，音爆boom在前，属性灼烧声滞后0.02s叠加
- 防御成功（法术被盾牌挡下）：金属震颤+能量散射"噼啪"+盾牌凹陷"嗡"
- 防御失败（法术击中身体）：穿透声+骨骼碎裂+灼烧+身体被轰飞的气流声

**⑦武器对地面/环境（剑劈地/枪砸岩/刀斩柱）**
- 音爆本体：低频boom（20-40Hz）+ 地面传导闷响（50-150Hz），持续0.2-0.3s
- 接触材质音：岩石碎裂"咔嚓"+碎石飞溅"哗啦啦"+尘土"噗"
- 复合效果："轰——咔嚓！哗啦啦！"，音爆boom+地面碎裂+碎石飞溅三层叠加
- 劈地面：剑入石"嗤"+岩石向两侧裂开"咔嚓"+碎石"哗啦啦"
- 砸地面：枪砸坑"咚"+地面凹陷"嗡"+尘土"噗"+碎石飞溅
- 斩石柱：刀斩石"咔嚓"+石柱断裂"轰隆"+倒地"砰"

**⑧拔刀/收刀（居合道/快速拔刀）**
- 音爆本体：中频撕裂声（2-5kHz）+ 低频boom（30-50Hz），持续0.08-0.12s
- 接触材质音：刀出鞘"唰——"+金属摩擦"铮"+刀镡弹开"咔哒"
- 复合效果："唰——铮！轰！"，拔刀声在前，金属铮鸣滞后，音爆boom在斩击瞬间
- 纳刀：刀入鞘"嚓"+鞘口摩擦"铮"+纳刀完毕"咔哒"

**⑨枪械/投射物（仅写实版）**
- 音爆本体：高频撕裂声（4-8kHz）+ 低频boom（40-60Hz），持续0.05-0.1s
- 接触材质音：枪口爆音"砰"+子弹出膛"嗖"+弹壳落地"叮铃"
- 复合效果："砰——嗖！"，枪口爆音在前，子弹超音速撕裂声滞后
- 命中：子弹入肉"噗"+骨骼"咔"+血液"嘶"；命中金属："叮"+火星"噼啪"+跳弹"嗖"

**通用规则：**
- 与静默→爆发配合：音爆环出现前0.1s全静音→环体扩散瞬间音效峰值→尾随环带次级音效
- 多层音爆环：每层间隔0.05s，产生连续叠加效果（如金属对金属双层="铿-轰！铿-轰！"）
- 音画同步：音爆环视觉扩散第1帧=音效峰值，误差≤0.02s
- 禁止：音爆环出现时没有声音/所有接触都用同一个boom/声音与接触材质不匹配（如剑剑对撞用肉体闷响）/音画不同步

#### 【连锁反应】（音爆环不是孤立特效，必须带物理连锁）

音爆环扩散→吹飞周围尘土/碎石/落叶（半径与环体一致）→地面环形龟裂（环体压过处）→轻量物体被推飞（≤50kg物体位移1-3米）→角色衣摆头发被环体风压吹直

#### 【写法规范·嵌入动作轴】（以下为修仙版写法，写实版写法详见2.13痛点六）

音爆环必须写在触发动作之后，用→连接，格式：`[触发动作]→音爆环[层数]层从[起点]炸出，环壁[薄/厚]、[瞬间鼓开/层层荡开]，边缘白色凝结云+棱镜彩晕，[扩散到哪、多大·画面语言]→[连锁反应]→[音爆音效：接触类型+具体音效]`（不写cm/m/s/半径米）

示例1（剑气触发·金属对肉体）：
`0.1s刀客拔刀斩出一道青蓝色剑气、横贯大半个画面（机位WHIP甩镜跟随剑弧，广角），剑气尖端破音→尖端炸开一圈音爆环、环壁薄而锐利、边缘白汽加一圈细彩晕，身周竹叶被扫成一圈向外平铺→音爆音效：金属对肉体，剑气撕裂空气"唰——"+命中肉体"噗"+低频"轰！"`

示例2（重击触发·肉体对肉体）：
`3.2s拳面命中目标胸口（CU特写拳面陷进皮肉，顿帧0.06s，120fps升格0.2s）→命中点炸出两圈音爆环层层荡开、白汽+锥形汽团+彩晕，环壁扫飞碎石尘土、目标被气浪追加推得连退→音爆音效：肉体对肉体，闷响"咚——"+厚重低频"轰！"+骨骼"咔啦"`

示例3（终极技触发·法术对法术）：
`7.5s万剑归宗爆发、铺满天幕的剑阵漩涡收缩（EWS大远景PULL后拉）→剑阵中心三圈音爆环连放、半球形汽幕盖下+强彩晕，环壁扫过之处碎石尽飞、地面环形龟裂、烟尘柱被压成圆盘→音爆音效：法术对法术，超低频"轰——！"+空间撕裂"滋啦"+能量粒子"噼啪"，三层环间隔0.05s连放`

示例4（兵刃对撞·金属对金属）：
`1.8s刀身与剑刃高速对撞（CU特写接触点火花飞溅，顿帧0.08s，120fps升格0.15s）→碰撞点炸出两圈音爆环、白汽+彩晕，环壁扫飞碎石、两人各被震退半步→音爆音效：金属对金属，尖锐"铿——"+低频"轰！"+金属共振嗡鸣0.3s`

#### 【硬性限制】（修仙版，写实版详见2.13痛点六）

必须：音爆环有触发原因（速度突破音速/重击爆发/所有高速接触含金属对金属/金属对肉体/肉体对肉体/肉体对金属/法术对法术/法术对金属肉体/武器对环境）/环体参数与攻击等级匹配（标准级1层/绝技级2层/终极级3层）/音爆环带凝结云+棱镜色散（禁止纯色光圈）/音爆环带物理连锁（尘土/碎石/地面龟裂）/音爆环有对应声音且按接触类型匹配音效（金属对金属=铿+轰/金属对肉体=噗+轰+咔/肉体对肉体=咚+轰/法术对法术=超低频轰+空间撕裂+噼啪）/音画同步误差≤0.02s
禁止：低速攻击出现音爆环/所有攻击都套终极级3层环/音爆环是纯色发光圈无凝结云无色散/音爆环无物理连锁像贴图层/音爆环持续超过1秒不消散/音爆环扩散速度低于340m/s/写实版出现棱镜色散或能量色彩/音爆环无声/所有接触都用同一个boom/声音与接触材质不匹配（如剑剑对撞用肉体闷响）/音画不同步

### 2.15 冲击帧特效规范（参数为内部参考，输出翻译成画面语言）

#### 【核心理念】

冲击帧（Impact Frame）是碰撞/命中/爆发瞬间那一帧的**画面滤镜+身体形变处理**，不是时间停顿（那是顿帧），不是空气压缩（那是音爆环），不是镜头位移（那是震屏）。冲击帧管的是**那一帧画面本身长什么样+身体怎么形变**——闪白/闪黑/过曝/径向形变/速度线拉满/Bloom峰值/鱼眼畸变+皮肤凹陷/肌肉波纹/骨骼传导。四者（冲击帧+顿帧+震屏+音爆环）在碰撞第1帧同步触发，各司其职，叠加出完整打击感。
#### 【与现有体系的关系·五者分工】

| 机制 | 管什么 | 时间维度 | 视觉维度 |
|------|--------|---------|---------|
| 顿帧 | 时间停顿多久 | 0.05-0.3s画面定格 | 无（只是停住） |
| 冲击帧 | 画面滤镜+身体形变 | 命中第1帧0.03-0.15s | 闪白/闪黑/过曝/径向形变/速度线/Bloom/鱼眼+皮肤凹陷/肌肉波纹/骨骼传导 |
| 震屏 | 镜头位移 | 命中后0.1-0.3s | 画面位移1%-8%+旋转2°-5° |
| 音爆环 | 空气压缩可视化 | 命中第2帧开始扩散0.2-0.8s | 环形压缩空气层+凝结云+色散 |
**同步规则**：碰撞第1帧=冲击帧峰值+顿帧开始+震屏开始+ACT锁定开始；第2帧=音爆环开始扩散+震屏持续；第3-5帧=顿帧结束+震屏衰减+音爆环继续扩散+ACT回弹。禁止四者不同步。
#### 【八大触发场景】（满足任一即触发，按场景自动匹配等级）

| 场景编号 | 触发场景 | 典型描述 | 默认等级 |
|---------|---------|---------|---------|
| ① | 打戏命中 | 拳脚命中肉体/武器斩中身体/武器击中武器 | 轻击→轻击级；重击→重击级；终结→终结级 |
| ② | 兵刃对撞 | 剑剑交击/刀剑碰撞/枪剑格挡/刀盾对撞 | 标准对撞→重击级；力量对抗破局→终结级 |
| ③ | 法术对冲 | 剑气对剑气/火球撞冰墙/雷柱碰风刃/能量对能量 | 同量级对冲→重击级；量级碾压→终结级 |
| ④ | 法术命中 | 法术击中肉体/盾牌/地面/建筑/武器 | 标准级法术→重击级；绝技/终极→终结级 |
| ⑤ | 大招爆发 | 终结技/终极技/必杀技释放瞬间/蓄力完成爆发 | 绝技级→重击级；终极级→终结级 |
| ⑥ | 能量对波 | 双方能量光束/气浪/拳风对推的碰撞点 | 僵持→重击级；一方碾压破局→终结级 |
| ⑦ | 硬接格挡 | 用武器/身体/护盾硬接重击或法术 | 成功格挡→重击级；格挡碎裂→终结级 |
| ⑧ | 落地冲击 | 角色被轰飞落地/高空坠落砸地/重物砸地 | 普通落地→轻击级；高速砸地→重击级；终结砸地→终结级 |
**附加触发**：超音速突破（位移/攻击尖端>340m/s瞬间）触发轻击级冲击帧+音爆环；武器交缠僵持后破局瞬间触发重击级冲击帧。
#### 【三档分级参数表】

| 参数维度 | 轻击级 | 重击级 | 终结级 |
|---------|--------|--------|--------|
| 持续时长 | 0.03s（约1-2帧@基础帧率） | 0.05-0.08s（3-5帧） | 0.08-0.15s（5-9帧） |
| 闪帧类型 | 无闪帧，仅过曝 | 纯白闪帧（#FFFFFF覆盖60-80%画面） | 纯黑帧0.03s→纯白帧0.05s双闪 |

| 速度线 | 无 | 放射状速度线从命中点向四周拉满，长度占画面40% | 3层冲击线从碰撞点扩散（主层+2尾随层），速度线占画面60% |

| 镜头反馈 | 无 | 镜头被冲击波推后0.3米+微震 | 镜头被冲击波推后0.5-1米+剧烈晃动 |

| 配合音爆环 | 无或标准级1层 | 重击级2层 | 终极级3层 |

#### 【双轨制差异】

- **修仙版**：冲击帧可叠加能量色彩（如剑气命中带青色过曝，雷系带紫白过曝），终结级冲击帧可带属性粒子爆发（电弧/火星/冰晶从命中点飞溅），径向形变可带空间扭曲波纹
- **写实版**：冲击帧严格黑白/过曝，禁止能量色彩，闪白帧为真实高光溢出（如金属碰撞火花过曝），终结级双闪为"碰撞黑影→火花白闪"，禁止鱼眼畸变超过10%
- **混合场景**：从写实过渡到修仙时，前半招用写实版冲击帧（黑白过曝），命中瞬间叠加修仙版冲击帧（能量色彩+属性粒子）
#### 【按接触类型的冲击帧细节差异】

**①金属对金属（剑剑/刀剑/枪剑/刀盾）**
- 轻击级：兵刃接触点火花过曝，金属反光瞬间clip
- 重击级：纯白闪帧从碰撞点扩散+火花飞溅呈放射状+金属高频震颤画面微抖
- 终结级：纯黑帧（兵刃接触剪影）→纯白帧（火花爆炸全画面过曝）→冲击线3层+金属碎片飞溅
**②金属对肉体（剑劈身/刀斩肢/枪刺躯）**
- 轻击级：命中点过曝+衣料撕裂碎屑
- 重击级：纯白闪帧+能量/光液飞溅呈扇形+身体形变波纹
- 终结级：纯黑→纯白双闪+命中点光爆+身体被冲击力扭曲+冲击线向外扩散
**③肉体对肉体（拳拳/脚踢/肘击）**
- 轻击级：皮肤接触点过曝+肌肉波纹
- 重击级：纯白闪帧+汗水/能量飞溅+肌肉凹陷形变+皮肤波纹扩散
- 终结级：纯黑→纯白双闪+冲击波可视化（空气压缩纹）+身体严重形变+地面龟裂
**④法术对法术（剑气对剑气/火球撞冰墙/雷柱碰风刃）**
- 轻击级：两种能量接触点过曝+属性粒子混合飞溅
- 重击级：纯白闪帧+能量爆炸从对撞点向外扩散+两种属性粒子交织+空间扭曲波纹
- 终结级：纯黑→纯白双闪+能量湮灭光爆+3层冲击线+对撞点产生真空域+周围物体先被吸向碰撞点再被吹飞
**⑤法术对金属/肉体（剑气劈武器/火球砸盾牌/雷柱击中身体）**
- 轻击级：法术接触点过曝+属性灼烧效果
- 重击级：纯白闪帧+法术能量沿接触面扩散+金属熔化/肉体能量灼伤+蒸汽/电弧
- 终结级：纯黑→纯白双闪+法术穿透/爆炸+盾牌碎裂/身体能量贯穿+大范围属性破坏
**⑥武器对地面/环境（剑劈地/枪砸岩/刀斩柱）**
- 轻击级：接触点过曝+碎石飞溅
- 重击级：纯白闪帧+地面龟裂从命中点扩散+碎石呈放射状飞溅+尘土柱
- 终结级：纯黑→纯白双闪+地面塌陷+冲击波环形扩散+大范围破坏+烟尘柱被压成圆盘
**⑦能量对波（光束对推/气浪对撞/拳风对轰）**
- 轻击级：对推接触面过曝+能量震荡波纹
- 重击级：纯白闪帧+对推点能量累积膨胀+周围空气被压缩+地面环形龟裂
- 终结级：纯黑→纯白双闪+一方碾压破局+能量失衡爆炸+3层冲击线+被碾压方被轰飞
**⑧落地冲击（被轰飞落地/高空坠落）**
- 轻击级：脚底接触点过曝+地面微裂+尘土
- 重击级：纯白闪帧+地面蛛网龟裂+碎石放射状飞溅+角色膝盖弯曲卸力+尘土柱
- 终结级：纯黑→纯白双闪+地面塌陷坑洞+冲击波环形扩散+大范围龟裂+烟尘柱升腾+角色单膝跪地
#### 【写法规范·嵌入动作轴】

冲击帧必须写在命中/碰撞动作之后，用→连接，格式：
`[命中/碰撞动作]→冲击帧[等级]（[闪帧类型]+[速度线]+[镜头反应]，用画面语言禁止百分比和Bloom参数）→ACT运镜[档位]（[跟随方向]+[镜头怎么动]+[命中凝滞]+[惯性回弹]+[目标保持]，用画面语言禁止米数/秒数）→镜头震动[等级]→音爆环[层数]层从[起点]扩散→[连锁反应]→[音效]`
