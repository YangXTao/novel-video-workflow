## 模块一点五：焦段镜头语言提示词指南（全镜通用）

### 1.5.0 核心原理（写提示词前必须理解）

**焦距本身不造透视，拍摄距离才造透视。**

AI只写"24mm广角"时，它只记住了和24mm绑定的视觉特征碎片：宽视野、近大远小、空间拉伸、轻微畸变。但它经常只抽中"宽视野"，没出透视感，画面就"降智"了。

**同景别下（人物大小不变）：**
- 24mm → 摄影机要凑很近 → 近大远小强烈 → 背景更小更远
- 100mm → 摄影机要退很远 → 背景拉到眼前 → 空间压缩

空间压缩/拉伸**不是焦距自带的**，是为了保持画面大小而改变了拍摄距离。

> 🔴 **写提示词铁律（整改）：焦段必须和构图比例、人物占比写在同一句里。** 例如"18mm极端超广角，天地占画面95%，双人极小"——焦段+构图+人物占比一句话写完。禁止只写"24mm广角"不写构图关系。距离用空间关系和前景交互表达（"镜头几乎擦过沙漠表面""前景碎片高速擦镜"），禁止写"摄影机距主体X米"。

### 1.5.2 两个万能公式（剧本未指定焦段时自动匹配）

#### 广角端公式（<50mm，用于大场面/环境建立/冲击感）

```
人物大小不变 + 摄影机[靠近/非常靠近/极度靠近]主体 + 
近大远小[轻微/明显/强烈/极致] + 
背景[更远/更小更远/被推得极小极远] + 
空间[自然延伸/快速延伸/急速延伸/急速收束] + 
(可选)边缘[轻微/明显]透视畸变
```

#### 长焦端公式（>50mm，用于人物特写/情绪聚焦/疏离感）

```
人物大小不变 + 摄影机[远离/极度远离/极远]主体 + 
背景[相对放大/大幅放大/完全压平]并[靠近/紧贴]主体 + 
[轻度/明显/强烈/极致]压缩前景与背景的空间 + 
(可选)景深[较浅/极浅]
```

### 1.5.5 标准提示词镜头语言组装顺序（每镜必按此顺序）

```
1. 焦段+构图比例+人物占比（同一句，如"18mm极端超广角，天地占画面95%，双人极小"）
2. 主体与动作（谁，在做什么）——运镜用五种融合句式融进动作句
3. 前景交互（什么东西从镜头哪侧飞过/被冲散/擦镜）
4. 空间关系（近大远小/空间压缩——从焦段表复制画面描述）
5. 景深效果（从1.5.3景深表复制画面语言，禁止f值）
6. 光线与氛围（揉进动作句，如"硬光在沙面拉出锐利长影"）
7. 画质风格（一行极简：画幅+帧率+渲染风格+材质+光影+尺度，禁止英文工程参数堆砌）
```

### 1.5.6 焦段使用铁律

1. 🔴 **每镜必须写焦段+构图比例+人物占比（同一句）**，如"18mm极端超广角，天地占画面95%，双人极小"，禁止只写"24mm广角"不写构图关系。距离用空间关系和前景交互表达，禁止写"摄影机距主体X米"。
2. 🔴 **同景别不同焦段，空间距离感必须不同**：近景用广角=镜头几乎贴到主体（前景交互强烈）；近景用长焦=镜头离主体极远（空间压缩感强）。禁止写"摄影机距X米"，用前景交互和空间关系表达距离。
3. 🔴 **打戏交锋段优先24-35mm广角+手持/FPV**（临场冲击）；**文戏情绪段优先85-135mm长焦+推镜/环绕**（聚焦凝视）。
4. 🔴 **EWS大远景必须用广角（14-24mm）+全景深**（从近到远全清晰），保证空间层次。
5. 🔴 **人物特写CU/ECU优先85-135mm长焦+极浅景深**（背景完全虚化呈奶油状散景），避免广角近摄导致面部畸变。
6. 🔴 **焦段跳跃制造节奏**：连续镜头焦段差≥20mm（如24mm→85mm→35mm），禁止全程50mm中景（最容易PPT）。
7. 焦距不直接造情绪，它只给观众安排观看位置：广角=参与者，中焦=见证者，长焦=观察者。
8. 铁律：焦段必须和构图比例+人物占比写在同一句里（"18mm极端超广角，天地占画面95%，双人极小"），禁止只写焦段。距离用空间关系和前景交互表达，禁止写"摄影机距主体X米"。禁止f值光圈参数，景深用画面语言（"背景完全虚化呈奶油状散景"/"全景深从近到远全清晰"）。
