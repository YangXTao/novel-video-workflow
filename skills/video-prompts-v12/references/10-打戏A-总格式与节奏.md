# 模块二A·1.5–2.0 衔接/双画质/四段式/时间轴闸/标杆示例


## 模块二：打戏专项（速度感根治）

### 1.5 分镜衔接铁律——每镜开头必须描述上一镜尾帧

🔴红线：每个分镜头都是单独生成的，AI没有跨镜头记忆。因此每镜开头必须用【上一镜尾帧衔接】字段，清晰描述上一个镜头最后一帧的完整状态，本镜从该状态无缝延续。禁止假设AI"知道"上一镜发生了什么。

- ①一镜最后一帧画面：上一镜最后一帧的完整画面状态（角色位置/姿势/朝向/战损/能量/场景破坏/粒子/光源/机位/声音），本镜从该状态无缝延续。

**招式库reference文件调用规则（拆包）**：具体招式参数已拆分为独立reference文件，匹配到武器后必须读取对应文件获取完整参数：
- 剑类武器 → 调用 `文末附录·剑法招式库`
- 刀类武器 → 调用 `文末附录·刀法招式库`
- 枪类长兵 → 调用 `文末附录·枪法招式库`
- 拳/掌/体术 → 调用 `文末附录·拳掌体术招式库` + 文末《视觉标准参考·体修拳法》（体修拳法打戏必须同时读取，前者提供招式参数，后者提供7种运镜模式+打击感四档画面表现+色彩光影标准+画面描述范式）
- 锁链/软兵 → 调用 `文末附录·锁链软兵招式库`
- 法术/施法 → 调用 `文末附录·法术招式库`
- 拔刀术/居合 → 调用 `文末附录·拔刀术居合道`
- 法阵/布阵 → 调用 `文末附录·大型法阵系统`
- 🔴 **所有武器/法术特效的三层复合元素材质定义** → 调用 `文末附录A·三层复合元素标准库`（13种三层复合元素标准库：水墨黑白三层/墨黑三层黑红紫电弧/赤红三层/暗金三层/暗紫三层/紫蓝白三层/金橙黑三层/幽蓝白三层/透翠绿三层/土褐金三层/黑紫金三层/金紫黑三层/暗金白三层。每种元素固定三层结构（主体层+边缘层+表面层），写剑气/刀气/法术时必须从本文件复制对应元素的完整三层材质定义，禁止模型自由发挥颜色和材质。本文件只定义材质颜色，尺寸规模按铁律19尺度四件套输出（画框分数+宏观尺寸+参照物+人物占比）。）

读取后将招式的起手式+发力链+轨迹+速度+命中效果+物理连锁+运镜展开为具体动作描写写入10秒动作轴，最终输出不出现招式名。特效材质必须从文末附录A调用对应三层结构，禁止自编。一镜最后一帧的画面是什么（如"刀客背身站在峰顶残端，衣摆被风吹向左侧，烟尘柱在身后升腾"）。
- ②角色位置：每个角色在画面中的精确位置（左/右/前/后/空中/地面）、姿势（站立/半跪/倒飞/蓄力）、朝向（面朝哪个方向）。
- ③角色状态：战损（衣服破口位置/血量/武器损伤）、表情、能量状态（灵力残余/电弧闪烁/雾气环绕）。
- ④场景状态：环境破坏（坑洞/龟裂/碎石/烟尘）、粒子效果（能量碎屑/雪花/火星）、光源状态（烛火摇曳/劫云翻滚/夕阳角度）。
- ⑤运镜状态：上一镜结尾的机位位置、景别、运镜方向（如"镜头正在匀速后拉，当前为FS全景"），本镜从该机位继续。
- ⑥声音状态：上一镜结尾的声音（如"爆炸声渐弱，留下低频余响+碎石落地声"），本镜声音从该状态延续。

#### 标准写法（每镜开头第一行，替换[X]为具体内容）：

- 【上一镜尾帧衔接】上一镜结尾：[画面状态]。[角色A]在[位置]，[姿势]，面朝[方向]，[战损/表情/能量状态]；[角色B]在[位置]，[姿势]，面朝[方向]，[状态]。场景：[环境破坏/粒子/光源]。机位：[景别+运镜状态]。声音：[声音状态]。本镜从该状态无缝延续。

#### 示例（打戏衔接）：

- 【上一镜尾帧衔接】上一镜结尾：刀客背身站在峰顶残端，衣摆被爆风扯向左侧，银灰长发狂舞，身后黑色大山裂成两半，银红蘑菇云冲天而起，碎石雨持续坠落。刀客在画面左侧峰顶，站立，面朝右侧山脉，月白长袍右袖一道焦痕，嘴角挂着两缕血珠，周身裹着一层薄雾；剑客在画面右侧半空、倒飞中，面朝左下方，左翼羽毛散乱，王冠微斜。场景：峰顶岩石碎裂滑落深渊，烟尘柱冲天而起，暗紫劫云翻滚。机位：EWS大远景，镜头正在匀速后拉。声音：爆炸声渐弱，留下低频余响+碎石落地噼啪声。本镜从该状态无缝延续。

#### 示例（文戏衔接）：

- 【上一镜尾帧衔接】上一镜结尾：白衣男子放下茶壶，目光望向窗外雨景，青蓝女子低头看着茶盏，唇角轻扬。白衣男子在画面左侧木凳，坐姿，面朝右侧女子，月白长袍微皱，眉间剑印微光黯淡，神色放松；青蓝女子在画面右侧木凳，坐姿，面朝左侧男子，冰蓝长裙纱袖垂落，神色带浅笑。场景：木桌中央烛火摇曳，窗外雨丝细密滑落，茶盏两个相对摆放，书架在左侧墙，窗户在右侧墙。机位：MS中景，镜头静止。声音：窗外雨声+烛火噼啪+室内安静氛围音。本镜从该状态无缝延续。

#### 铁律：

- ①每镜（无论打戏/文戏/法术）开头必须有【上一镜尾帧衔接】字段，第一镜写"本镜为开场第一镜，无上一镜，从[初始状态]开始"。
- ②禁止使用"同上""同前镜""延续上一镜"等任何缩写，必须完整重写所有6项状态。
- ③本镜的10秒动作轴必须从【上一镜尾帧衔接】描述的状态开始，禁止凭空出现新状态（如上一镜角色在地面，本镜开头角色突然在空中且没有起跳过程）。
- ④如果两镜之间有转场（硬切/叠化/遮挡），必须在【上一镜尾帧衔接】里写明转场类型，本镜从转场后的状态开始。
- ⑤角色战损、场景破坏、光源角度必须从上一镜继承，禁止重置（如上一镜衣服破了，本镜衣服必须还是破的；上一镜地面有坑，本镜地面必须还有坑）。

### 1.6 双画质分流铁律

- 铁律1：每条提示词必须在【画质基准】字段明确标注【文戏画质】或【打戏画质】，禁止模糊处理。
- 铁律2：文戏镜头绝对禁止出现径向速度模糊、刀刃拖影、背景拉伸等打戏专属效果。
- 铁律3：打戏镜头绝对禁止出现镜头稳定、运镜缓慢克制、f/1.4极浅景深等文戏专属参数。
- 铁律4：文戏用高精度3DCG三渲二（虚拟数字人+PBR材质+SSS次表面散射+柔和漫射光无硬阴影+瓷白通透肤质），打戏用高精度超写实CG电影级渲染（超写实PBR材质，电影级硬光，非低精度游戏CG非平面图），两套风格不可混用。
- 铁律5：文戏主光为柔和漫射光+轮廓光勾勒（用画面语言，禁止光比X:1等参数）；打戏主光为硬主光+法术/武器高光，光影逻辑不可混淆。
- 铁律6：混合戏按时间轴切片，每个10秒容器内只能属于一种戏种，禁止同一镜内文戏打戏画质混用。

### 1.7 静默使用规范

- 铁律1：静默后必须有强烈的声音爆发，不能静默后继续静默（那叫没声音，不叫设计）。
- 铁律2：一场戏静默最多使用2次，滥用会失去冲击力。
- 铁律3：静默时画面不能静止——角色可以有微表情/蓄力动作，只是声音消失。
- 标准用法：重击/对撞/终结技前0.2-0.5秒全静音→命中瞬间全频段峰值爆发→延迟0.5秒→环境音恢复。

### 1.8 玄幻特效五要素转译协议

每个法术/特效必须按五要素转译为具象描述，禁止只写"释放火球""放出雷电"等空泛词：

- ①形态材质：法术是什么形状/什么材质（熔岩球体/冰晶锥体/电弧流体/墨色泼洒），表面纹理是什么。
- ②物理交互：法术与物理世界产生什么交互（热浪扭曲空气/地面熔融/碎石悬浮/树木碳化）。
- ③光影色彩：法术的主色/辅色/高光色/阴影色，对周围环境的光照影响。
- ④粒子流体：法术周围有什么粒子（火星/冰晶/电弧/墨滴/符文/碎屑），粒子的运动方向和密度。
- ⑤镜头反馈：法术出现时镜头怎么反应（镜头被震/被推后飞/推近/后拉/画面鼓成球面，用画面语言禁止Bloom参数）。
- 错误示例："释放火球"（空泛，五要素全无）
- 正确示例："释放熔岩球体（形态材质），高温使周围空气产生热浪扭曲，地面岩石熔融冒烟（物理交互），表面金红色火焰翻涌边缘橙红火苗舌状外吐（光影色彩），火星碎屑向四周飞溅（粒子流体），镜头被热浪推得后缩+剧烈震动（镜头反馈）"

### 1.9 景深参数自动匹配

- 特写CU/ECU：极浅景深，背景完全虚化呈奶油状散景，突出人物表情/武器细节。
- 中景MS/MCU：浅景深，人物清晰背景适度虚化。
- 全景FS/WS：中等景深，人物与环境都清晰。
- 大远景EWS：全景深，整个场景从近到远全部清晰。
- 打戏动作镜头：浅景深，保证动作主体清晰同时背景有适度运动模糊。
- 文戏对话镜头：极浅景深，突出表情，背景柔化。
🔴禁止写f/1.4、f/2.8、f/8等光圈参数，用画面语言描述。

### 1.10 跨集延续规则

- ①造型继承：下集开场角色造型必须与上集结尾一致，变更需宣告【造型变更：V1→V2】并完整描述新造型。
- ②旧造型残留：新造型中必须保留至少1个旧造型元素（同一枚玉佩/同一把剑/同一道疤痕），体现连续性。
- ③场景状态继承：上集结尾的场景破坏（坑洞/火灾/碎石/血迹）必须在下集开场延续，禁止重置。
- ④情绪弧线连贯：跨集开场第一个镜头必须是"情绪延续镜"——1-2秒展示角色当前情绪状态，与上集结尾形成情感衔接。
- ⑤全剧色调演进：全剧色调按四阶段演进——开场（冷调/压抑）→发展（暖调/希望）→高潮（高对比/浓烈）→结局（低饱和/余韵），每集色调必须符合当前阶段。

### 1.11 打戏节奏四铁律

- 铁律1：连续快切最多5镜，必须插入1镜慢镜/静止/全景做呼吸点，禁止全程2秒快切。
- 铁律2：重击/终结技前必须有0.3-0.5秒的节奏放缓（蓄力帧），然后才爆发，禁止从头到尾匀速攻击。
- 铁律3：一场打戏至少有1次攻防转换（不能一方从头打到尾），攻防转换点是节奏反转的关键。
- 铁律4：升格慢动作每场打戏最多使用2次，且必须用在重击/终结技/关键格挡，禁止滥用。

### 1.12 物理状态"嫁接"法则

角色的物理状态必须逐镜"嫁接"——上一镜结束时的姿势/位置/战损/能量状态，必须是下一镜开始时的初始状态，禁止状态重置。

- ①姿势嫁接：上一镜角色半跪在地，下一镜不能突然站立（除非有起身动作过程）。
- ②位置嫁接：上一镜角色被轰飞到左侧撞墙，下一镜必须在左侧墙边，不能回到原位。
- ③战损嫁接：上一镜衣服被划破/受伤，下一镜必须保留同样的破口和血迹，禁止衣服自动修复。
- ④能量嫁接：上一镜灵力耗尽/电弧闪烁，下一镜必须延续虚弱状态，禁止突然满状态。
- ⑤武器嫁接：上一镜武器脱手飞出，下一镜武器必须在飞出的位置，不能突然回到手中。
- 【v12.4新增】⑥服装/发型/道具运动状态嫁接：上一镜衣摆被气浪掀起/发丝贴在汗湿的脸颊/道具被捏碎，下一镜必须延续该运动状态或后果（衣摆仍在飘/发丝仍湿贴/道具已碎不复原），禁止跨镜瞬间重置为整洁静止。

### 2.0 打戏输出总格式（四段式重构·参考0819紫红/0812蓝雷/银尊青霜/万剑/沙漠/剑仙水刃/武打skill七份范本）

> 核心理念：四段式，复制即用。时间轴是唯一核心——镜头怎么动、谁在哪、在打什么、特效什么样、环境怎么炸，全部用自然画面语言揉在句子里，不拆列、不贴标签、不预列清单。开局即战，每击必爆，借反力零空帧，结尾不同框。

#### 【2.0.0 时间轴逐拍过闸（出稿前静默执行·规则通向最终句子的唯一闸门）】
> 时间轴每写一拍，都必须让这一拍从下面十二道闸依次过一遍；该出现而没出现的，当场补进这一拍的自然句，补不进就重写这一拍。闸门只在脑内静默过，成品只见流畅分镜正文，不见编号、打勾、字段或规则说明。

> 【v12.4新增·前置闸·场景锚定】过下面十二道闸之前，先过这一闸：这一拍的动作必须落在②段五层法已建立的具体地标上（铁律42），地标一旦被用必须声明消耗状态（铁律43），禁止抽象空间打斗。场景没立起来的拍，后面十二闸过得再漂亮也打回。

1. **机位先行＋运镜成链（铁律27/37）**：这拍开口先给焦段＋景别＋角度＋机位此刻空间位置＋人物在画框哪侧、占多少，再让动作发生；运镜按起→随→变→落成一条链（每个动作绑视觉目标、被动力只在命中用），这拍落点就是下一拍起手；贴身/混合战先在脑内定这拍属贴身/中距/面状/宏观哪一带、四带交替且不越轴（铁律39）。
2. **力有源头（发力链）**：动作带蹬地/借力点碎裂→转胯→肩→手的传导，衣摆发丝因惯性晚半拍；禁止凭空挥出、滑步飘移；位移必须落在一个具体身法支点上并给支点形变反馈，用秒数＋画框横向占比量化位移（铁律39）。🔴每招必须显式写出攻击者→被击者→【目标：具体部位/兵器关节】（铁律41），禁无对象朝空气出招。
3. **能量先定形（铁律28）**：先判附着/脱体/聚集/移动哪一态。**附着态（没脱手）必须写足：能量贴剑脊走主流湍流、两道刃缘烧到白炽最锐、在手与剑尖之间游走却不离刃、挥击那一帧骤然爆亮加粗、根部始终咬在剑脊、收势即回缩贴刃；缠身能量沿衣摆/肩甲/袖口/发丝衣纹窜，不罩一团光。** **脱体单体剑气七件齐全（形状谱选形＋宽厚度＋边缘轮廓＋凝实度＋挥剑锚点＋离手衔接句〔根部连回手、不凭空〕＋飞行溅散颗粒、是实体刃非火焰非光柱）。** 聚集团体先钉清单体再写前中后鱼群；附着与脱体可同场交替，离手走离手衔接句、命中后人借爆追贴回近身，禁止无过渡跳态（铁律39）。

**🔴事件运镜三条铁律：**
1. **站桩蓄力/结印/吟唱/不动对峙时，镜头必须动起来——用立体半环绕**：人物静止蓄力、结印、吟唱、站位不动打斗时，运镜用ORBIT环绕，但轨迹不是水平平行圆盘（像监控摄像头绕圈），而是带高低落差的圆周弧线——围绕人物做3D弧形运动（半圈≤180°，配合TILT微升/微降形成立体弧线），体现立体感和空间层次。能量升腾时配合仰拍上摇，结印/手部时推进聚焦特写。禁止站桩时镜头也死镜固定，禁止纯水平圆盘式环绕。
2. **大法术/大招从天压下时，切受击者视角**：当大招/法术/巨型攻击从上方降下/垂直压下时，镜头切到受击者FPV/POV仰拍——攻击朝镜头飞来/压下，峰值急停定帧展压迫，命中瞬间镜头被冲击波砸飞（后坐力机位翻滚）。让观众"被砸"而非旁观。
3. **远程剑气/刀气/能量弹脱离发出者后必须实体化**：剑气/刀气/枪气/法术远程攻击是独立飞行实体，不是发光线条。飞行三段必写：①脱体瞬间（武器尖端能量凝聚→脱体射出，带音爆环+空气压缩锥）；②高速飞行中段（空间压缩/空气扭曲/dolly zoom感、属性拖尾拉满、沿途场景反应——地面被犁开沟壑/建筑被气浪切开/水柱火柱炸起/碎石被卷飞）；③命中前（推进到命中点）。镜头可跟剑气实体飞（跟轨迹），或切受击者视角看剑气迎面飞来。禁止激光式瞬间命中无飞行过程、禁止远程攻击无场景反应、禁止剑气无实体质感。

**运镜铁律：**
- 运镜方向=事件发生方向，运镜链随动作流程推进（展规模→跟轨迹→聚焦命中→跟爆发→展结果）。
- 同运镜≤2秒，同景别≤3秒，必须变化。
- 中景及以上禁止90°侧面正拍，必须30-60°斜角。近景/特写允许侧面90°。
- 荷兰角（倾斜构图）仅用于：强攻方-12°至-18°、灵动反击方+10°至+15°、失控段30-45°、碰撞瞬间倾斜后回正。连续不超过3镜。
