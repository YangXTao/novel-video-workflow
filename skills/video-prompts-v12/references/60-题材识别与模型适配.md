## 模块九：16种剧本类型自动识别

AI读取剧本关键词自动匹配题材，切换光影/特效/场景模板。

- ①现代都市
场景：天际线/公寓/深夜街道/咖啡厅/医院/办公室/停车场/雨夜路口 运镜：DOLLY纵深+城市尺度；夜景WS/EWS建立；室内OTS过肩+前景遮挡；追车HANDHELD+WHIP 光影：日景5500K自然光+建筑反射高对比；夜景霓虹(蓝紫红)+路灯暖黄+车灯白，冷青橙LUT；雨天漫射柔光+地面反光 特效：城市光污染/车灯光轨在湿滑路面拉成长线/雨滴水花/玻璃反射 AI推断：“城市街道”→时间段+天气+街道类型；“他走在街上”→行走速度+周围环境+光影；角色服装→按身份推断(白领=西装/学生=校服/混混=夹克) 反向：建筑比例错误/窗户畸形/车辆穿模/行人克隆/霓虹文字乱码

- ②科幻/赛博朋克
场景：赛博街道/太空站/全息UI/义体工坊/外星地貌/黑客空间 运镜：AERIAL宏大+CU科技界面；太空ORBIT零重力；追逐HANDHELD+WHIP 光影：赛博高饱和霓虹(品红/青蓝/琥珀)+深暗背景冷暖对比；太空冷白蓝调低饱和；全息UI自发光蓝绿白 特效：全息投影(半透明+扫描线+光粒散射)/机械义体(金属+发光关节)/飞船尾焰拖出长长焰尾/数据流瀑布 AI推断：“未来城市”→年代+科技水平+天气；“机器人/义体”→材质+发光部位+运动方式；太空→主动加舷窗星空+零重力漂浮物，禁止大气散射 反向：科技设备出现现代元素/UI乱码/机械结构不合理

- ③悬疑/推理
场景：暗调办公室/老旧走廊/雨夜小巷/审讯室/犯罪现场/档案室 运镜：缓慢PUSH压迫+前景遮挡信息隐藏；Jump Scare(WS平静→PUSH→边缘异常→硬切CU)；调查HANDHELD+快速PAN 光影：Low Key暗调大面积阴影仅局部照明；百叶窗/树影/霓虹彩色阴影；冷蓝冷绿为主，绝对禁止均匀照明 特效：信息量控制半隐半现；Jump Scare(平静2-3s→边缘异常0.5s→硬切CU 0.3s)；Dutch Angle15-30°；环境音消失→寂静1s→低频嗡鸣 AI推断：“暗调房间”→光源类型+阴影形状+色温；“发现线索”→线索类型+发现方式+镜头节奏 反向：光线均匀明亮/阴影柔和/场景整洁/表情夸张

- ④恐怖/惊悚
场景：废弃医院/老宅地下室/浓雾森林/午夜高速/镜子暗室/人群异类 运镜：缓慢PUSH+突然WHIP；恐惧距离(CU角色恐惧→WS恐怖源部分遮挡→CU反应)；留白恐怖(WS 90%正常10%异常) 光影：极低照度单一光源(吊灯/手电/月光/霓虹透窗)；冷蓝冷绿病态黄，绝对禁止暖色；大面积死黑但死黑中有极暗灰细节 特效：Jump Scare；视觉暗示不展示全貌(阴影/局部/反射)；环境异变(灯闪0.5→3Hz加速/降温呼出白气/电子故障) AI推断：“恐怖场景”→恐怖类型+源形态+出现方式；“废弃医院”→具体场景+光源+环境细节；主动加呼吸加重/心跳/脚步回声 反向：光线明亮/恐怖源展示过清/表情卡通/血腥过度

- ⑤战争/军事
场景：前线/军事基地/战壕/空战/海军/巷战 运镜：AERIAL+EWS建立全貌→HANDHELD剧烈进入地面；爆炸序列(WS全貌→PUSH角色反应CU→慢动作碎片)；弹道快速PAN 光影：日景高对比尘土体积光；夜景照明弹/爆炸/探照灯明暗交替；低饱和偏黄灰战争色调 特效：爆炸四阶段(闪光0.2s白屏→冲击波瞬间横扫WS→碎片抛飞CU→烟尘柱冲天WS)；弹道轨迹细如发丝、拉出长长尾迹；人群几何队形禁止克隆 AI推断：“战场”→战争类型+地形+时段；“爆炸”→类型+当量+四阶段+烟尘柱；“士兵冲锋”→人数+队形+速度+环境反馈 反向：武器穿模/爆炸物理不合理/人群动作重复/装备型号错误

- ⑥古装宫廷/历史正剧
场景：朝堂/后宫/御花园/走廊/武将府/市井/寺庙/校场 5朝代服化道：唐(襦裙半臂披帛/圆领袍幞头浓丽)/宋(褙子抹胸百迭裙/直裰襕衫雅致)/明(袄裙马面裙披风/飞鱼服曳撒严谨)/清(旗袍氅衣两把头/长袍马褂顶戴满汉融合)/汉(深衣曲裾/深衣冠帽古朴) 运镜：DOLLY宫殿纵深+缓慢CRANE；朝堂WS→MCU/CU君臣OTS；后宫缓慢PUSH浅景深 光影：日景窗棂条纹光5500K；夜景红烛灯笼暖橙摇曳；朝堂高窗侧光+顶部天光柔光、明暗柔和 特效：烟雾香火/衣袂飘带/雨雪水墨意境 AI推断：“古代”→朝代+场景类型+服化道；“皇帝上朝”→大殿规格+百官站位+礼仪动作；主动加线香烟雾/衣袂飘动/宫灯光晕 反向：服装朝代错误/现代物品穿帮/建筑比例错误

- ⑦爱情/情感
场景：黄昏天台/雨中共伞/咖啡厅/海边/雪景街道/厨房 运镜：浅景深CU/MCU焦点面部眼睛；对视OTS+RACK；亲密极缓PUSH(MS→CU)+120fps升格；离别缓慢PULL 光影：柔光漫反射光比1.5:1-2:1禁止硬光；暖色调(夕阳金/烛光橙/室内暖白)；大量逆光发丝光轮廓光；Bokeh圆形光斑 特效：柔光滤镜(高光扩散5-20像素强度30-60%)；120fps升格关键情感时刻；花瓣雪花雨滴前景 AI推断：“两人见面”→关系阶段+距离变化+情绪基调；“浪漫场景”→时间段+天气+场景元素；主动加前景元素(花瓣/雪花/雨滴) 反向：表情夸张/光线生硬/景深过深/动作僵硬

- ⑧喜剧
场景：办公室/家庭/校园/街头/餐厅/交通工具 笑点节拍：Setup(2-3s建立)→Misdirection(1-2s误导)→Punchline(1s反转)→Reaction(2-3s反应)，总6-9s/笑点 运镜：快切2-3s/镜；Punchline后Reaction CU放大表情；物理喜剧HANDHELD+快速PAN；尴尬沉默固定机位长停留 光影：明亮均匀高亮度低对比暖白自然光；夸张场景高饱和 特效：速度变化(正常→慢动作→恢复)；夸张音效(弹簧/玻璃碎裂/卡通boing)；文字特效 AI推断：“搞笑场景”→喜剧类型+笑点位置+反应角色；“他摔倒了”→摔倒方式+夸张程度+周围人反应；主动加夸张音效+速度变化 反向：表情严肃/光线暗沉/节奏缓慢/缺反应镜头

- ⑨犯罪/警匪
场景：审讯室/追车/黑帮据点/犯罪现场/天台对峙/监控室 运镜：HANDHELD晃动+快速切镜；审讯OTS+缓慢PUSH压迫；追车HANDHELD+WHIP+快速PAN；对峙WS→MCU→CU节奏加快 光影：Low Key高对比；审讯室单一顶灯+单向玻璃反射冷白蓝调；夜戏警车红蓝灯+路灯+霓虹黑色电影风格 特效：枪战(枪口闪光+弹壳飞溅+墙壁弹孔+硝烟)；追车(轮胎烟雾+火花+碰撞变形+玻璃碎裂)；监控视角(低清绿调带时间戳) AI推断：“警察抓坏人”→场景+时间段+武器类型；“追车”→车辆类型+速度+路况+镜头角度；主动加警车红蓝灯湿滑路面旋转光斑+轮胎烟雾 反向：枪械操作错误/服装混乱/追车物理不合理

- ⑩灾难/末日
场景：地震/洪水/火山/陨石入侵/瘟疫/核爆 运镜：AERIAL+EWS建立全貌→HANDHELD剧烈人物视角；破坏序列(WS倒塌全貌→PUSH人物反应→慢动作碎片)；逃生HANDHELD+快速切镜+WHIP 光影：地震灰黄低对比尘土散射；火山橙红主光+黑色烟柱；末日黄昏长阴影低饱和废土；核爆三阶段(极白→黑暗→蘑菇云橙红) 特效：建筑坍塌(应力变形→整体倒塌→粉尘云)；洪水流体动力学；火山熔岩流动+火山灰；人群恐慌避免克隆(分配奔跑/摔倒/呼救/救人/呆立) AI推断：“灾难”→类型+规模+阶段；“地震”→震级+破坏表现+人群反应；“洪水”→水深+流速+漂浮物 反向：物理不真实/坍塌不符合结构力学/人群重复

- ⑪青春/校园
场景：教室/操场/天台/走廊/食堂/图书馆/小卖部/放学路 青春滤镜：暖黄淡青低饱和轻微过曝+1/4柔光+轻微胶片颗粒 运镜：偷拍视角前景遮挡+RACK焦点(暗恋对象清晰→偷拍者模糊→暗恋对象清晰)；120fps升格关键瞬间(回头/微笑/递纸条) AI推断：“校园”→年级+季节+时间段；“暗恋”→暗恋者视角+被暗恋者动作+偷拍角度+心跳视觉暗示(浅景深/慢动作/光斑) 反向：服装成熟/场景破旧/表情沉重

⑫职场/商战

场景：办公室/会议室对峙/写字楼大堂/商务餐厅/工厂仓库/交易大厅 运镜：OTS对峙+缓慢PUSH压迫+数据可视化(CU图表→拉远WS)；权力关系(高位WS低角度仰拍/低位CU高角度俯拍) 光影：日景冷白荧光高亮度；会议室冷调高对比；夜景台灯电脑屏冷蓝大面积阴影 AI推断：“会议室”→公司类型+参会人数+权力关系+氛围；“商务谈判”→谈判阶段+桌上物品+角色微表情 反向：服装休闲/布局不合理/电子设备非现代

⑬公路/旅行

场景：高速/山间公路/海边公路/沙漠公路/小镇/加油站旅馆/自然奇观/车站机场 运镜：车载稳定器+外部吸盘+AERIAL航拍公路；车内多角度(正拍/侧拍/后视镜反射)+窗外风景流动；延时摄影 诗意转场：匹配剪辑(车窗/后视镜/挡风玻璃)/时间流逝延时/声音先行 AI推断：“在路上”→公路类型+交通工具+旅伴关系+时间段；“车窗外风景”→风景类型+天气+车速+窗外物体流动速度 反向：车辆物理不合理/风景季节不匹配/交通标志错误

⑭音乐/歌舞

场景：舞台/MV/街头表演/录音棚/演唱会/舞蹈室 运镜：ORBIT环绕+快速PUSH/PULL配合节拍；低角度仰拍+广角畸变增强动感；MV快切0.5-1s 节拍卡点：鼓点切换镜/重拍触发视觉特效(闪光/变形/缩放)/旋律可视化/能量曲线(主歌平静→副歌爆发→桥段沉淀) AI推断：“唱歌/跳舞”→音乐类型+节奏快慢+场景；推断镜头切换频率与节拍同步+灯光颜色与情绪匹配 反向：音画不同步/舞蹈僵硬/灯光不合理

⑮纪录片/写实

场景：真实工作/新闻现场/自然生态/历史档案/采访间/街头纪实 去美化画质：HANDHELD手持轻微晃动+自然光+低饱和偏灰黄+适当噪点+24fps基准（覆盖全局基础帧率） 运镜：HANDHELD观察式长镜头不干预；采访固定CU/MCU浅景深自然光；AERIAL宏观缓慢移动 AI推断：“纪实场景”→纪录片类型+拍摄风格+被摄对象状态；主动加环境杂音/手持晃动/不完美构图/自然光 反向：画面过精美/光线过完美/表情表演化/构图刻意

⑯动画风格

## 模块十一：失败重试与模型适配

常见失败降级

角色变脸：增加面部细节+缩短单镜2-3s+改用CU减少面部面积

特效浑浊：简化特效聚焦单一元素+减少同屏特效+加”clean clear”

动作卡顿PPT：增加运镜指令+加大景别跳跃+机位夹角≥30°+攻击阶段swift/whip

🔴 打戏速度慢没打击感（9项排查）：①攻击动作有速度量化吗②运镜攻击阶段用swift/whip吗③有顿帧→爆发对比吗④有物理连锁反馈吗⑤动态模糊高强度吗⑥反向词有No sluggish movement/No weak impact吗⑦增加静默→爆发声画设计⑧正向词增加Fast Paced/High Speed Motion/Quick Cuts⑨命中/碰撞有冲击帧吗（纯白闪帧+速度线+镜头震动同步，禁止Bloom百分比）⑩单挑交锋段用ACT战斗跟随运镜吗（攻击方向驱动+命中锁定+惯性回弹）

🔴 沉浸感不足像旁观者（/，4项排查）：①有FPV/POV/ACT中至少一种沉浸感运镜吗②运镜写清起点位置+运镜路径+前景交互了吗（FPV）/跟随方向+镜头怎么动+命中凝滞了吗（ACT），用画面语言禁止m/s和米数③角色位移有属性定制化能量拖尾吗（风格+颜色+长度）④传统机位与沉浸感机位交替使用了吗⑤单挑交锋段用ACT战斗跟随运镜了吗

穿模武器消失：增加具体持握描述+反向词追加武器穿模+缩短动作幅度

光影死黑过曝：显式写”柔光漫反射柔光、明暗柔和”+加”暗部保留细节”+减少高对比

背景瞬移：增加专属物理背景+位移写起点→运动→终点+减少场景物体

### 11.1 Seedance正向约束适配（2.0/2.5双适配）

Seedance无独立negative字段，否定式约束必须改写为正向描述融入prompt正文；其他模型保留负面提示词。不确定时双保险：正文写正向描述+负面提示词保留禁止项。

| 否定式（不输出） | 正向描述（Seedance输出） |
|----------------|----------------------|
| 禁止肢体变形/穿模/多手指 | 肢体结构正常，手指数量正确，衣物贴合身体 |
| 禁止画面模糊/抖动 | 画面稳定清晰，焦点准确 |
| 禁止BGM | 全程无BGM，仅物理音效+环境音 |
| 禁止慢动作（非指定段） | 正常速度24fps，仅命中段升格 |
| 禁止字幕/水印/文字 | 画面无任何文字字幕水印 |
| 禁止表情崩坏 | 面部稳定，表情自然 |
| 禁止鱼眼畸变（非冲击帧） | 标准透视，无镜头畸变 |
| 禁止多余角色入画 | 画面中只有指定角色 |

**Seedance 2.5特效适配（与铁律19联动）：** 2.5对工程参数（米数/百分比/Bloom值/m/s）不敏感，特效描述必须用画面分区+视觉比较语言（铁律19翻译表）。2.0 fast能理解数字但视觉语言同样更友好，统一输出画面语言双适配。时间参数（顿帧0.05s/升格120fps）2.0/2.5都能理解，保留。
