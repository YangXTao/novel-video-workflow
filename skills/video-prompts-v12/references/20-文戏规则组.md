## 模块三：文戏专项

> **现行边界**：本模块的字段模板和示例时长只作组织参考；实际输出协议、项目秒数、承接拍、空间锚定、喜剧模态和适用规则以96号依赖清单及100号现行口径为准。

### 3.00 文戏导演脑：内心→外显·自然句总控（最高执行脑·写任何文戏镜头前先走一遍，对标打戏铁律0）

**一条红线（和打戏"禁空话"同级）**：情绪、潜台词、氛围只是给你自己看的内部注记，**禁止直接写进最终正文**——不写"她很失望""气氛很压抑""空气黏稠得要用力呼吸""安静有重量"，也不写"光软得像煮旧的粥"这类文学比喻，模型渲染不出形容词和比喻，只渲染动作、画面、声音。任何内心状态落字前必须翻译成三件可拍摄的东西：**①一个外显信号（生理/脸/手/身/道具，五通道见下）②一个镜头选择（景别·机位·运镜·焦点）③这句台词怎么念、或用非语言发声/静默代替**。观众只能靠"看到的动作＋听到的念法＋镜头怎么给"读出情绪，读不到情绪名词本身。

**脑内十八维逐项过（包括但不限于；与本镜有关才用、不强塞、不凑数）**：①空间与距离 ②眼神与视线 ③微表情与面部 ④手部细节 ⑤呼吸与身体节律 ⑥光影与情绪 ⑦环境声与空气感 ⑧服饰与物品叙事 ⑨镜头语言 ⑩节奏与停顿 ⑪情绪命名与转化 ⑫台词与声音 ⑬场景物品锚定（每件关键道具/家具的固定位置与当前状态、跨镜继承不漂移，联动3.6场景控制与7.7物品追踪）⑭相对参照物控制关系（用人物相对门框/桌沿/光源/彼此的位置·高低·远近·占画面多少演权力与亲疏，联动3.2走位权力与负空间）。【v12.4新增·多人对话四维度】⑮话语权（谁在说/谁被打断/谁的台词被压住，用台词先后与叠化演权力消长）⑯站位几何（三人以上时的三角/直线/包围站位，位置移动=关系变化）⑰注意力焦点（众人视线/身体朝向汇聚点，焦点转移=戏剧重心转移）⑱信息差（谁知道/谁不知道/谁装不知道，用反应镜的时间差演悬疑）。🔴硬配额：每镜**至少选3个维度**真正外显落句，其中必含①空间与距离，且"身体细节（②—⑤任一）"与"物品/参照物锚定（⑧/⑬/⑭任一）"至少各一个；禁止直接用情绪名词代替描写，情绪必须经身体/物品/光/距离/声音外化（具体转化见下方"不写X写Y"十条）；需要把情绪做成可见微特效（泪/呼出白气/悬尘/烛火/发丝/信纸卷角）时走2.9.1⑭文戏情绪可视系（载体+路径+时间感+互动）。每一维要么外显成可见画面或可听声音、要么本镜明确不涉及，不允许“想到了却没落进句子”；十八维之外，轴线（3.5）、反应镜头（3.10.5）、J/L-Cut（3.9）、连续性防崩（3.6/七）同样默认在岗。

**内心→外显速查（左栏只在脑内、禁止落进正文；右栏才是写进句子的演法，每处任选1—2个、别堆满）**：
| 内心（内部不落字） | 外显演法（写进句子） |
|------|------|
| 隐忍克制 | 呼吸浅到胸口不起伏、眨眼变慢、只嘴角动一下其余不动、指节发白又慢慢松开 |
| 崩溃边缘 | 句尾在空气里发颤、吸气断断续续、眼睑轻颤、血色从唇上褪掉 |
| 失望心凉 | 眼神那点光慢慢灭掉、别开脸、肩垮下来、手伸到一半又收回 |
| 紧张撒谎 | 吞口水喉结滚动、尾音不自觉上扬、手指反复摩挲、避开对视去看衣领 |
| 决绝 | 每个字咬清楚像刀切、先吸一口气才开口、眼神锐、嘴唇抿成一线 |
| 虚与委蛇 | 嘴角在笑眼不笑、Rack Focus在眼和手之间切换、脚悄悄后退半步 |
| 压着的怒 | 越怒声音越轻、齿音重、咬后槽牙、鼻息变粗、重音词出口时手收紧 |
| 温柔心动 | 气声混着实声放慢、目光追随对方、不自觉靠近半寸、瞳孔微张 |
其余情绪走3.3情绪→肌肉映射与3.10.2情绪变调表，三表配合、不重复堆词。

**"不写X写Y"十条外化对照（抽象词/情绪名词的转化口诀，落句前逐条对照；右栏给转化方向，具体演法仍取上方速查表与3.3/3.10，不重复堆词）**：
1. 不写情绪，写身体泄漏——"他很紧张"→喉结滚动/指尖反复摩挲纸边/呼吸停半拍。
2. 不写"静"，写静里的动——"屋里很静"→钟摆声/光柱里悬尘缓慢下沉/烛火轻轻摇。
3. 不写"很久"，写物品变了——"等了很久"→茶凉透一口没动/香烧到尾/烛泪堆成一小摊。
4. 不写关系差，写空间替他们说话——"两人疏远"→各据桌沿两端、中间空出整条桌、谁也不越线。
5. 不写难过，写光的态度——"她很难过"→云移过、脸上的光一点点暗掉、人沉进影里。
6. 不写说谎，写身体和嘴不同步——"他在撒谎"→嘴上语气平稳、手却把纸边掐出折痕、眼神避开去看衣领。
7. 不写尴尬，写空气的重量——"气氛尴尬"→谁都没接话、茶杯悬在半空、远处一声蝉鸣被放大。
8. 不写犹豫，写动作的中间态——"他犹豫了"→手伸到一半停住、指尖将碰未碰、话到嘴边又咽回。
9. 不写"对视"，写视线的碰和逃——"两人对视"→目光刚撞上、其中一方先移开、看别处再悄悄挪回。
10. 不写哭，写眼泪的路线——"她哭了"→泪在眼眶蓄住、沿鼻侧滑到下巴、停一秒才坠下砸开。
十条只负责把抽象词转成可拍细节，落句仍走"文戏单镜自然句母版"，禁止把十条当标签罗列。

**外显信号五通道（每镜至少让一个通道"说真话"，3.3.3言行一致时优先给泄露真实情绪的通道INSERT）**：
- **呼吸生理**：呼吸深浅、话说一半呼吸停半拍、那口气是叹出来还是从身体里"漏"出来、颈侧血管轻跳、细汗、眨眼频率、吞咽。
- **眼神**：看哪、敢不敢对视、瞳孔聚焦还是散焦、目光从眼滑到唇又赶紧移开、眼神光点亮或灭掉；写清对视持续多久、谁先移开眼，眼神质感（发冷/发柔/突然空掉/湿漉漉）用一个可拍细节带过，不直接写形容词。
- **手部**：手指在杯沿画圈越画越急、指甲刮桌面刮出白痕、两只手隔着一杯茶的距离、指尖将碰又缩回、整理一个根本不乱的东西。
- **肩背姿态**：肩垮或绷紧、重心前倾/后撤、抱臂把自己裹住、站在门框里显得很小。
- **服装道具**：松了自己没察觉的领扣、把外套裹紧、反复折一张纸展开又折；衣物随情绪动（攥紧衣襟、衣摆垂坠、站直时抻平褶皱），服饰与身份的关系（正装太板显拘谨、新衣太挺显格格不入、卸下装束那一刻的松懈）；情感道具见下条。

**情感道具叙事（3.6管"道具位置不跳"，本条管"道具会演戏"）**：每场选1件承载情绪/时间/关系的物件，用它的状态和被对待的方式替角色说话——照片反扣在桌面、茶凉透了一口没碰、戒指放在两人正中间谁也不拿、信被攥皱又展平、袖口针脚被摩挲起毛。道具状态跨镜延续（凉了不会自己热、皱了不会自己平），关键情绪先给INSERT物件特写再Rack Focus回脸。

**负空间与画面权重（构图即关系，配合3.2距离/高低差）**：用人物占画面多少、被放在哪、四周留多少空来演心理——被压迫者挤在画面一角、压迫者占三分之二；孤独疏离就让人物只占约三分之一、其余全是空房间/空走廊并缓拉让空越来越大；关系亲近就让两人同框占满、缝隙变小。

**光影与空气也会演戏（接3.1.1/3.7，仍走外显、不写形容词）**：用影子和“人与光的位置”说话——影子先一步探进门、谁的影子盖住谁、人站在光的边缘将进未进、半张脸沉进影里、云移过脸上的光慢慢暗掉。“空气感”禁止直接写“黏稠/清冷/压抑”，必须外显成**可见＋可听**：清冷=呼出的白汽、冷调里搓手呵气、窗缝漏进的细光；黏稠逼仄=窄光柱里缓慢悬浮的尘粒、额角细汗、被放大的蝉鸣/钟摆/电流声；静默不是没声，是把一个具体的小声（水滴/钟摆/炭火/远处车声）凸显出来。主观时间被拉长时，用慢动作里的一个细节（飘落的灰、将落未落的泪、悬停的手）让观众感到时间变慢，而不是写“像过了一生”。

**文戏单镜自然句母版（字段只在脑内组织，正文必须织成一整句流畅可拍的话，禁止竖线串/标签罗列/关键词堆叠）**，内部成句顺序：
空间锚点（谁在画面哪、相对哪件家具或哪个人、距离与朝向、三层纵深、用逼仄层高或空旷留白制造压迫/疏离）→ 外显表演（眼/手/身体/呼吸/道具的具体动作，不出现情绪名词）→ 镜头（焦段景别·机位角度·缓推缓拉/手持呼吸感/Rack Focus，融进动作句、不单独列"运镜："）→ 光色随这一拍情绪怎么变（3.1.1）→ 台词怎么念【角色｜基础声色→情绪变调｜嘴部状态】加重音气口、或非语言发声/静默 → 听话人反应。一镜连读是一段人话，标杆密度与写法严格对齐3.11完整示例。

**台词口径**：默认**由视频模型原生说出台词、不做后期配音**。每句台词都要在自然句里写清：正脸或3/4脸给足口型、怎么念（气声/颤音/咬字/语速/音调走向，3.10.2）、什么音色（质地/温度/年龄感，8.5.1）、重音与气口（3.10.3），用来驱动模型开口、声画同步；仅当确认所用模型不发声时，才退化为"口型说原台词、不出声"的纯画面写法（见3.4）。

### 3.0 文戏输出格式（字段式四段）

文戏输出固定为以下字段顺序，复制即用，无解释无废话：

**全集开头（每集输出一次，不在每镜重复）**：
- 渲染风格（每镜复读的画质基准词）
- 全局运镜基调：手持微晃程度+默认焦段+正反打节奏+切镜方式，声明一次逐镜不重复，对标打戏铁律20）
- 声音规则（声色表+嘴部状态+项目契约锁定的内心小人模态）
- 空间站位规则（每个场景的坐标系：家具方位+门窗位置，以不变的固定陈设锚定人物位置）
- 身高差规则（角色身高+站/骑/抱时的相对高度）
- 穿模规避规则（全集高频风险点）
- 内心小人规则（按铁律50与61号14.2的项目契约模态执行）

**每镜铁律**：
1. 画质基准、场景、角色每镜完整复读，禁止"同上/同前镜/画质同前"等任何缩写（铁律1），声色/空间/道具/光源同样禁止省略。
2. 焦段必须和构图比例+人物占比写同一句（如"85mm中长焦，面部占画面70%"），禁止只写焦段。
3. 运镜用五种融合句式融进动作句，禁止单独列"运镜："。
4. 台词按当前镜头总时长、模型原生语速和项目契约核算；4-5字/秒与10-12字只是容量参考，完整剧本台词不得因参考容量被静默删减，长台词需请求用户决定拆镜或加时。
5. 前景交互按场景和戏剧需要安排；动作/转场段可多次，静态文戏不为满足配额强行制造前景运动。
6. 子时间节点粒度0.5-1.5秒，每节点开头焦段+构图+人物占比，节点间焦段或运镜必须有变化。
7. 空间六要素每镜完整，同场景连续镜头空间关系连贯，站位/朝向/门窗方向/光源不跳变。
8. 上镜衔接每镜一句话（上镜结尾画面+角色位置+机位），战损/破坏/道具状态从上镜继承。

### 3.2 走位与权力映射

高位=权力优势(台阶上/椅子上/画面上方)，低位=劣势；权力反转时劣势方渐走向高处

距离=心理距离：亲密=一臂之内(恋人/密谈/威胁)/社交=一张桌子宽(对话/谈判)/公共=隔整张桌子开外(疏远/敌对/正式)；情绪升温→靠近，破裂→后退

朝向=态度：正面(坦诚/对抗/重视)/侧身背对(隐瞒/冷漠/拒绝)/45°侧身(轻松/友好)；转变背对→侧身→正面

走位时间轴示例(60s)：0-15s建立(A左窗前后景B右桌旁中景距3m45°侧身)→15-30s升温(A走向B距1.5m正面)→30-45s顶点(A逼近0.8m威胁距离B后退)→45-55s转折(B转身走向深处背对距3m)→55-60s收束(一左一右一前一后留白)

### 3.3.3 言行一致性原则（悬疑/权谋/怪谈核心）

**形式（三模态，按剧作风格与用户指定三选一、全剧统一，详见61号14.2）**：
- **A 小框模式**：画面角落（左下角或右下角）浮出一个独立圆角小框，小框有细边框和半透明背景，与正片画面区分；小框内是该角色的3D三头身Q版mini版。
- **B 实体化模式**：Q版小人**实体化站在正片画面里**——站在真人肩膀上/脑袋旁/场景实物上（酒杯沿/桌面/剑坛石头/门楼牌匾等），与正片场景实物发生物理接触；**有实体光影**（投射小影子、被场景光照亮、踩出小脚印），剧中角色看不见、只有观众看得见。
- **C 混合模式**：同剧内小框与实体化按场景切换。
- 小人是该角色的3D三头身Q版mini版（掌心大小，穿同款服装，发型一致，五官是该角色的Q版简化）。
- 小人做搞笑动作（蹲角落画圈圈/蹦高撒花/抱头吐槽/叉腰哼气/举牌子/头顶小乌云下雨/灵魂出窍/抱银子蹦高/捂脸蹲下等）。
- 小人开口说话（用该角色自己的音色，嘴巴动），说的是角色内心真实想法。
- 小人出现0.3秒过渡（弹出/滑入/跳进画面），消失0.3秒（缩小/淡出/跳走）。
- 小人消失后切回正片，正片角色表情切换一次（如从高冷→嫌弃、从淡定→嘴角抽搐、从暴怒→假笑、从黑脸→认命），表示"心里话被观众听到了但表面维持住了"。

**使用时机**（只在内外反差时用，不是每镜都有）：
- 表面淡定内心崩溃（角色看到珍视之物被毁但强装镇定）
- 表面高冷内心得意（角色装老成其实心里偷着乐）
- 表面嫌弃内心崇拜（角色嘴硬但其实已经服了）
- 吐槽/自傲/愤怒/社死/心虚
- 反向心理（嘴上说不要身体很诚实）

**写法（在时间轴子节点中）**：
"第X秒画面左下角浮出独立小框，mini角色（三头身Q版，同款服装）做什么动作+说什么台词（角色自述声色），小框第X秒消失，切回正片角色表情切换成什么。"

**铁律**：
1. mini角色（小人）用该角色自己的音色（不是独立旁白音色），嘴巴动。
2. 正片角色在小人出现时闭嘴只有微表情，小人消失后表情切换一次。
3. 同一镜最多1个小人，不叠加。
4. 小人位置按模态定：A小框模式=小框位于画面角落，具体左/右由构图和不遮挡正片核心人物决定；B实体化模式=小人站在真人肩膀上/脑袋旁/场景实物上（与正片实物接触、投小影子）；C混合=按场景在A/B间切换。
5. 小人时长1-3秒，说完就消失，不贯穿整镜。
6. 严肃戏/打戏/情感戏不用小人，只用在喜剧反应。
7. mini角色动作要具体（不要只写"很搞笑"），如"蹲角落画圈圈头顶小乌云下雨""双手举牌牌子写XXX""原地蹦高撒花脚下弹出星星"。

### 3.4.1 文戏剧Beat库（5种标准情绪曲线模板）

**核心理念**：文戏不是"两个人站着说话"，而是有情绪起伏的戏剧曲线。根据剧本关系和情绪走向，自动匹配以下5种标准beat模板，指导走位、运镜、光影、微表情的节奏分配。

#### Beat模板一：试探升温型（初次见面/谈判/暧昧/暗中较量）

**曲线**：建立(20%)→试探(25%)→升温(25%)→顶点(20%)→留白(10%)
- 建立段：双方距离一张桌子开外，45°侧身，运镜MS/MCU缓慢PUSH，柔和漫射光，微表情克制
- 试探段：一方缓慢趋近0.5m，距离缩到一臂半，运镜OTS过肩+RACK焦点，侧光微显明暗分割，微表情（挑眉/喉结滚动/手指摩挲）
- 升温段：距离缩到一臂之内，正面相对，运镜极缓PUSH(MS→CU)，侧光明暗分割强烈，微表情频率加快（眼神交汇/呼吸变浅/咬肌隐现）
- 顶点段：距离近到呼吸相闻，运镜CU极缓推进或STATIC定格，硬光、半脸没入阴影，微表情爆发（瞳孔骤缩/眼眶泛红/嘴角颤抖），静默极短一瞬
- 留白段：一方后退/转身，距离重新拉开一张桌子宽，运镜PULL后拉或空境，光比回落、明暗柔和

#### Beat模板二：冲突爆发型（争吵/决裂/对峙/质问）

**曲线**：建立(15%)→升级(25%)→爆发(30%)→余震(20%)→收束(10%)
- 建立段：双方距离一张桌子宽，正面相对，运镜MS对称构图，硬光冷调、明暗分明，微表情压抑
- 升级段：一方逼近，距离缩到一臂之内，运镜HANDHELD微晃+快速PUSH，硬光、明暗对比强烈，微表情加剧
- 爆发段：距离近到贴面冲突或一方后退到一张桌子开外，运镜WHIP甩镜+CU快切，硬光、明暗高对比，微表情爆发（怒目/牙关紧咬/拳头攥紧）
- 余震段：双方距离拉开到隔整张桌子，背对或侧身，运镜PULL后拉WS+空境，光比回落3:1，微表情（喘息/眼眶泛红/低头）
- 收束段：一方离开或沉默，运镜缓慢PUSH至单人CU或空境，柔光、明暗柔和柔光

#### Beat模板三：情感递进型（告白/和解/师徒传承/生死告别）

**曲线**：铺垫(20%)→靠近(25%)→交汇(30%)→顶点(15%)→余韵(10%)
- 铺垫段：距离2m，侧身或背对，运镜MS缓慢横移，柔光暖调、明暗柔和，微表情内敛
- 靠近段：一方缓慢趋近，距离1.5m→1m，运镜极缓PUSH+RACK焦点，光影渐暖，微表情（深呼吸/眼神坚定）
- 交汇段：距离0.5-1m，正面或45°相对，运镜CU交替正反打+极缓PUSH，暖光+逆光发丝光、明暗分明，微表情（眼神交汇/眼眶泛红/微笑）
- 顶点段：距离0.5m内（拥抱/握手/对视），运镜STATIC CU或极缓环绕，硬光、明暗对比强烈暖光高光，微表情顶点（泪水/闭眼/释然微笑），静默一瞬
- 余韵段：运镜PULL后拉或空境（夕阳/落叶/烛火），柔光、明暗柔和柔光，环境音+音乐渐起

#### Beat模板四：权力博弈型（君臣/上下级/谈判桌/审讯）

**曲线**：制衡(20%)→施压(25%)→反转(25%)→定局(20%)→收尾(10%)
- 制衡段：双方等高或高位者略高，距离2m，运镜MS对称+低角度仰拍高位者，硬光、明暗分明
- 施压段：高位者趋近或站立，低位者坐姿/后退，距离1.5m，运镜高角度俯拍低位者+低角度仰拍高位者，硬光、明暗对比强烈
- 反转段：低位者起身/趋近，权力翻转，距离1m，运镜机位高度渐变（俯拍→仰拍），光比渐变
- 定局段：新权力关系确立，运镜低角度仰拍新高位者，硬光、明暗分明
- 收尾段：双方距离拉开，运镜PULL后拉WS，光比回落3:1

#### Beat模板五：平静叙事型（日常/交代信息/并肩观景/回忆讲述）

**曲线**：建立(30%)→叙事(40%)→微澜(20%)→收束(10%)
- 建立段：并排或同方向，距离1-1.5m，运镜MS/WS缓慢横移或固定，柔光、明暗柔和自然光
- 叙事段：保持距离，偶尔手势，运镜MCU交替+细节特写，光比稳定，微表情自然
- 微澜段：信息冲击点，运镜极缓PUSH至CU，光比微变（阴影略增），微表情（眼神变化/停顿/深呼吸）
- 收束段：回归平静，运镜PULL后拉或空境，柔光、明暗柔和

**Beat选择规则**：明确冲突→模板二；情感递进→模板三；权力关系→模板四；初次见面/暧昧→模板一；日常/交代→模板五。混合情绪取主导，可拼接两种模板。

### 3.5 空间锁定与180°轴线铁律

铁律：段首必须显式宣告角色左右站位，机位只能在两人连线同一侧移动，绝对禁止两人左右位置互换，死死锁住轴线。

- ①站位锁定格式（每镜必写）："[角色A]在画面左侧，面朝[方向]；[角色B]在画面右侧，面朝[方向]；两人相距[用身体比例/前景交互表达，如"相隔三步""一臂距离""隔着整张桌子"，禁止米数]，180°轴线锁死（轴线为两人连线，镜头始终在轴线同一侧拍摄）。"
- ②反打切镜时背景必须精准跟随人物——A在左则背景永远是A身后的场景，B在右则背景永远是B身后的场景，禁止越轴导致左右互换。
- ③多人对话：以主要对话双方的连线为轴线，第三人在轴线同一侧移动，禁止第三人从左侧突然跳到右侧。
- ④角色移动时轴线跟随更新：如果角色走动导致左右位置变化，必须用一个跟随镜头展示移动过程，禁止硬切后位置突变。
- ⑤违反后果：越轴=空间逻辑崩坏=生成失败，必须重新生成。

### 3.6 场景控制铁律——禁止空间乱穿

铁律：场景内的空间关系必须符合物理逻辑，禁止"镜头穿墙""视角乱跳""室内外无媒介切换"。

- ①室内展示室外天气：必须通过窗户/门缝/屋檐/屏风等媒介，禁止室内对话镜头突然变成室外雨景。正确写法："窗外细密雨丝打在窗棂上，雨滴沿玻璃滑落，室内烛光在雨痕上折射出暖金光斑"——雨永远在窗外，镜头始终在室内。
- ②视角限制：如果机位在室内，所有画面必须是室内视角，室外内容只能通过门窗等开口看到；如果要切到室外，必须用转场（走到门口开门/镜头推向窗户穿越/硬切到室外建立镜）。
- ③场景参照物锁定：每镜必须写明场景参照物（如"木桌在画面中央偏后，烛台在桌中央，书架在左侧墙，窗户在右侧墙"），后续镜头参照物位置不变。
- ④禁止"空间跳跃"：角色从A位置到B位置必须有移动过程或合理转场，禁止上一秒在桌边下一秒在门口且没有走动镜头。
- ⑤三层纵深构图（每镜必写）：前景（飘落的树叶/衣袖/烛火/茶杯）+ 中景（对话角色）+ 背景（窗外雨景/远山/书架/墙壁），三层必须同时存在，禁止只有人物没有环境。

### 3.7 光影一致性铁律

铁律：光源方向不可随意变更，同一场景内主光/辅光/轮廓光的方向、颜色、强度必须严格一致。

- ①光源声明格式（每镜必写）："主光：[方向，如左上方45°窗外冷蓝月光]，辅光：[方向，如右侧烛火暖金反射]，轮廓光：[方向，如背后窗外逆光]，光比[X:1]。"
- ②室内烛光场景：主光=烛火（暖金，方向从桌面向上），辅光=窗外冷蓝月光/天光（方向从窗户射入），轮廓光=窗外逆光，硬光、明暗分明（烛光为主，月光为辅）。
- ③角色移动时光影跟随：角色走到窗边时脸上冷蓝月光增强、暖金烛光减弱；走到烛火旁时脸上暖金增强、冷蓝减弱，禁止光影不随位置变化。
- ④禁止"自发光人脸"：角色面部必须受场景光源影响，有明暗面、有阴影，禁止面部均匀发光无阴影。
- ⑤体积光：光源穿过空气中的尘埃/水汽/烟雾形成可见光束，室内烛光有暖金体积光，窗外月光有冷蓝体积光，两者在空气中交汇。

### 3.8 镜头衔接6模式

铁律：禁止连续两个固定机位，相邻镜头必须按照"固定→推/拉/摇/移/跟→固定…"交替。相邻衔接必须归入5模式之一。

- ①同向衔接：前镜左移→后镜左移，方向一致，动作连贯。适用于角色连续走动、视线连续移动。
- ②反向衔接：前镜左移→后镜右移，方向相反，形成节奏对比。适用于对话正反打、情绪转折。
- ③静切动：前镜固定→后镜运动，从静到动，制造能量提升。适用于情绪升温、角色突然起身。
- ④动切静：前镜运动→后镜固定，从动到静，制造停顿和呼吸。适用于情绪顶点后的沉默、重要台词前的静止。
- ⑤同质叠加：前镜推→后镜继续推，同方向同速度叠加，制造持续推进感。适用于长镜头情绪累积、逼近威胁。
- ⑥角色位移时，相邻镜头方向必须顺畅（如左移接左移），绝不允许左右互搏（前镜左移后镜右移且没有合理动机）。

### 3.9 转场规范

- ①硬切：前镜声音骤停，后镜声音骤起。适用于节奏突变、场景跳转、情绪断裂。
- ②叠化：前镜渐弱后镜渐强，声音交叉淡入淡出。适用于时间流逝、回忆、情绪延续。
- ③J-Cut（声音先入）：后镜声音先于画面出现，前镜画面还在时后镜声音已经响起。适用于对话衔接、声音引导画面。
- ④L-Cut（声音延后）：前镜声音延续到后镜画面中，后镜画面已经出现但前镜声音还在。适用于台词余韵、情绪延续。
- ⑤遮挡转场：物体/人物经过镜头前遮挡画面，遮挡间隙切换。适用于室内外切换、角色移动转场。
- ⑥运动转场：镜头甩/推/拉至运动模糊，模糊中切换。适用于快速转场、动作衔接。
- ⑦匹配剪辑：利用相似形状/颜色/动作衔接两个场景（如烛火圆形→太阳圆形、开门动作→开门动作）。适用于创意转场、主题呼应。

### 3.10 文戏台词与声色控制（强化·对手戏核心）

#### 3.10.1 与8.5全局声音系统的关系（先读）

8.5是全局声音底层（8.5.1角色音色表/8.5.2旁白模式A·B/8.5.3音画同步嘴部状态表/8.5.5标注示例），本章节是**文戏专用的台词表演控制层**，两者共存不冲突。工作流：开局按8.5.1建角色音色表+8.5.2选定旁白模式 → 逐镜按本章节写台词的情绪变调/呼吸气口/对手戏交互/反应镜头/非语言发声。底层音色表是"这个角色天生什么嗓"，本章节管"这句台词他怎么说"。

#### 3.10.2 情绪变调表（🔴静态音色表不够，同角色随情绪变嗓）

| 情绪 | 发声特征 | 标注要点 |
|------|---------|---------|
| 压抑愤怒 | 音量反而压低、齿音重、胸腔共鸣、语速放慢咬字狠 | 不吼，越怒越轻 |
| 暴怒爆发 | 音量陡增、破音边缘、语速加快、尾音上挑 | 与压抑形成陡转 |
| 悲伤 | 气声为主、音量弱、句尾下沉发颤、断续 | 鼻腔哽咽 |
| 恐惧/紧张 | 声音发紧发颤、气息浅、吞字、声调飘 | 喉结滚动 |
| 冷笑/嘲讽 | 鼻腔出气、不张嘴、单声哼、嘴角歪 | 非语言发声 |
| 温柔 | 气声混实声、语速放慢、尾音轻 | 气息绵长 |
| 虚弱 | 气多声少、断句多、气息不稳 | 句间大喘气 |
| 威严施压 | 低位置共鸣、语速慢、字字停顿、不抬音量 | 靠停顿不靠吼 |
标注格式扩展为【角色名｜基础声色→情绪变调｜嘴部状态】，例：[角色A｜低沉磁性男音→压抑愤怒·齿音加重·放慢｜开口]："你再说一遍。" 禁止只标基础声色不标情绪变调。

#### 3.10.3 台词的呼吸与气口（让台词像活人说的，不是念稿）

- **重音**：每句标1个重音词，重音词必须绑定一个微表情/动作点（说到重音词时手指收紧/眼神一沉/茶杯一顿）。
- **气口**：长句标换气位置；情绪激动气短、气口密；平静/城府深气口长、一气呵成。
- **吞字与停顿**：欲言又止=话说半句停住+咽口水/别开眼；关键名词前留0.2s停顿制造强调。
- **尾音处理**：陈述下沉、疑问上扬、心虚尾音飘走、狠话尾音收干净不留余音、谎言尾音不自觉上扬。
- **边做边说**：台词必须与动作绑定——背对镜头说/转身瞬间说/手里忙着说/走近过程中说/低头做事说。禁止角色站定正对镜头念台词（这是PPT感最大来源）。
- **哭腔/笑腔反差**：哭着说笑、笑着说狠话，标注发声位置（鼻腔哽咽/胸腔震动/气声发抖）。

#### 3.10.4 对手戏对白交互（🔴不是轮流背台词，是攻防）

- **打断**：A话没说完（写省略号"你根本就……"）→B抢入，A嘴巴还张着/被噎住的微表情，B抢话瞬间可快切。
- **抢话/重叠**：两人同时开口→其中一人立刻收声让位；或异口同声后同时停住对视（默契）。
- **把话咽回去**：角色张嘴想说→看到对方眼神/动作→把话咽回（喉咙滚动/嘴唇抿紧/低头），用动作代替没说出口的台词。
- **画外接话**：镜头对着听话人，说话人在画外，观众只看反应；下一句再切回说话人（联动3.10.5）。
- **沉默对峙**：该接话时不接，用2-3秒沉默+眼神攻防+环境音放大（时钟/水滴/风声/炭火噼啪），沉默比台词更有压迫感。
- **各说各话**：两人聊的不是一件事、答非所问，表现疏离/回避/各怀心事。
- **反应垫词**：一次只让一人的台词是信息主体，另一人只用"嗯""是吗""然后呢"做反应垫词，不抢信息。

#### 3.10.5 说话人/听话人镜头分配（台词正反打）

- **铺垫性台词**：边走边说/画外音配环境/中景双人，不必给特写。
- **关键台词（真相/狠话/告白/决定）**：必须给说话人近景或特写，开口前0.2s先静止，落音后留0.3s不切，让台词砸下来。
- **关键词切反应**：说到名字/秘密/决定的那个词，切听话人反应镜头（瞳孔骤缩/嘴角抽动/攥紧的手），用听话人反应放大台词分量。
- **长台词跨镜拆**：前镜说话人→后镜听话人反应+后半句画外音（L-Cut，见3.9）。
- **镜头跟着情绪走**：谁的情绪正在变化镜头给谁，不是谁说话镜头就一直钉着谁。
- **多人对话**：用视线匹配（7.10）引导，谁说话其余人视线看向谁，观众视线随之走。

#### 3.10.6 非语言发声（🔴不是台词但有戏，必标不占台词字数）

叹息/冷笑·哼/倒吸冷气/抽气/哽咽/吞咽口水/鼻息加重/嗤笑/轻"嗯"/痛哼/咬牙关。按8.5.3同格式标注：[角色名｜一声嗤笑·鼻腔出气｜鼻息]、[角色名｜倒吸一口凉气｜开口]。情绪转折处优先用非语言发声+微表情代替把情绪直说出来。

#### 3.10.7 静默即台词（该说而没说）

- **欲言又止**：张嘴→停顿→摇头/转身，没说出口的话全用动作交代。
- **话到嘴边换词**："我……没事。"停顿处给微表情，换的词暴露真实想法。
- **延迟回答**：被问后不立刻答，先做一个动作（点烟/倒水/看窗外/掸灰）再开口，延迟的几秒就是心理活动。
- 一场戏允许1-2处"该说而没说"，静默时环境音按8.7③放大，BGM按8.6让位。

#### 3.10.8 音色滤镜（空间/介质/状态，联动8.8声音空间感）

| 场景 | 音色处理 |
|------|---------|
| 隔墙/门外/闷在被中 | 闷响、高频衰减、声音发闷 |
| 电话/对讲机/传音法器 | 带电子失真/轻微金属感/窄频 |
| 远处呼喊 | 音量小、尾音被空间吃掉、带混响 |
| 蒙面/面罩/捂嘴 | 声音发闷、含糊 |
| 大殿/山洞/空巷 | 长混响回声（8.8①） |
| 耳鸣/濒死/中毒主观听感 | 周围声闷化拉远+高频啸叫+自己心跳声放大 |

#### 3.10.9 文戏台词每镜检查清单（缺一不可）

1. 每句台词标【角色｜基础声色→情绪变调｜嘴部状态】，情绪变调不能省（3.10.2）。
2. 语速4-5字/秒、单镜台词≤10-12字、长台词跨镜拆、每句精确到秒（8.5.3）。
3. 关键台词给近景/特写+开口前停顿+落音留白；关键词切听话人反应（3.10.5）。
4. 至少一处台词与动作绑定（边做边说/背对说/转身说），禁止站定正对镜头念稿（3.10.3）。
5. 对手戏必须有交互（打断/抢话/沉默/画外接话/反应垫词其一），不是轮流背台词（3.10.4）。
6. 情绪转折优先用非语言发声或静默代替直说（3.10.6/3.10.7）。
7. OS/旁白按8.5.2模式+铁律14嘴部状态：开口说话嘴动、内心OS闭嘴只有微表情。
8. 台词出现时BGM降一个力度层级（8.7①），静默点环境音放大。
