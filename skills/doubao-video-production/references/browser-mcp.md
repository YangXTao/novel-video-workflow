# 豆包专用Playwright MCP

## 固定实现

- MCP名称：`doubao_playwright`。
- 传输方式：项目级STDIO MCP；不依赖Plugin。
- 启动脚本：`D:\jimeng\novel-video-tools\doubao-playwright-mcp\start-mcp.cmd`。
- Chrome程序：`C:\Program Files\Google\Chrome\Application\chrome.exe`。
- 独立用户目录：`D:\jimeng\novel-video-browser\doubao-profile`。
- 浏览器产物目录：`D:\jimeng\novel-video-browser\artifacts`。
- 由上述MCP启动有界面的专用Chrome，使用原持久化目录；不要求另启调试端口。

该用户目录只供此MCP实例使用。不得同时启动两个使用同一目录的浏览器实例，也不得改用用户日常Chrome配置目录。

## 可见窗口与可恢复连接

沿用项目既有STDIO MCP链路，不自动改成worker、独立CDP服务、后台或无头浏览器。启动前核对Chrome进程所属Windows用户、交互会话和user-data-dir；专用Chrome应在持有该目录的原桌面用户下可见运行，不能用沙箱服务账号打开同一登录目录。不要因超时清空、复制替换或新建登录目录。配置目录存在不等于网站仍已登录，登录状态以可见页面为准。

生成核验优先读取视频卡片状态、时长和原始链接，不自动播放视频；仅在必要的视频画质检查时才短暂播放或截帧。

页面应随实际窗口显示：启动配置使用 `browser.contextOptions.viewport: null` 和 `headless: false`，不固定小视口。已有窗口最小化时先恢复normal再最大化；只调整显示，不为修正灰边重启浏览器。配置文件更新只影响后续启动，当前窗口仍须核验。

若控制器出现 `Transport closed`、超时或Codex侧工具断连：

1. 保持专用Chrome和同一用户目录不动，不关闭页面，不重提生成，不切换账号；
2. 在原始豆包任务页确认已有视频卡片、任务状态和原始结果链接；
3. 检查原 `doubao_playwright` MCP是否可用，恢复可用后继续等待、展示原始视频卡片、下载和质检；连接未恢复时保留断点，不启动另一套控制器争用原目录；
4. 仅当Chrome进程本身退出，才让原MCP使用同一目录、原桌面用户启动；先恢复原任务页再操作。

控制恢复不能读取Cookie、密码、localStorage或其他敏感浏览器存储。不得为了恢复而重复点击提交或“重新生成”。

## 两级授权

“无额度测试”只授权：启动浏览器、打开豆包、用户登录后读取页面、进入本镜计划的对话视频或工作任务云电脑入口、上传当前镜头已审核图片、填写并回读提示词。它不授权点击任何会创建生成任务的按钮。

用户明确授权某镜或通过总控授权整章时，可按已批准入口提交对话视频或创建云电脑工作任务，并自动回复普通生成确认/继续消息；重做与账号切换遵从workflow.md及generation-routes-and-quota.md的范围和上限。不得由普通确认推导购买额度、扩权或其他章节授权。

## 首次连接

1. 确认 `doubao_playwright` MCP工具已加载。
2. 打开豆包首页；第一次启动会出现独立Chrome窗口。
3. 如果未登录、出现二维码、验证码或安全校验，停止自动操作并让用户亲自完成。
4. 登录完成后读取可见页面，确认账号和视频入口；不得读取、导出或保存密码、Cookie和令牌。
5. 仅当用户要求无额度测试时止于本镜提交前预览；已有正式生产授权则按workflow.md继续。

## 页面适配

豆包页面定位必须以当次可见页面和可访问性快照为准，禁止把未经验证的CSS选择器写入长期规则。页面没有清楚显示目标控件时停止，不凭坐标猜测。

每镜提交前重新确认：

- 本镜计划的豆包网页“对话→视频生成”或“工作任务→云电脑”，不擅自切换路线；
- 已有明确模型要求（有控件核对，无控件通过执行指令传达）；
- 本镜目标比例：用户在提交小说、剧本或启动本章制作时明确指定则按用户值，否则一律为`16:9`；对话入口必须由网页控件显式显示该目标比例，`自动`视为未配置，不能仅凭正文中的比例文字放行；
- 本镜target_duration_seconds，不固定10秒；
- 当前账号、可见套餐和本入口额度状态；
- 图片数量与上传顺序；
- 文本框中是本镜执行指令、缺失的真实参考图映射（没有缺失则省略）和原样完整视频提示词正文；
- 页面不存在结果未知的同镜任务。

## 安全锁

- 创建工作任务、提交视频、生成确认和重试均要求已有生产范围授权；次数只在实际视频任务被确认创建时递增，不按工作任务数或消息数计费统计。
- 没有当前镜头或覆盖它的章节级授权时，即使按钮可见也不得点击；普通生成确认在有效授权内自动处理。
- 上传失败、顺序不明、提示词无法完整回读或任务状态不明时停止。
- 登录、验证码、付费和模型不可用停止受影响操作；额度不足仅在已有授权账号和同参数路线内恢复，均不可用则报告断点。
